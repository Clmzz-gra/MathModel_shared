# Code Gems

> **这不是一个库。** LLM 可以在需要时即时生成代码。这里存在的代码是为了教学目的
> —— 它展示了模式、风格或深入原理。如果某个文件可以通过"写一个做 X 的 Python 函数"
> 这样的 prompt 生成，它就不属于这里。

## 什么属于这里

- 展示算法结构的教学级实现（不是快速实现，而是清晰实现）
- 生成解释方法的可视化
- 教你用精确的 matplotlib 设置生成 MCM 品质图表的脚本
- 如果 LLM 生成不出来 —— 需要试 5 次才对的片段

## 什么不属于这里

- 工具函数
- 数据加载器
- LLM 可以从头写的模型实现
- 任何可导入的库代码

## 使用方式

LLM 读取这里的代码作为风格和模式参考，**绝不导入**。解题时的代码写在
`outputs/scratch/`（临时）或内联在 notebook 中。
