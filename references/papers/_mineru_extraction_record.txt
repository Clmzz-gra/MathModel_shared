=== Known Issue: MinerU CDN SSL Failure Behind Proxy ===
Root cause: When system proxy (e.g., Clash/V2Ray at 127.0.0.1:7892) is active,
the CDN `cdn-mineru.openxlab.org.cn` fails SSL handshake through the proxy tunnel.
The proxy's CONNECT returns 200 but the actual CDN SSL negotiation fails.
Direct connection (bypassing proxy) works perfectly.

Fix: Set $env:HTTPS_PROXY='' and $env:HTTP_PROXY='' before running mineru-open-api.
