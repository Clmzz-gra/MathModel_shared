## 1 问 的 述与提出

## 1.1 “互联网+”时代的出租车行业 况

随着网络通信 术的不断发 和智能 机 移动终 的迅速普及， 车软件 在全国范围内兴起，并且 有改变传统出租车市场的趋势。 前出租车市场面临的主要问 ， 三个字 是“ 车难”。其原因有三：

当 题 用 概括就 打一是出租车绝对数 供给不足，出租车数 的国家标准为“ 城市 万人不宜 于20辆”， 数城市都远远达不到这个标准。出租车市场的绝对需求 于绝对供给导 卖方市场，司机 于优势一方，乘客 于劣势一方，使 出租车价格较 。

二是 于信息不对称，出租车相对数 供给不足。想 车的人不知道哪 有车，出租车不知道哪 有人 车。这样 然会造 出租车有效资源的 浪费，在绝对数 不足的情况下，雪上加霜。更加会出现不可思议的 率和 车难并存的怪现 。

三是部分司机选 性停运，原因在于出租车司机不愿出车 选 性出车，导 道路上行 的出租车数 。是 于出租车市场的不均衡，需求远远 于供给。出租车司机 于优势地位，便会去挑选客人、路线、地点 ，从而产 司机 载的现 。

车软件出现之后，对 于信息不对称产 的 车难现 有 缓解，并且使 司机也可以选 周边的乘客进行服务，宏观上来看，减 了无效 旅 ，并增加了燃油利 效率。不仅 ， 于 车软件是新兴事 ，其渴望占有原出租车市场的行业份 ，故 然会提出各 补贴的政 ，从而刺激消费者群体的积极性，并建 司机群体中的使 习惯。 车软件公司在决 过 中遇到了一系列的问 ，，而这些问 是本文探讨的 点。

## 1.2 需解决的问

出租车是市民出行的 要交通工具之一，“ 车难”是人们关注的一个社会热点问 。随着“互联网+”时代的到来，有 家公司依 移动互联网建 了 车软件服务平台，实现了乘客与出租车司机之间的信息互通，同时推出了种出租车的补贴方案。

请你们 集相关数据，建 数学 型研 下问 ：

(1) 试建 合理的指标，并分析不同时 出租车资源的“供求匹 ” 度。

(2) 分析各公司的出租车补贴方案是否对“缓解 车难”有帮助？

(3) 果要创建一个新的 车软件服务平台，你们 设计什么样的补贴方案，并论证其合理性。

## 4 问 分析

## 4.1 问 （1）的分析

该问 要求建 合理的指标，并分析不同时 出租车资源的“供求匹 ” 度。本文基于“苍 ——滴滴 的智能出行平台”[1]中使 滴滴 车的出租车以及 的行为情况，建 了供求匹 情况下的出租车 型，并 以评价上海市的出租车资源“供求匹 ” 度。

衡 出租车运营情况的最直观数据 是出租车的位置分布，衡 出租车需求 度的最直观数据是 车人数即请求单数的分布，而直接和 车软件 体 相关联的数据则是乘客 车时间，这 们 接单时间来衡 。 于率K可以对应出租车供应 ，而乘客 时间可以对应出租车需求 ，故两者的函数关系可以作为衡 供应 的指标。通过对以上三个基本数据进行分析， 们 出可以 率K和乘客 时间T作为衡 供求情况的具体指标。通过考察城区和郊区全 24 时的K变化规 ， 们 出 间（城郊）和时间（全 ）两个维度的供求关系分布情况。

这部分 们分为三个部分进行探讨：

先， 们想确定在某个时间 内，研 上海市出租车粗 的 间分 情况。 们对某工作日和节假日进行样，使 插值的方法在Matlab中分别绘制出了这一 低 10：00、 17:00时 ，全上海市的 样点地理位置(经度x, 纬度y)与出租车分布、乘客需求 分布、以及 时间的三维图像，为进一 讨论 下了基础。

接下来， 们想讨论时间对于出租车分 度的 响。 于数据 过 ，且不同数据指标取样点的 间位置不是严格对应的， 们利 集簇的思想，选 了20个具有代表性的商圈以及城郊，并根据具体位置选 合适的半 ，囊 其周边的 样数据点，并 出平均 时间，作为某一具体时刻，具体地点的供求分 度的 度。 们选出具有代表性的商圈与城郊，考察他们在工作日、非工作日的情况，并作出了其周边一 内平均 载率Kave与真实时间t的二维图像。

最后， 们 入了供求满意度函数f，建 了出租车供需关系平衡的数学 型，并综合 二部分中的数据，利曲线 合工具 到了上海市区的供需平衡 型，并 其利 于评价上海市出租车资源“供求匹 ” 度。

该问 要求分析各公司的出租车补贴方案是否对“缓解 车难”有帮助。为了更客观的研 整个出租车 型，们想要建 一种合适的 过 方案，可以体现出在 车软件的情况下，有无补贴以及补贴力度不同时出租车盈利、行为 的不同。

“ 车难”具体可以表现为出租车总 路 ：即 路 越长，说明司机浪费在 寻乘客的路途上越长；反之，则说明乘客 车难受到了缓解。

## 4.3 问 （3）的分析

该问 要求讨论 果要创建一个新的 车软件服务平台，什么样的补贴方案 较合适，并论证其合理性。 们认为全文的研 范 更为理想化，而不涉及公司 争市场份 行为，更偏向于解决 今的“ 车难”问 。

## 5.1.4 建 出租车供需平衡 态下的出租车使 型

## 5.3 问 (3)的 型建 与求解

本环节 探讨实际 作过 中，补贴方案对于社会总福利的 响。在 国传统出租车市场中，社会福利的最化是 政府部门出租车系统的运营规 、服务价格及服务质 方面相关 制政 保证的；随着 车软件的出现，新兴的服务方 占据一定的市场份 ， 时，龙 公司的福利决 方案可以 然会对现有社会福利产

响。社会总福利根据社会学定义是 消费者剩余与 产者剩余两方面构 ，在出租车行业主要表现为司乘双方的剩余价值。保证消费者剩余可提 乘客的满意度，维持消费刺激；保证 产者剩余有利于出租车行业的可持续发Θ[7]

## 附录2.3网格模型概率矩阵计算

```matlab
function [P]=Pij(miu, fileName)
d=xlsread(fileName,3); % 最短路径矩阵
De=xlsread(fileName,4); % 方向需求矩阵（非对称）
P=zeros(7);
theta=0.3;
for i=1:1:7
Qi=De(i,8);
for j=1:1:7
if (i==j)
continue
end
fuko=exp(theta*(-d(i,j)+miu*Qi)); % 计算分子的值
fumu=0;
for k=1:1:7
fumu=fumu+exp(theta*(-d(i,k)+miu*Qi)); % 计算分母的值
end
if (fumu~=0)
P(i,j)=fuko/fumu;
else
P(i,j)=0;
end
end
end
%disp(P);
end
```

```matlab
function [S]=Tsa()
A=0.5:0.5:5;
B=0.5:0.5:5;
m=0.5;
n=0.06;
miu=0.05;
fileName='meshin1.xls';
p=4.41;% p为市场平均单位距离价格（元/公里）
alpha=-1.3;
beta=-0.2;
gamma=-1;% alpha, beta, gamma均为弹性系数
K1=45061;
K2=1386;
c=1.803;% c为单位距离运营成本（元/公里）
%------为方便求和运算 定义中间系数A1,A2,A3
A1=(p^(alpha+1) * alpha * (K1*K2^beta)^(1/alpha))/(alpha+1);
A2=gamma*beta/alpha;
A3=K1*K2^beta*p^alpha;
A4=gamma*beta;
Base=S0();
```
