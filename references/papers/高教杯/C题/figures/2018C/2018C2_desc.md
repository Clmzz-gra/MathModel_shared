这是一张关于“总金额”分布比例的学术论文插图，具体描述如下：

### 1. 图表类型
* **二维饼图（2D Pie Chart）**：用于展示各分类数据占总体的比例关系。

### 2. 核心信息
该图展示了数据集中“总金额”在四个不同区间的分布比例：
* **总金额为0**：占比最大，为 **75.00%**（蓝色区域）。
* **0 < 总金额 < 10000**：占比第二，为 **17.86%**（红褐色区域）。
* **10000 <= 总金额 <= 50000**：占比为 **5.65%**（绿色区域）。
* **总金额 > 50000**：占比最少，仅为 **1.48%**（紫色区域）。

### 3. 布局
* **主体部分**：饼图居于图像正中央，由蓝、红、绿、紫四个颜色扇区顺时针或逆时针排列组成（蓝色占大半部分）。
* **图例部分**：图例位于图表的最下方，采用横向并排布局，通过颜色色块与文字（如“总金额为0”）一一对应。
* **背景**：简洁的纯白色背景。

### 4. 标注方式
* 对于面积较大的扇区（蓝色和红褐色），百分比数值（`75.00%`、`17.86%`）直接标注在**扇区内部**。
* 对于面积较小的窄扇区（绿色和紫色），百分比数值（`5.65%`、`1.48%`）标注在**饼图外部上方**，并通过细灰色的**指引线**指向对应的扇区。

## p06_618x328.jpg
以下是对该学术论文插图的详细描述：

### 1. 图表类型
* **复合饼图（又称子母饼图、双重饼图，Pie of Pie Chart）**。它用于展示一个大整体的构成，并将其中占比极小、在主饼图中难以看清的分类，提取出来在右侧的子饼图中进行放大展示。

### 2. 核心信息
该图表展示了**“消费宗数”在不同区间段的用户/样本占比分布**。核心数据及结论如下：
* **零消费占比极高**：“消费宗数为0”的样本占比高达 **74.97%**，是绝对主体。
* **低频消费次之**：“0 < 消费宗数 <= 10”占比为 **19.30%**。
* **中高频消费占比极低**：随着消费宗数的增加，比例急剧下降。
  * 10 < 消费宗数 <= 20：占比 **2.75%**。
  * 20 < 消费宗数 <= 50：占比 **2.00%**。
  * 50 < 消费宗数 <= 100：占比 **0.68%**。
  * 消费宗数 > 100：占比 **0.30%**。
* **主子饼图关联**：右侧子饼图将占比极低的两项（50-100次和100次以上，合计约 0.98%）放大，在主饼图中对应的是占比写为 `0.00977633552`（即约0.98%）的极窄深蓝色扇区。

### 3. 布局
* **左侧（主饼图）**：体积较大，位于左侧中心，展示了占比前四分类和极小值集合分类。
* **右侧（子饼图）**：体积较小，位于右侧，通过两根灰色的牵引线与主饼图中的极窄扇区相连。
* **底部（图例）**：图例位于最下方，呈水平两行居中排布，共有6个彩色方块对应6个消费区间。

### 4. 标注方式
* **内部标注**：对于面积较宽的扇区（如 74.97%、19.30%、0.68%、0.30%），百分比数值直接标注在对应的扇区内部。
* **外部对齐标注**：对于主饼图右侧较窄的三个扇区（2.75%、2.00% 和 0.00977633552），数值被统一放置在扇区右侧，呈上下垂直对齐排列，清晰易读。
* **文本/图例标注**：分类定义（如“0 < 消费宗数 <= 10”）全部放在底部的图例中，使用标准的数学区间符号进行科学标注。

### 5. 水印内容
* 该图片背景为纯白色，**没有任何水印、LOGO或版权标识**。

这是一张关于“购买数量”分布比例的学术论文插图。以下是对该图的具体描述：

### 1. 图表类型
该图为**复合饼图（又称子母饼图 / Pie-of-Pie Chart）**。它由一个主饼图和一个子饼图组成，用于细化并放大主饼图中占比极小的分类。

### 2. 核心信息
图表展示了用户/样本在不同“购买数量”区间内的比例分布：
*   **绝大多数**样本的购买数量为0，占比高达 **74.97%**。
*   其次是购买数量在0到10之间（不含0，含10），占比 **19.14%**。
*   随着购买数量的增加，比例急剧下降：10~20占比 **2.77%**；20~50占比 **2.08%**。
*   购买数量大于50的比例极低，合计约为1.04%（主饼图中以小数 `0.0104335682` 标注）。这部分极小比例在右侧子饼图中被放大展示：其中50~100占比 **0.71%**，大于100占比 **0.33%**。

### 3. 布局
*   **主体布局**：采用左右结构。左侧为较大的主饼图，右侧为较小的子饼图。子饼图通过两条灰色的指引斜线与主饼图中的极小切片相连，表示数据的延伸和放大。
*   **图例布局**：图例位于图表的正下方，采用两行横向排列，通过颜色色块与文字对照，依次列出了6个购买数量区间的分类。
*   **背景**：纯白色背景，无网格线或边框。

### 4. 标注方式
*   **百分比标注**：主饼图的大份额切片（蓝、红）和子饼图的切片（天蓝、橙）直接在扇区内部标注百分比（如 `74.97%`、`19.14%`、`0.71%`、`0.33%`）。
*   **指引线标注**：主饼图中较窄的切片由于空间不足，百分比数值（如 `2.77%`、`2.08%` 和表示子饼图总和的十进制小数 `0.0104335682`）被放置在切片右侧，并通过细指引线指向对应的扇区。
*   **图例标注**：底部图例使用“颜色方块 + 区间数学表达式”（如 `0<购买数量<=10`）来清晰界定各部分的含义。

### 5. 水印内容
该图片干净、清晰，**没有任何水印**（无平台logo、无用户名或防盗图背景字样）。

### 2. 核心信息
该图表反映了**商场会员与非会员在2016年1月至2017年9月期间的每日消费总额对比及趋势**：
* **非会员消费总额（蓝色填充区域）**：在2016年1月至3月期间消费额极高（多次突破400万元），但自2016年4月起急剧下降，此后一直保持在较低且相对平稳的水平（基本在100万元以下）。
* **会员消费总额（红色折线）**：日常消费额普遍较低，但呈现出极强的季节性或活动驱动的“脉冲式”暴涨。在2016年12月前后达到近1000万元的最高峰；在2016年10月、2017年3月、2017年9月等节点也出现了数百万到近千万不等的消费巨峰。

### 3. 布局
* **顶部**：居中放置图表主标题。
* **中心区域**：为数据展示主体，配有灰色的水平参考网格线，便于对比数值。
* **左侧**：纵坐标轴（Y轴），代表消费金额。
* **底部**：横坐标轴（X轴）代表时间，轴下方居中设有图例。

### 4. 标注方式
* **标题标注**：顶部标题为“商场会员、非会员每日消费总额”。
* **纵轴（Y轴）标注**：

* **横轴（X轴）标注**：
  * 轴标签为“消费时间”。
  * 刻度为日期格式（如 `2016/1/1`），采用**逆时针倾斜45度**的标注方式，以防文字重叠。
