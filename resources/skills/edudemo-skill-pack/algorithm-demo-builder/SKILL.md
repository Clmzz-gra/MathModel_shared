# Algorithm Demo Builder — 智能算法教学演示工具生成规范

> 版本 1.0 | 2026-08-17 | 反推自 edudemo（说明见 `../edudemo/README.md`）
> 本 skill 承载「生成算法教学演示 GUI 工具」的完整规范：结构（core/ui/utils 三层）+ 算法要素 + 界面要素 + 实验对比 + 验收标准。

## 定位

edudemo 是四件套算法教学演示工具（ACO/GA/PSO/SA），每个工具是一个独立可运行的 GUI 应用，用
**可视化交互**让学生理解智能优化算法的搜索过程。本 skill 把这一工具族的**工程规范**沉淀下来：
当需要**新建**某算法的教学演示工具、**复现** edudemo 四件套、或**扩展**新算法演示时按本规范执行。

## 工具蓝图（四件套）

| 工具 | 算法 | 特点 |
|------|------|------|
| `aco-gui-tool` | 蚁群优化 ACO | TSP 路径可视化、信息素更新过程、多代蚂蚁路径演化 |
| `ga-gui-tool` | 遗传算法 GA | 选择/交叉/变异算子可视化、适应度演化、测试函数寻优 |
| `pso-gui-tool` | 粒子群 PSO | 粒子群运动、拓扑结构（全局/局部）、速度-位置更新可视化 |
| `sa-gui-tool` | 模拟退火 SA | 温度下降曲线、邻域搜索、接受/拒绝跳变可视化 |

每个工具**独立可运行**（不互相依赖），共享同一套工程结构。

## 工程结构（强制三层）

```
<algo>-gui-tool/
├── main.py              # 入口：启动 GUI 主窗口（Tkinter/PySide 均可）
├── core/                # 算法核心（纯逻辑，不依赖界面）
│   ├── algorithm.py     # 主算法类：状态、迭代、收敛判定
│   ├── <algo>_specific  # 算法特有模块（见下表）
│   └── test_functions.py# 基准测试函数（Rastrigin/Ackley/Sphere 等）
├── ui/                  # 界面层（只做展示与交互，不写算法逻辑）
│   ├── visualization.py # 画布：实时绘制迭代过程
│   ├── sidebar.py       # 控制面板：参数滑块/按钮/状态区
│   ├── analysis.py      # 结果分析：收敛曲线/统计输出
│   └── help_content.py  # 帮助面板：算法说明文本
└── utils/               # 工具层（实验/批处理）
    └── experiment.py    # 多次运行实验、统计对比、导出
```

## 算法特有模块

| 工具 | 特有模块 | 内容 |
|------|---------|------|
| aco | `tsp_problems.py` | TSP 城市坐标生成/加载、距离矩阵 |
| ga | `selection.py` / `crossover.py` / `mutation.py` | 选择算子 / 交叉算子 / 变异算子 |
| pso | `topology.py` | 邻域拓扑（全局 best / 环形局部 best） |
| sa | `annealing.py` / `cooling_schedules.py` / `neighborhood.py` | 退火主循环 / 降温策略 / 邻域生成 |

## 分层规则（强制）

1. **core 层零界面依赖**：算法类只接收参数、返回结果，不 import 任何 UI 模块；界面层调用 core、core 不反向依赖 ui。
2. **ui 层零算法逻辑**：界面只负责参数收集、调用 core、绘制结果；收敛判定/公式迭代一律在 core。
3. **utils 层可复用 core**：实验脚本 import core 的算法类做批量运行，不经界面。
4. **参数面**：界面侧栏暴露的参数与 core 算法类构造参数一一对应（种群规模/迭代次数/交叉概率/变异概率/温度初值/降温率…）。

## 算法要素（每个工具 core 必须实现）

1. **状态对象**：保存当前解/种群/粒子群/温度等全部搜索状态，供界面逐帧读取绘图。
2. **单步迭代接口**：`step()` 或 `solve(step_callback)`——界面按帧调用，每次推进一代/一次邻域移动，回调暴露中间状态。
3. **收敛判定**：迭代上限 + 适应度停滞阈值双条件，返回是否收敛。
4. **随机种子**：可传入 seed，保证实验可复现。
5. **结果输出**：最终解、最优值、收敛历史（每次迭代最优值序列，供收敛曲线）。

## 界面要素（每工具 ui 必须实现）

1. **实时画布**：可视化每次迭代的当前状态（ACO 路径图 / GA-PSO 适应度图 / SA 接受跳变图）。
2. **参数侧栏**：全部关键参数滑块 + 随机种子 + 开始/暂停/重置按钮。
3. **收敛曲线面板**：迭代次数 × 最优适应度（与画布同屏或 tab 切换）。
4. **结果统计区**：最优值、收敛代数、运行时间。
5. **帮助面板**：算法原理简文 + 参数含义 + 操作说明（`help_content.py`）。

## 实验对比（utils/experiment.py）

同一算法不同参数/不同种子多次运行：输出各次最优值、均值、标准差、收敛代数；
支持导出 CSV，供教学演示参数敏感性结论。跨算法对比（ACO vs GA vs PSO vs SA）由四工具分别运行后人工对照。

## 验收标准（生成完成后逐条核对）

1. `main.py` 可独立启动 GUI，无 import 错误。
2. core 层可在无界面环境单独运行（脚本调用 step 循环跑完收敛）。
3. 界面实时绘图不卡顿（每帧迭代计算 < 100ms，或用异步/降帧）。
4. 随机种子固定时结果可复现（两次运行最优值一致）。
5. 收敛曲线有值（迭代至少推进 10 步以上才允许结束）。
6. 帮助面板覆盖：算法原理、全部参数含义、操作步骤。

## 与项目其他机制的配合

- 生成代码遵循 `TRAE-规范.md` C1 代码头注释（含性能声明——GUI 工具通常轻量；若做批量实验需声明并行策略）。
- 实验批处理遵循 C8 决策树（多 seed 并行优先）。
- 代码审查走两遍审核（建模查原理、coding 查逻辑）。
- 本 skill 为教学演示类；竞赛求解仍走管线正式代码（不以此代替正式模型代码）。
