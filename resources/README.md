# resources — 队友资源共享区

**这个目录是给队友用的，不受 PR 限制**：可以自由创建子目录、自由修改，直接 push。

## 怎么用

1. **一个资源 = 一个子目录**（用中文或英文名都行），例如：
   ```
   resources/2024-B优秀论文/
   resources/历届获奖论文笔记/
   resources/常用代码片段/
   ```
2. 每个子目录里放一个 `说明.md`，写清楚：
   ```
   # 资源名称
   - 内容：这个资源是什么
   - 用途：能用来干什么
   - 来源：出处或作者
   - 上传：你的名字 + 日期
   ```
3. commit 信息写清楚，如：`资源: 添加 2024-B 优秀论文合集`

## 注意

- 这里的内容**不会同步到队长的核心仓**，只在共享仓内流通
- **不要把临时文件塞进 `references/`、`latex/` 等共享目录**——那些是正式资产，会被同步走且受 PR 保护
