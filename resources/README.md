# resources — 队友资源共享区

**这个目录是给队友用的，不受 PR 限制**：可以自由创建子目录、自由修改，直接 push。

> 核心原则：**一个资源一个文件夹，文件夹里必须带说明**。分类越清晰、说明越完整，别人用起来越省力。

## 一、用文件夹分类

**每个资源放一个独立文件夹**，不要把所有文件堆在 `resources/` 根目录下，也不要堆在同一个文件夹里。

```
resources/
├── 2024-B优秀论文/
├── 历届获奖论文笔记/
├── 常用代码片段/
├── 图表配色方案/
└── 队友共享的赛题解析/
```

命名规范：文件夹名能一眼看出内容是什么（年份 + 题号 + 主题，如 `2024-B优秀论文`）。

如果某个类别下内容很多，可以**再建一层子文件夹**继续细分：

```
resources/历届获奖论文/
├── 2023/
│   ├── A题/
│   └── B题/
└── 2024/
    ├── A题/
    └── B题/
```

## 二、每个文件夹里放说明文件

**建文件夹的同时，在里面放一个 `说明.md`**，让别人不用打开文件就知道这里是什么：

```markdown
# 资源名称

- 内容：这个资源是什么（论文 / 数据 / 模板 / 工具…）
- 用途：能用来干什么
- 来源：出处或作者
- 上传：你的名字 + 日期
```

说明可以很短，几句话就够；没有说明的资源，别人不知道怎么用，等于白传。

## 三、写清 commit 信息

每次分享，commit 信息写清楚加了什么，例如：

```
资源: 添加 2024-B 优秀论文合集
```

不要只写 `update`、`add`。

## 注意

- 这里的内容**不会同步到队长的核心仓**，只在共享仓内流通
- **不要把临时文件塞进 `references/`、`latex/` 等共享目录**——那些是正式资产，会被同步走且受 PR 保护
- `resources/skills/math-explainer/` 是队长贡献的数学讲解 skill，**只读使用，不要修改**
