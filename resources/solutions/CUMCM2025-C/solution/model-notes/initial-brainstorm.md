# 2025 C题 初始头脑风暴

## 整体思路

### 核心挑战
1. **生物统计问题**：Y 染色体浓度随孕周的增长是非线性的（早期快速增长，后期趋于饱和）
2. **风险权衡问题**：检测过早 → 浓度不达标 → 结果不准确；检测过晚 → 治疗窗口期缩短 → 风险增加
3. **个体差异问题**：BMI、年龄、身高、体重等都在影响达标时间
4. **女胎分类问题**：没有 Y 染色体作为标记，需依靠染色体 Z 值等间接判断异常

### 问题 1 思路

Y 染色体浓度的增长最可能是 **Logistic 生长曲线**：
$$Y(t) = \frac{K}{1 + e^{-r(t - t_0)}}$$
其中：
- $K$ ≈ 饱和浓度（受 BMI 调节）
- $r$ ≈ 增长率
- $t_0$ ≈ 拐点孕周

BMI 的影响可能体现在：
- 高 BMI → 血容量增大 → 胎儿 DNA 被稀释 → $K$ 降低、$t_0$ 后移
- 需要验证 BMI 与 Y 浓度之间是否确实是反向关系

**替代方案**：
- 分段线性回归（孕周 < 16 周快速上升段 + ≥16 周平台段）
- 广义线性模型（GLM）带交互项
- 随机森林/梯度提升（无需预设函数形式）

### 问题 2 思路

**风险函数设计**：
$$R(T) = \alpha \cdot P_{\text{不达标}}(T) + \beta \cdot L(T)$$

其中：
- $P_{\text{不达标}}(T)$：在时点 T 检测时 Y 浓度 < 4% 的概率
  - 从问题 1 模型中 Y 浓度的预测分布（预测区间）计算
- $L(T)$：治疗窗口损失 = f(发现时间 - 理想发现时间)
  - 分段：≤12 周 0 风险，13-27 周 线性递增，≥28 周 极高

**BMI 分组**：
- 方法 1：等宽分组（按题目给出的区间）
- 方法 2：K-means 聚类分组
- 方法 3：基于风险最小化的最优分割
- 每组内取使该组平均风险最小的时点为最佳 NIPT 时点

### 问题 3 思路

比问题 2 多了几个维度：
1. **多因素模型**：将年龄、身高、体重等纳入 Y 浓度预测模型
2. **达标比例**：每组内达标比例 ≥ 某个阈值（如 95%）是约束条件
3. **联合优化**：分组 + 时点联合优化

**方法候选**：
- 在问题 1 的多因素模型基础上，用决策树对 BMI 进行最优分割
- 将达标比例作为约束，在满足约束的时点中选择风险最小的

### 问题 4 思路

女胎异常判定的关键是：
1. **Z 值分析**：21/18/13 号染色体的 Z 值 ≥ 3 通常提示三体（正常 Z 值约在 [-3, 3] 区间）
2. **X 染色体**：女胎 X 染色体浓度 = 两条 X 染色体的总浓度，异常可能提示 Turner 综合征（XO）或 XXX 综合征
3. **多指标综合**：需要综合考虑多个 Z 值和测序质量指标

**方法候选**：
1. **统计规则法**：Z 值 > 3 为异常阈值（经典 Z 值方法）
2. **逻辑回归**：可解释性好的分类模型
3. **集成学习**（随机森林/XGBoost）：性能更好但可解释性差
4. **多阶段判定**：先用 Z 值规则过滤，再对边界样本用机器学习

**类别不平衡**：异常胎儿在总体中比例很小（<5%），需要处理不平衡问题。

## 数据侧写

### 男胎数据 (1082 行)
- 多个孕妇有多次检测记录（重复测量），需要处理组内相关性
- Y 染色体浓度范围：需要检查是否有达标/未达标的分界
- BMI 范围：题目说"大多为高 BMI"，需要确认分布
- 孕周范围：应覆盖 10-25 周

### 女胎数据 (605 行)
- 无 Y 染色体相关列，有 X 染色体 Z 值/X 染色体浓度
- AB 列（染色体非整倍体）可能是 ground truth，但需要确认空白 = 正常
- X 染色体浓度可能出现负值（题目说明提到）
- 胎儿是否健康（AE 列） = 婴儿出生后的结果

## 需要注意的陷阱

1. **重复测量**：同一孕妇多次检测的数据不是独立的，需要处理这种组内相关性（混合效应模型？）
2. **测序失败**：部分数据因时点过早等原因可能有测序质量问题，需要做质量控制过滤
3. **负值浓度**：X 染色体浓度可能出现负值（题目说明），需要在预处理时注意
4. **缺失值**：女胎数据中 Y 染色体相关列为空白，男胎数据中某些列也可能有缺失
5. **BMl 异常值**：题目提到"大多为高 BMI"，可能存在极端高 BMI 的样本
6. **女胎标签质量**：AB 列的"空白"是否确实为正常？（临床 Z 值分析可能有灰色地带）
