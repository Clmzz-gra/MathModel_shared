# 问题 2 重述（修正版）

**最后修改**：2026-07-19
**状态**：operationalized

## 题目原文

> 临床证明，男胎孕妇的 BMI 是影响胎儿 Y 染色体浓度最早达标时间的主要因素。试对男胎孕妇的 BMI 进行合理分组，给出每组的 BMI 区间和最佳 NIPT 时点，使得孕妇可能的潜在风险最小，并分析检测误差对结果的影响。

---

## 关键洞察：早测与晚测的代价不对称

| 场景 | 后果 | 不可逆？ |
|------|------|:--:|
| **测太早**，Y < 4%，检测不可靠 | 约下一次重新抽血即可 | ✗ |
| **测太晚**，治疗窗口关闭 | 无法干预 | ✓ |

一个可以重来，一个不能重来。因此：

> "风险最小化" ≠ 在检测失败和窗口损失之间找平衡点。
> "风险最小化" = **在可接受的达标把握下，尽可能早测。**

---

## 操作化定义

### 最优时点

$$t^* = \min\Big\{ t \in [10, 25] : P(Y \geq 4\% \mid t, \text{BMI}) \geq p_0 \Big\}$$

| 符号 | 含义 |
|------|------|
| $t$ | 检测孕周 |
| $P(Y \geq 4\% \mid t, \text{BMI})$ | 由问题 1 模型给出的条件达标概率 |
| $p_0$ | 可接受的达标概率阈值（例 $p_0=0.5$——意味着不达标只需重测，代价小故可容忍较低把握） |

若某组即使在 $t=25$ 周仍无法达到 $p_0$，则 $t^* = 25$（检测窗口上限），并在结果中标注"此组在现有窗口内达标率有限"。

### 治疗窗口风险作为硬约束

孕期 28 周之后为极高风险——$t^*$ 不得超过 25 周（预留 3 周 buffer）。$t^* \leq 25$ 是硬约束。

---

## 输出规格

1. 各组 BMI 区间
2. 各组最佳 NIPT 时点 $t^*$
3. 该时点的达标概率 $P(Y \geq 4\% \mid t^*)$
4. $p_0$ 灵敏度分析：当把握阈值从 0.5 调到 0.7 时，$t^*$ 变化多少？——即"检测误差对结果的影响"
