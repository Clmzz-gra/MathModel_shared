# 2024 CUMCM C题 — 农作物的种植策略

## 一、核心问题

为华北山区某乡村制定 2024–2030 年农作物最优种植方案，在耕地类型、轮作约束、预期销量等限制下，最大化种植收益。

---

## 二、问题背景

- **地理位置**：华北山区，常年温度偏低
- **耕地总量**：1201 亩露天耕地，分散为 34 个不同地块
- **耕地类型**（4种）：平旱地、梯田、山坡地、水浇地
- **大棚**：16 个普通大棚 + 4 个智慧大棚（每个 0.6 亩）
- **种植季次**：大多数耕地每年一季；水浇地可一季水稻或两季蔬菜；普通大棚可一季蔬菜+一季食用菌；智慧大棚可两季蔬菜
- **合种**：同一地块（含大棚）每季可以合种不同作物
- **约束**：
  - 不能连续重茬种植同一作物
  - 2023 年起，每个地块三年内至少种植一次豆类作物
  - 每种作物每季种植地不能太分散
  - 每种作物在单个地块种植的面积不宜太小
- **数据来源**：附件1（耕地基本情况）、附件2（2023年种植与统计）、附件3（结果模板）

---

## 三、子问题拆解

### 问题 1：静态环境下的最优种植方案（确定性优化）

**假设**：预期销售量、种植成本、亩产量、销售价格均相对 2023 年保持不变。
**约束**：每季总产量超过预期销售量的部分——(1) 滞销浪费；(2) 按 50% 价格降价出售。
**产出**：2024–2030 年每年两季（或一季）的作物-地块-面积分配方案。
**输出文件**：`result1_1.xlsx`（浪费情况）、`result1_2.xlsx`（降价情况）

**关键特征**：
- 本质是 7 年多周期的**线性规划 / 混合整数规划**
- 两种超产处理方式相当于两种目标函数
- 需要考虑轮作约束（三年豆类循环、禁止重茬）

### 问题 2：不确定环境下的最优种植方案（鲁棒优化）

**不确定性来源**：
| 变量 | 变化特征 |
|------|---------|
| 小麦/玉米预期销售量 | 年增长 5%–10% |
| 其他作物预期销售量 | 年变化 ±5% |
| 亩产量 | 年变化 ±10%（受气候影响） |
| 种植成本 | 年增长约 5% |
| 粮食类销售价格 | 基本稳定 |
| 蔬菜类销售价格 | 年增长约 5% |
| 食用菌销售价格 | 年下降 1%–5%（羊肚菌年降 5%） |

**产出**：鲁棒最优种植方案，填入 `result2.xlsx`。

**关键特征**：
- 需要处理多维不确定性
- 适合**随机规划**或**鲁棒优化**或**情景分析 + 蒙特卡洛**
- 需要量化"种植风险"

### 问题 3：考虑替代性/互补性与相关性的种植策略

在问题 2 基础上，额外考虑：
- 作物间的**可替代性与互补性**（交叉弹性）
- 预期销售量与销售价格、种植成本之间的**相关性**
- 通过**模拟数据**求解，与问题 2 比较

**关键特征**：
- 需要生成模拟数据
- 模型复杂度最高
- 需要做对比分析

---

## 四、要求产出

1. 数学模型（每个问题至少一个）
2. 计算结果填入 Excel 模板（result1_1, result1_2, result2）
3. 论文：包含问题分析、模型建立、求解算法、结果分析、灵敏度分析

---

## 五、显式约束

- 时间跨度：2024–2030（7 年）
- 地块不可拆分太细（"种植面积不宜太小"）
- 作物每季种植地不能太分散
- 超产 → 滞销浪费 或 降价 50% 处理
- 水浇地：一季水稻 **或** 两季蔬菜
- 大棚有固定类型和数量

---

## 六、隐含约束

- "种植地不能太分散"、"面积不宜太小" → 需要定义具体阈值或通过目标函数软约束实现
- 豆类轮作：三年内至少一次 → 7 年跨度意味着至少 2–3 次豆类种植
- 作物生长期与季次匹配（题目暗示但未详细说明）
- 大棚内部合种可能受空间限制
- 劳动力/田间管理未量化，但通过"不太分散"间接体现
