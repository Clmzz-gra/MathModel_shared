# solution/handoff/

讲解包体系存放目录（队友写作交接区）。按文件名序号阅读：

| 序号 | 文件 | 内容 | 生成时机 |
|---|---|---|---|
| 00 | `00-赛题内容与数据解析.md` | 赛题转述 + 数据认知（字典/规模/口径/清洗） | 阶段 0-1 |
| 01 | `01-整体分析逻辑与思路.md` | 问题拆解、问间依赖、整体建模路线、阅读地图 | 阶段 0-1 |
| 02.. | `02-问题N分析与思路.md`…（每问一个） | 该问的分析思路、模型、结果、写作要点 | 报告定稿（门禁 A）后 |
| M-xx | `M-xx-方法讲解-<方法名>.md`…（每个方法一个） | 数学方法讲解（含迷你算例），被多个问共用 | 首次用到该方法时 |

- 生成方式：math-explainer skill「讲解包模式」单独生成（阶段 2.5；全局 00/01 在阶段 0-1 后）
- 交付条件：人类审阅通过（门禁 B）后才可交给队友写作

模板：`latex/templates/components/explain-pack.md`
