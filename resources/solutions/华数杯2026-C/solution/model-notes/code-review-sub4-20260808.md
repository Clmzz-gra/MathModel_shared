### 🟠 中等

**M-1：E/F 共 70 个 EDF 失败任务对层 2 MILP 结构性不可行**

**M-2：D 区基荷填充 17.3% 与方案书"87% 覆盖"叙事不符**
- 处理：不改代码（Q3 要求层 1 与 S2 严格一致），回填方案书实证口径

**M-3：AI IT 配额用 NonAI 均值，高峰小时"绿色覆盖"被突破**
- 修复：逐时配额 `quota_arr = max(P25/PUE − NonAI_t, 0)`

**M-4：EDF 最坏情况 O(候选×窗口×dur) 无守卫**
- 修复：slack_gpu/slack_aiit 总余量守卫（精确必要条件，只跳过不误杀）

### 🟡 轻微

- **L-1**：硬编码 0.16 → `s2['power_mapping']['AITraining']`
