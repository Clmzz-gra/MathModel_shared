## 1. 方案概述

**主方案（A）**：6 区域独立、2400 小时主时域 + 2400–2405 结清段的全时域储能协同优化**线性规划（LP）**。以逐时储能充放电、购售电、新能源分配为决策变量，在功率平衡、SOC 递推（含 SOC(2406)≥Initial 硬约束）、充放功率/容量/购售电边界约束下，**最小化运行成本**（购电 − 卖电收入），并按碳排 ε-约束三档（基准碳排 90%/95%/100%）扫描，输出成本-碳排权衡前沿。

**对照框架（D1 裁定）**：
- 诚实对照下界 = **无储能口径 c**（GridPurchase = max(Total_Load − UsedRenewable, 0)，保留基准直消纳、去掉储能）：成本 2387.86 M 元 / 碳排 2108.00 kt / 峰值净购电 479.0 MW（F1）
- 参考上界 = 基准轨迹（F2：1802.34 M 元 / 2045.36 kt / 497.0 MW）——**仅作参考并注明 D/E/F 违反 SOC(2406)≥Initial**（F3），不作公平对照

## 3. 数学框架

**索引**：区域 $r \in \{A,\dots,F\}$；时段 $t = 0,\dots,2405$（2406 为状态结算，$E_{2406}=E_{2405}$）。

**决策变量**（逐区域）：
- $G_t \ge 0$：购电功率（MW）；$S_t \ge 0$：卖电功率（MW）
- $D_t \ge 0$：放电功率（MW）
- $C_t = C_t^g + C_t^r \ge 0$：总充电功率 = 电网充电 + 新能源充电（MW）
- $R_t \ge 0$：新能源直供（MW）
- $E_t$：SOC（时段末状态，MWh），$E_{-1} = \mathrm{InitialSOC}$

**约束**：
1. 功率平衡：$G_t + R_t + D_t = \mathrm{Load}_t + C_t^g + S_t,\ \forall t$
2. 新能源上限：$R_t + C_t^r \le \mathrm{Avail}_t,\ \forall t$（弃电 = Avail − R − C^r ≥ 0 隐含）
3. SOC 递推：$E_t = E_{t-1} + \eta_c C_t - D_t/\eta_d,\ \forall t$
4. SOC 边界：$\mathrm{MinSOC} \le E_t \le \mathrm{Capacity}$；**终态硬约束 $E_{2406} \ge \mathrm{InitialSOC}$**（说明 5）
5. 充放功率：$0 \le C_t \le \mathrm{MaxCharge}$；$0 \le D_t \le \mathrm{MaxDischarge}$
6. 购售电边界：$0 \le G_t \le \mathrm{MaxGridImport}$；$0 \le S_t \le \mathrm{SellLimit}_r$（A/B/C 为 0）
7. 同时充放：由目标自动排除（$\eta_c \eta_d < 1$，同刻充放纯损耗），不显式约束（F4 支持）

**目标与碳约束**（分区域，逐区独立求解）：
$$\min \sum_{t=0}^{2405} \big( G_t \cdot \mathrm{Price}_t - S_t \cdot \mathrm{SellPrice}_t \big)$$
$$\text{s.t. } \sum_{t=0}^{2399} G_t \cdot \mathrm{CarbonIntensity}_t \;\le\; 10^3 \cdot \varepsilon \cdot \mathrm{CarbonBase}_r, \quad \varepsilon = 1.00\ \text{（主解；0.90/0.95 经实证全部区域不可行）}$$
其中 $\mathrm{CarbonBase}_r$ = 区域基准碳排（**主时域 0–2399 口径**，F2：A 581.27 / B 519.70 / C 483.82 / D 262.96 / E 84.56 / F 113.06 kt）；$10^3$ 为 kt→tCO$_2$ 单位换算。
> 碳约束时域口径定稿（阶段 1.5 审查项 #1，详见 math-sub3.tex §4）：约束域限主时域 0–2399，与分母 F2 基准同口径；结清段 2400–2405 购电仍计入成本、不设碳约束（其购电碳排≈0，A/B/C 无购电、D/E/F 净购电为负）。

> 决策点覆盖：D1→§2 A1；D2→A2（受限消纳 B1 定稿）；D3→A3；D4→ε=1.00 主解（D4 修订）；D5→A5；D6→A6。

## 4. 求解方法

- 求解器：scipy.optimize.linprog（HiGHS，method='highs'），与 S1/S2 生态一致；备选 scipy.optimize.milp 无需求（纯连续）
- 规模：每区域 ~7 变量 × 2406 时点 ≈ 1.7 万连续变量、~1 万约束 → **6 区域总 ~10 万变量，LP 秒级可解，无需启发式/分解**
- 求解策略：逐区独立（A7）→ 并行/顺序求解后聚合；ε 三档 × 6 区域 = 18 次 LP
- 时间口径：0–2405 全时域入模（A9），无滑窗
