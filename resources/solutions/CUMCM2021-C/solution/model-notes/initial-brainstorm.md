# 初始头脑风暴 — CUMCM 2021 C 题

## 问题本质

这是一个**带随机性的供应链订购-运输联合优化问题**，核心是「评价→选择→优化→提升」四步递进：

1. **评价**：402家供应商 → 量化重要性 → 筛选Top 50
2. **选择**：最少需要多少家保证生产？→ 粗选供应商集合
3. **优化**：24周订购方案（最经济）+ 转运方案（最低损耗）
4. **提升**：压缩成本（A↑C↓）+ 探产能天花板

## 方法选型思路

### 子问题1：供应商评价
- **首选**：熵权法 + TOPSIS（MS-024），客观赋权，无需专家打分
- **备选**：投影寻踪 + AGA（MS-029），适合高维指标降维
- 指标建议：供货量均值、供货稳定性（CV）、供货满足率、缺货频率、最大单周供货量、品类（one-hot）

### 子问题2：订购+转运
- **路线A**：分层求解 — 先贪心/DP选最少供应商，再LP做订购，再分配转运
- **路线B**：统一求解 — 双层随机规划（MS-030），上层运输损耗，下层订购成本
- **路线C**：GA统一 — 编码订购方案+转运方案，GA一次求解
- 前置步骤：必须按 MS-031 对供应商时间模式分类（K-S检验→泊松型 / 周期型 / 平稳型 / 突变型）

### 子问题3：多目标优化
- **方法**：多目标粒子群优化 MOPSO（MS-032）或加权转为单目标
- 三个目标：max A采购量、min C采购量、min 运输损耗率
- 需要设定A/B/C的消耗率换算关系，使目标可比

### 子问题4：产能提升
- **方法**：LP求最大可行产能（给定供应商+转运商约束）
- 或二分搜索 + 可行性检验

## 四种参考方案对比

| 维度 | D1 (GA主导) | D2 (双层随机) | D3 (贪心) | D4 (LP序列) |
|------|------------|-------------|----------|------------|
| 评价指标 | 6个 | 4个 | 9个(AHP修正) | 8个 |
| 评价方法 | 熵权+TOPSIS | 熵权+TOPSIS | 熵权+AHP | 投影寻踪+AGA |
| 最少供应商 | 39家 | 27家 | ~16家 | 24家 |
| 产能提升 | +1.58万m³ | +0.35万m³ | +1.51万m³ | +4.57万m³ |

## 待决策事项

1. 子问题1指标选择——哪些指标能真正反映「保障生产重要性」？
2. 是否对供应商做时间模式分类（K-S检验）？这将显著影响后续建模策略
3. 子问题2采用分层求解还是统一求解？
4. 子问题3多目标如何处理——Pareto前沿展示还是加权归一？
5. 是否需要对损耗率做分布拟合？
