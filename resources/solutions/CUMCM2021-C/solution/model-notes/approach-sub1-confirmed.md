# 方案确认书 — 子问题 1：供应商重要性评估与筛选

> 阶段 1.3 终版 | 2026-07-26 | 分支：experimentPCA | 方案：v4（5指标PCA）

## 最终方案

**PCA → 供应商重要性安全指数 I ∈ [0,1] → 排序取 Top 50**

经过 v1-v5 五轮迭代，最终选定 5 指标 PCA 方案（不引入品类 one-hot）。

## 指标体系（5 特征）

| 维度 | 指标 | 公式 | 含义 |
|------|------|------|------|
| 供货规模 | 供货总量 | Σ s_t | 240周总供货量 |
| 供货规模 | 供货周数 | Σ I[s_t > 0] | 有供货的周数 |
| 供货可靠性 | 供货满足率 | Σ I[s_t ≥ o_t] / Σ I[o_t > 0] | 企业订货时供够的比例 |
| 供货可靠性 | 供订CV差 | CV(supply_nz) - CV(order_nz) | 供比订更稳则为负 |
| 发展趋势 | 可靠性趋势 | fulfill(后半) - fulfill(前半) | 满足率在变好还是变坏 |

## PCA 结果

- Kaiser 保留 PC 数: m=2（累计方差 66.1%）
- PC1(46.0%): 规模+可靠性 — 供货周数(+0.59)、满足率(+0.55)、总量(+0.47)、供订CV差(+0.36)
- PC2(20.1%): 可靠性趋势 — 可靠性趋势(+0.99)、其他指标载荷 ≈ 0

## 不纳入指标（经 v1-v5 实验排除）

| 指标 | 排除理由 |
|------|---------|
| 品类 one-hot (A/B/C) | v2/v3/v5 验证：污染 PCA，导致品类偏好失衡 |
| 进步因子 (后半/前半供货量) | v1 验证：被需求波动污染，S374排#1异常 |
| 消耗率换算产能 | ρ=0.994，无信息增益 |
| 时间模式分类标签 | 需求驱动验证：突变/周期是企业订货策略而非供应商属性 |
