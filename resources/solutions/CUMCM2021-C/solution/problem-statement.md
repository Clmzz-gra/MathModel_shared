# 问题陈述 — CUMCM 2021 C 题

## 核心问题

某建筑装饰板材生产企业需制定 **24 周的原材料订购与转运计划**，在满足生产需求和库存约束的前提下，最小化采购与运输成本，并评估产能提升空间。

## 背景参数

| 参数 | 数值 |
|------|------|
| 年生产周数 | 48 周 |
| 计划周期 | 24 周 |
| 每周产能 | 2.82 万 m³ |
| A 类消耗率 | 0.6 m³ / m³ 产品 |
| B 类消耗率 | 0.66 m³ / m³ 产品 |
| C 类消耗率 | 0.72 m³ / m³ 产品 |
| A 采购单价 | C 的 120% |
| B 采购单价 | C 的 110% |
| 运输/仓储单位费用 | 三类相同 |
| 最低库存 | ≥ 2 周生产需求 |
| 转运商运力 | 6000 m³/周/家 |
| 供应商-转运商关系 | 一家供应商每周尽量由一家转运商运输 |

## 子问题拆解

### 子问题 1：供应商重要性评估与筛选
- 对 402 家供应商的供货特征（订货量 vs 供货量、供货稳定性、品类分布）进行量化分析
- 建立反映「保障企业生产重要性」的数学模型
- 筛选出 **50 家最重要的供应商**，列表给出结果

### 子问题 2：最小供应商数 + 最优订购与转运方案
- 确定满足生产需求的最少供应商数量
- 制定未来 24 周最经济的原材料订购方案
- 制定损耗最少的转运方案
- 分析订购方案和转运方案的实施效果

### 子问题 3：成本压缩 — 多目标优化
- 目标 1：尽量多采购 A 类原材料
- 目标 2：尽量少采购 C 类原材料
- 目标 3：转运损耗率尽量少
- 制定新的订购方案和转运方案，并分析实施效果

### 子问题 4：产能提升评估
- 基于现有供应商和转运商条件，评估每周产能可提高多少
- 给出该产能下的 24 周订购和转运方案

## 要求产出

1. 论文（含问题 1 的 Top 50 供应商列表）
2. 附件 A — 问题 2、3、4 的订购方案数值结果
3. 附件 B — 问题 2、3、4 的转运方案数值结果

## 显式约束

- 供应商实际供货量可能多于或少于订货量
- 企业全部收购供应商实际提供的原材料
- 一家供应商每周尽量由一家转运商运输
- 损耗率 = (供货量 - 接收量) / 供货量 × 100%

## 隐含约束

- 供应商供货具有不确定性，需考虑供货稳定性/可靠性
- 不同品类原材料之间可能存在替代关系（产能消耗率不同）
- 订购方案需考虑库存缓冲
- 转运商选择影响实际到货量
