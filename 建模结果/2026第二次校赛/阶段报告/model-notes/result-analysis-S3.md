## 一、待裁定项裁决（handoff §四）

### 1. Platt 符号约定（规格错误）— **已修正三处规格，代码无需修改**

- **裁决**：采纳修正。`math-S3.tex §7.2/§7.3`、`approach-S3-confirmed.md §4.4`、`handoff-S3-code-agent.md §2.6` 三处规格的「A>0 单调递增 / 校验 A>0」为**规格符号错误**——在公式 $P_{\text{cal}}=1/(1+\exp(A\cdot f+B))$ 下，$A<0$ 才使 $P_{\text{cal}}$ 关于 $f$ 严格单调递增（$\frac{dP}{df}=-\frac{A\exp(Af+B)}{(1+\exp(Af+B))^2}>0 \iff A<0$）。
- **代码已正确**：实现按 sklearn 形式 $P=1/(1+\exp(-(w\cdot f+b)))$，故 $A=-w,\ B=-b$，单调性校验 $w>0$（等价 $A<0$），pkl `meta.note` 与 `field_semantics` 已显式标注「口径修正」。
- **落地**：三处规格文档已实际修改（`A>0 → A<0`，校验异常条件 `A≤0 → A≥0`），math-S3.tex 重新编译通过（11 页）。**代码无需修改**。
- **pkl 佐证**：`D_calibrated.<C>.A` 三组合均为负（C1 −13.10 / C2 −21.85 / C3 −18.56），`platt_w` 均为正（13.10 / 21.85 / 18.56），与「A<0、w>0」一致。

### 2. 域内 AUC 口径 — **采用 264 特征口径**

- **裁决**：采用 264 特征重算的域内 AUC（`domain_auc`：CRC 0.7811 / IBD 0.8588 / Obesity 0.6638），与跨疾病 264 特征「同口径对比」更严谨。A3 的 1331 特征参考值（`domain_auc_reference_A3`：0.814 / 0.885 / 0.644）保留在 pkl 供对照，不作为衰减归因主口径。
- **理由**：衰减量 $\Delta_d = \text{AUC}_{\text{cross}} - \text{AUC}_{\text{domain}}$ 要求分子分母同特征口径，否则衰减量混入特征集差异（1331 vs 264），归因失真。

### 3. R2 样本合并 ≡ 策略 A（规格冗余）— **登记为规格冗余**

- **裁决**：登记为规格冗余。LODO 协议本身已合并 2 训练疾病，R2「样本合并通用模型」与策略 A 数学恒等（pkl `R2_pooled.mean_auc` = `A_direct.mean_auc` = 0.5603，逐组合 AUC 完全一致），回退链中 R2 无法提供增量。代码忠实实现（注释「≡策略 A 口径」）。R2 保留在回退链中作完整性记录，不产生独立结论。

### 4. R3 密度比估计方法 — **确认接受域分类器法**

- **裁决**：确认接受域分类器法（Logistic 区分 train/test，$w=\exp(\text{logit})\times n_{\text{train}}/n_{\text{test}}$，裁剪上界 10）。math-S3.tex §9.3 写「KLIEP 或 uLSIF」为代理值（`proxy-replacement-checklist-S3.md` #3 标注「方法未定」），实现选择域分类器法属方法选择而非硬矛盾。**需在规格中登记方法落地**（见 §五 未闭合清单 #4）。

### 5. pkl 结构命名 — **按实际键名取数**

- **裁决**：按实际键名取数——策略 C 拆为 `C_genus`/`C_phylum` 两键（各含 `level`/`n_features`），顶层 `best_strategy = R3_weighted`（最优可达，非交付），`strategy_compare.best_strategy = A_direct`（策略对比内 base 最优）。信息未丢失，字段语义差异登记为规格冗余。

## 二、结果解读

### 2.1 四策略对比（正式建模核心交付）

| 策略 | 构建方式 | C1(CRC) | C2(IBD) | C3(Obesity) | 3 组合 AUC 均值 |
|---|---|---|---|---|---|
| A 直接迁移 | L2+CLR 物种级 264 | 0.5674 | 0.5882 | 0.5253 | **0.5603** |
| B 共享标志物 | 252 特征交集重训 | 0.5417 | 0.6080 | 0.5218 | 0.5572 |
| C 属级聚合 | g__ 求和 106 特征 | 0.3616 | 0.4861 | 0.5440 | 0.4639 |
| C 门级聚合 | p__ 求和 11 特征 | 0.4141 | 0.5261 | 0.5999 | 0.5134 |
| D 部署校正 | Platt 校准（base=A） | 0.5674 | 0.5882 | 0.5253 | 0.5603（AUC 不变） |

- **四策略 3 组合 AUC 均值全部 < 0.60**（A 0.5603 / B 0.5572 / C属 0.4639 / C门 0.5134 / D 0.5603）→ **触发紧急回退**（pkl `fallback.triggered = True`）。
- **策略 A 基线**：0.5603 接近随机线（0.5），跨疾病直接迁移基本失败。
- **策略 B 共享标志物**：0.5572 与 A 几乎持平（−0.003），共享物种的**存在性**不承载可迁移信号（支持 H3 前半）。
- **策略 C 分类学聚合**：属级 0.4639 / 门级 0.5134，**聚合不提升反略降**（属级甚至低于随机），印证「求和抹平物种级方向信息」（H5 证伪成立，如实报告）。
- **策略 D 部署校正**：AUC 与 base 完全一致（0.5603，Platt 单调变换不改排序），只影响可部署指标。

### 2.2 紧急回退结果（R1-R4）

| 回退层级 | 模型族 | 3 组合 AUC 均值 | 达可用线？ |
|---|---|---|---|
| R1 树模型 | RandomForest 500 树 | 0.5092 | 否 |
| R2 样本合并 | Logistic（≡策略 A 口径） | 0.5603 | 否 |
| R3 密度比重加权 | importance weighting（域分类器法） | **0.6068** | 否（<0.65，提升 +0.0465 <0.10） |
| R4 对抗式域适应 | DANN（梯度反转） | 0.5947 | 否 |

- **穷尽出口**：R1-R4 全部未达可用线（均值 ≥0.65 或相对 A 提升 ≥0.10）。`fallback.usable = False`，`delivered_strategy = None`。
- **最优可达性能**：`exhausted_evidence.best_strategy = R3_weighted`，`best_mean_auc = 0.6068`，`usable_line = 0.65`。R3 相对 A 提升 +0.0465，是唯一接近可用线的候选，但未达交付标准。
- **结论**：在现有数据与协议下，跨疾病预测模型最优可达 AUC 0.6068（R3_weighted），低于可用线 0.65；负结果是回退流程验证后的最终结论。

### 2.3 衰减归因（三分法，264 特征域内口径）

| 疾病 | 域内 AUC | 跨疾病 AUC | 衰减量 | 主导归因 |
|---|---|---|---|---|
| CRC | 0.7811 | 0.5674 | −0.2138 | 疾病特异信号 |
| IBD | 0.8588 | 0.5882 | **−0.2706** | 疾病特异信号（最强） |
| Obesity | 0.6638 | 0.5253 | −0.1384 | 标签语义漂移 |

- **IBD 衰减最大（−0.271）**：域内最强（0.8588）却跨疾病塌缩最狠，说明模型学的是 IBD 特有标志物，对新疾病不适用——疾病特异信号主导。
- **Obesity 归因标签语义漂移**：域内最弱（0.6638），跨疾病 0.5253，衰减 −0.138，叠加 C3 阈值漂移（见 2.5）。
- **批次效应不主导**：A 类验证 silhouette 0.070 近 0（approach §4.5），不引入 ComBat 批次校正。

### 2.4 深度迁移分析（共享物种方向一致性）

- 方向一致（可迁移）**387** / 方向翻转（疾病特异）**369**，`n_valid = 756`，一致占比 **51.2%**（`consistent_fraction = 0.5119`），符号检验 **p = 0.5364**（不显著）。
- **结论**：共享物种的「患病↑/↓」方向跨疾病**接近随机**（≈50/50），即共享物种的**存在性**不承载可迁移信号，信号藏在**疾病特异方向**里（支持 H3）。方向一致性分析配符号检验，不裸报描述统计（approach §5.7 约束满足）。

### 2.5 C3 阈值漂移量化（H4 证伪）

- 训练患病基线 **0.3160** vs 测试 **0.6482**，基线差 **Δ = +0.3322**。
- Youden 阈值 **τ\* = 0.9205** 落在测试分数分布的 **96.0% 分位**（`boundary_position = 0.9605`，96.0% 测试样本被判健康），灵敏度 **0.0244**（几乎全判健康）。
- **诊断**：标签语义漂移（决策边界跨疾病失准），AUC 接近随机（0.5253）而可部署指标崩溃。
- **H4 证伪**：Platt 校准是单调变换，Youden 阈值迁移后决策边界不变，故 C3 灵敏度校准前后一致（0.0244）；即使改用 0.5 概率阈值，灵敏度仅 0.1646（`thr05_sensitivity`，仍差）。**结论：C3 阈值漂移是测试分布基线偏移，训练集拟合的单调校准无法修复**——H4「概率校准能修复 C3 可部署指标」被证伪，如实报告。

#### 2.6.3 归因收束（论文表述口径）

六轮实验依次排除「批次效应、模型容量、模型族/稀疏先验、评估协议过严、模型组合方式、深度学习表示能力」六类替代解释后，跨疾病 AUC ≈ 0.56~0.60 的失败收敛为**数据固有限制：疾病特异信号不迁移 + 标签语义漂移**，与 2.3/2.4/2.5 三分法归因自洽，证据链闭环：

- **统一跨疾病泛化不成立**：非单一实验偶然，而是六层独立检验共同支撑的最终结论；
- **泛化失败方向不对称**：C1(CRC) 存在弱可迁移信号（few-shot 0.6567、MLP 0.6852），C2/C3 不可学/语义漂移——**不可表述为「三种疾病之间绝对无任何可迁移信息」**；
- **论文表述口径**：以「最优可达（R3 0.6068）+ 完整证据链（E0–E6）」交付，未交付可用模型；改进方向 = 更大规模多疾病数据 / 目标疾病定向迁移（CRC 方向受益）/ 标签定义对齐（统一患病标准）。

## 四、实际落地检查（两条必答题）

1. **输入鲁棒性**：核心输入为物种级相对丰度（成分数据），CLR 零值替换 δ=6.5e-6 为固定常数（S1 口径），StandardScaler 均值/方差仅训练集估计——结论对特征集口径（264 vs 1331）敏感（域内 AUC 略降），但对 δ 与正则化强度不敏感（A 类验证已覆盖）。**结论对「特征集口径」敏感，报告需声明 264 特征口径**。
