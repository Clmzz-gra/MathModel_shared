## 3. 待裁定项裁决（handoff §5）

### 3.1 过拟合判定：采用「CV vs LOOCV」口径，判定**无过拟合**

- **pkl 事实**：三数据集 `full_AUC` 均为 1.000（样本内），`overfit_delta = full_AUC - LOOCV_AUC` = 0.1958 / 0.1252 / 0.3730，全部 >0.1，`overfit_flag=True`。
- **裁决**：`full_AUC=1.0` 是 **n≪p 的必然现象**（264 特征 vs 110-253 样本，样本内线性可分），非模型缺陷。**更诚实的判定口径**：5 折 CV AUC vs LOOCV AUC 差距 = 0.0135 / 0.0123 / 0.0226，全部 <0.025，**模型稳定无过拟合**。
- **处置**：结果分析正文与报告采用「CV vs LOOCV」口径，并**显式说明 full_AUC=1.0 的 n≪p 背景**（样本内自评是乐观上界，不反映泛化）。`overfit_flag=True` 字段保留为原始判定留痕，但正文以 CV vs LOOCV 为准。

### 3.2 Chatelier RF 少数类 F1/Recall 极低（0.0944/0.0562）：按规格执行，AUC 为诚实指标

- **pkl 事实**：Chatelier RF F1_minority=0.0944、Recall_minority=0.0562；混淆矩阵 [[5,84],[6,158]]（少数类=健康，几乎全预测多数类 obesity）。
- **裁决**：RF 无 class_weight（handoff §1.4 规格），默认阈值 0.5 对不平衡数据（少数类 35.2%）次优，RF 几乎全预测多数类。**AUC 0.6602 是阈值无关的诚实指标**，反映真实判别力；F1/Recall 低是「无 class_weight + 默认阈值」的已知局限，非模型失效。
- **处置**：按规格执行，不补充 class_weight/调阈值（handoff 未要求，且 metahit 的 B3 已验证 class_weight 仅提升 Recall 不提升 AUC）。报告正文以 AUC 为主指标，F1/Recall 标注「RF 无 class_weight 局限」口径声明。**不将 RF 的 F1/Recall 作为性能结论**。

### 3.3 small_adenoma 主口径：推荐维持①（归健康），③（剔除）作为敏感性附录

- **pkl 事实**（`adenoma_sensitivity` 字段）：

| 口径 | L2 AUC | RF AUC | n | 说明 |
|:--|:--:|:--:|:--:|:--|
| ① 归健康（默认主口径） | 0.7907 | 0.8454 | 121 | 题面主口径 |
| ② 归病变 | 0.6112 | 0.6509 | 121 | ⚠️ 明显更差（small_adenoma 混入病变污染正类） |
| ③ 剔除 | 0.8022 | 0.8667 | 95 | 略优于①（ΔL2 +0.0115 / ΔRF +0.0213） |
| ④ 单开一类 | 0.8022 | 0.8667 | 95 | 二分类部分同③（26 例单独第三类） |

- **裁决**：口径②（归病变）显著劣化（L2 AUC 掉 0.18），**排除**。口径③/④（剔除）略优于①，但 **ΔAUC < 0.05 不显著**（与 A 类 F6 一致），且③/④样本量减至 95（剔除 26 例 small_adenoma）。
- **推荐**：**维持①（归健康）为主口径**——①是题面主口径、样本量最大（121）、可解释性最直接（small_adenoma 是癌前病变，归健康符合「患病 vs 健康」的临床二分）；③/④ 作为敏感性分析入附录，展示剔除后 AUC 略升但不改变主结论。`selected_main_caliber='healthy'` 已落盘，与推荐一致。
- **权衡说明**：若追求最高 AUC 可改③，但 Δ<0.05 无统计意义，且损失 26 样本，不划算；按可解释性选①。

## 4. 跨疾病差异四重归因

| 来源 | 判定依据（pkl/approach） | 结论 |
|:--|:--|:--|
| **样本量** | n=121/110/253；AUC_std：Zeller L2 0.1022（最大）、metahit 0.0708、Chatelier 0.0718 | 小样本 AUC 方差大（Zeller 5 折 fold AUC 0.593-0.864），跨疾病差异部分落在噪声内，不直接断言 |
| **类别平衡** | 少数类比例 39.7%/22.7%/35.2%（approach §4.2）；metahit ACC 0.8636 vs Recall 0.64（L2）、ACC 0.8182 vs Recall 0.24（RF） | metahit 最不平衡，ACC 虚高，AUC 才可比；RF 无 class_weight 时少数类 Recall 崩塌（0.24） |
| **信号强度** | 单特征基线 AUC 0.7581/0.8153/0.6395；增益 L2 +0.0326/+0.0718/+0.0101 | Chatelier 信号最弱，接近领域下界 0.65-0.75；metahit 信号最强 |
| **批次效应** | F8 聚类由 dataset 主导，14 离群样本独立成簇 | 三数据集不可直接横向比绝对 AUC，只比「相对基线的增益」 |

**收束**：三数据集性能差异主要由**信号强度**（metahit 最强、Chatelier 最弱）与**类别平衡**（metahit 最不平衡导致 RF 少数类 Recall 崩塌）主导，样本量贡献方差噪声，批次效应限制绝对 AUC 横向可比性。
