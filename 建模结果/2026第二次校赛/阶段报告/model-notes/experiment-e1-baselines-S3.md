# S3 补充实验 E1：免训练/低容量基线（NCM + PLS-DA）跨疾病 LODO

> 阶段：S3 补充实验（归因检验）| 日期：2026-08-21 | 角色：代码对话（S3）
> 数据接口：`outputs/data/S3-preprocessed.pkl`（复用，与 S3 正式实现同口径）
> 脚本：`outputs/scratch/S3-e1-baselines.py` | 产物：`outputs/data/S3-e1-baselines.pkl`
> 目的：检验「跨疾病 AUC 天花板（~0.56）是否与模型容量无关」——若免训练/低容量方法也 ≈0.56，
> 坐实数据固有限制（疾病特异信号 + 标签语义漂移），而非模型容量不足。

---

## 一、实验目的

S3 正式实现测得策略 A 直接迁移 3 组合 LODO AUC 均值 **0.5603**（近随机），回退 R3 密度比重加权
**0.6068**、R4 对抗式域适应 **0.5947**（均未达可用线 0.65）。一个待排除的替代解释是：**这些方法
容量不足（欠拟合）**，换更大容量模型可能突破天花板。本实验用**免训练**（NCM，仅 2 个类均值原型，
无任何迭代训练）与**低容量**（PLS-DA，线性潜变量）方法做对照：若它们也落在 0.53~0.58 的近随机
区间，则「近随机天花板」与模型容量无关，是数据固有限制。

## 二、方法

1. **数据准备**：复用 `S3-preprocessed.pkl` 的 `X_filtered`（484×264 过滤后物种级原始丰度，
   与 S3 正式实现同口径，避免重解析原始 Excel）→ CLR 变换（δ=6.5e-6 乘法替换 + 逐样本几何
   均值中心化）→ 得 `X_clr`（484×264）。
2. **NCM（最近类均值原型，免训练）**：每类原型 = 训练集该类样本的 CLR 空间均值向量
   μ_pos（患病）/ μ_neg（健康），仅 2×264 个「参数」（类均值），无迭代训练。测试样本按距离
   归最近原型，判别分数为连续量：
   - 欧氏距离：score = ‖x−μ_neg‖ − ‖x−μ_pos‖（越大越接近患病原型）
   - 余弦距离：score = cos(x,μ_pos) − cos(x,μ_neg)（越大越相似于患病原型）
   score 直接算 AUC（阈值无关）。「阈值 0.5」等价于 softmax 概率
   P(患病|x)=exp(−d_pos)/(exp(−d_pos)+exp(−d_neg)) 的 0.5 决策边界（即 d_pos=d_neg，最近原型），
   与 score=0 同界，AUC 不依赖该阈值。
3. **PLS-DA（低容量）**：sklearn `PLSRegression` 对二分类标签 y∈{0,1} 回归，预测连续分数作
   判别分数。n_components 用内层 5 折分层 CV（仅训练集，候选 2~10）按 AUC 选最优，再全训练集
   重拟合预测测试集；另报固定 n_components=5 作敏感性对照。StandardScaler 仅训练集 fit
   （与 S3 正式实现同口径，防泄漏），`PLSRegression(scale=False)` 避免双重标准化。
4. **LODO 协议**：与 S3 正式实现同口径——3 组合（C1 测 CRC / C2 测 IBD / C3 测 Obesity），
   测试疾病训练阶段完全不可见（标签与特征均不参与训练）。

## 三、结果

### 3.1 NCM / PLS-DA 3 组合 LODO AUC

| 组合 | 测试疾病 | NCM 欧氏 | NCM 余弦 | PLS-DA（内层CV） | PLS-DA（固定5） |
|:--|:--|:--|:--|:--|:--|
| C1 | CRC | 0.5068 | 0.4926 | 0.6099 | 0.5654 |
| C2 | IBD | 0.4856 | 0.5581 | 0.5478 | 0.5699 |
| C3 | Obesity | 0.6161 | 0.6276 | 0.5817 | 0.5369 |
| **均值** | — | **0.5362** | **0.5594** | **0.5798** | **0.5574** |

> PLS-DA 内层 CV 选出的 n_components：C1=2、C2=3、C3=2。

### 3.2 PLS-DA 内层 CV AUC vs 测试 AUC（域内强、跨疾病塌缩的直接证据）

| 组合 | 内层 CV AUC（仅训练集） | 测试 AUC | 塌缩量 |
|:--|:--|:--|:--|
| C1 | 0.7239 | 0.6099 | −0.1140 |
| C2 | 0.7453 | 0.5478 | −0.1975 |
| C3 | 0.8075 | 0.5817 | −0.2258 |

> 内层 CV 在训练疾病上能学到较强信号（0.72~0.81），但迁移到新疾病时塌缩到 0.55~0.61，
> 与 S3 正式实现的衰减归因（域内 0.78~0.86 → 跨疾病 0.53~0.59）完全一致。

### 3.3 与现有基线对比（3 组合 AUC 均值）

| 方法 | 容量 | 3 组合 AUC 均值 |
|:--|:--|:--|
| NCM 欧氏 | 免训练（2 原型） | 0.5362 |
| NCM 余弦 | 免训练（2 原型） | 0.5594 |
| PLS-DA（固定5） | 低容量（线性潜变量） | 0.5574 |
| **A 直接迁移** | Logistic L2（264 参数） | **0.5603** |
| PLS-DA（内层CV） | 低容量（线性潜变量） | 0.5798 |
| R4 DANN | 高容量（对抗式域适应） | 0.5947 |
| R3 加权 | 中容量（密度比重加权） | 0.6068 |

## 四、结论

**跨疾病 AUC 天花板（~0.56）与模型容量无关，数据固有限制为真。**

1. **免训练 NCM 与低容量 PLS-DA 均落在近随机区间**：NCM 欧氏 0.5362、NCM 余弦 0.5594、
   PLS-DA 固定5 0.5574，与策略 A 直接迁移 0.5603 同量级（0.53~0.58）。NCM 仅用 2 个类均值
   原型、零迭代训练，其性能与 264 参数的 Logistic 几乎无差——说明**增加模型容量不带来跨疾病
   增益**，天花板不是欠拟合所致。
2. **容量提升的边际收益极小且远低于可用线**：从免训练 NCM（0.5362）到高容量 R4 DANN（0.5947），
   容量跨越「零参数 → 线性 → 非线性 → 对抗式域适应」四个量级，AUC 均值仅从 0.536 抬到 0.595
   （+0.06），仍远低于可用线 0.65。若天花板是容量问题，容量提升应带来显著增益；实际增益微弱，
   印证瓶颈在数据本身。
3. **PLS-DA 内层 CV 与测试 AUC 的巨大落差（0.72~0.81 → 0.55~0.61）是疾病特异信号的直接证据**：
   模型在训练疾病上能学到强信号，但该信号不迁移到新疾病——与 S3 正式实现的衰减归因
   （疾病特异信号 + 标签语义漂移）完全一致，进一步坐实「数据固有限制」而非「模型欠拟合」。

## 五、下一步

- 本实验为**归因检验**，结论并入 S3 正式报告的归因分析（三分法），不改变四策略对比与紧急回退
  协议的主结论。
- 免训练/低容量基线**不采纳**为正式产物（性能不优于策略 A）；`S3-e1-baselines.pkl` 仅作
  「天花板与容量无关」的证据留存。
- 归因链已闭环：批次效应（ComBat 实验证伪）→ 疾病特异信号（本实验 + 衰减归因）→ 标签语义漂移
  （C3 阈值漂移量化）。S3 的负结果（最优可达 AUC 0.6068，R3 加权）是经回退流程验证后的最终结论。
