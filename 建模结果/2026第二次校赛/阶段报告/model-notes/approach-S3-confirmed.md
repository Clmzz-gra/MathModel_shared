## 0. 一句话收束（先给结论）

**S3 解决的是「模型到新疾病上还灵不灵」——正面回答是「建立跨疾病预测模型」：正式构建并对比四种跨疾病建模策略，选出最优者作为交付模型；若全部策略性能不达标（AUC 均值 < 0.60），触发紧急回退重新选模型，直至交付可用模型或穷尽候选后以完整证据链报告。** 归因分析（为什么差）是性能探讨的组成部分，不是替代「建立模型」的答案。

## 1. 最终方案

### 1.1 主框架：正式构建并对比四种跨疾病建模策略 + 紧急回退协议（2026-08-21 人类裁定重构）

**题面 S3 的硬交付是「建立一个跨疾病预测模型」**——A 类验证已给出直接迁移基线（AUC 均值 0.556 近随机），但**负结果不是合法终点**（人类裁定：若所有策略都不好用则紧急回退重新选模型）。因此主框架为：

1. **四策略正式建模对比**（§1.2-1.5）：四种跨疾病预测模型的构建方式，全部按正式建模规格实现（非诊断实验），3 组合 LODO 下对比 AUC，**选出最优策略作为交付模型**。
2. **紧急回退协议**（§1.6）：若四策略 AUC 均值均 < 0.60（接近随机线）→ 触发回退，重新选模型族（候选清单见 §1.6），直至交付可用模型或穷尽候选。
3. **性能探讨**（题面第二部分）：策略对比 AUC 表 + 最优策略性能水平 + 适用条件 + 局限；归因分析（三分法：批次效应 / 疾病特异信号 / 标签语义漂移）作为「为什么差」的解释层。
4. **深度迁移分析**：回答「什么在迁移、什么不迁移」——对三数据集共享的物种（A 类验证在 1331 全集上测得 344 个；正式实现基于过滤后 264 特征集重算），逐个检查其**跨疾病方向一致性**（在训练疾病里「患病↑」的标志物，到测试疾病里是否仍「患病↑」），把共享标志物分成「方向一致（可迁移信号）」与「方向翻转（疾病特异信号）」两类，量化占比。
5. **C3 阈值漂移量化**：把 A 类验证的「灵敏度 0.006」展开成完整诊断——训练集与测试集的患病概率基线差多少、Youden 阈值迁移后决策边界落在测试集分布的哪个位置、为什么 AUC 接近随机（0.556，统一表述见 B4 裁定）而可部署指标崩溃。

### 1.2 策略 A：直接迁移（S1 风格 Logistic L2 + CLR）

沿用 S1 已验证的模型口径，做 3 组合 leave-one-disease-out（协议定义见 §4.1）：

- **模型**：正则化 Logistic 回归（L2 惩罚），CLR 前置（成分数据强制），**近全零过滤后物种级特征（零值占比>95% 剔除，1331→264，三病并集统一口径，与 S1/S2 一致）**。
- **定位**：策略对比的**基线**（A 类已实测 AUC 均值 0.556）。
- **主评估**：AUC（阈值无关，最诚实）。
- **辅评估**：训练集 Youden J 最优阈值迁移下的 ACC / 灵敏度 / 特异度 / F1（标注测试集类别不平衡）。
- **硬约束**：**禁止在测试集上重定阈值**（会用到新疾病标签，造成评估泄漏）。

### 1.3 策略 B：跨疾病通用模型（共享标志物特征子集）

取三数据集共享的物种（A 类验证在 1331 全集上测得 344 个；**正式实现基于近全零过滤后的 264 特征集重算共享交集**，数量可能略减）作为特征子集，在训练疾病上重新训练 Logistic(L2)+CLR 模型。**定位：正式策略**（不是诊断实验）——「疾病无关特征上的通用患病模型」：

- **转导式边界显式声明（B5 裁定）**：特征交集仅使用**特征存在性**（哪些物种在三数据集中都出现），**绝不用测试集标签**；与 R3 重加权的转导式边界声明保持同一口径（用测试集特征、绝不用测试集标签）。
- 若共享子集 AUC 显著高于全特征 → 全特征里的疾病特异噪声在拖后腿，通用模型可用。
- 若共享子集 AUC 仍近随机 → 共享物种的存在性不承载可迁移信号（信号藏在方向里），记录并计入回退评估。

### 1.4 策略 C：分类学聚合模型（属级/门级 + CLR，回应题面注 2）

利用分类学层级信息（题面注 2「可利用微生物的分类学信息」），将物种级特征聚合到**属级/门级**（聚合后维度大幅下降）再训练 Logistic(L2)+CLR。**定位：正式策略**：

- A 类验证 A4 已实测：物种 0.556 → 属 0.539 → 门 0.528（聚合不提升反略降）——正式实现仍按正式策略完整跑 3 组合，**如实报告聚合不提升**（回答注 2：分类学信息已利用，实证无增益），该策略作为「利用分类学信息」的显式交付。

### 1.5 策略 D：部署校正模型（最优策略 + 概率校准 + 阈值迁移）

针对 A 类验证 F6（C3 阈值迁移灵敏度 0.006）这一**已被量化**的独立失败模式，在策略 A/B/C 中 AUC 最优者上叠加 Platt 缩放，把模型原始分数映射到校准概率，再迁移 Youden 阈值。**校准参数仅从训练集估计**（严格防泄漏）。**定位：正式策略（部署形态）**——目标**不是改 AUC**（AUC 阈值无关，校准不改变排序），而是修复可部署指标（ACC/F1/灵敏度），作为「跨疾病模型能否实际部署」的正面回答。

### 1.6 紧急回退协议（2026-08-21 人类裁定：所有策略都不好用则重新选模型）

**触发条件**：策略 A/B/C/D 的 3 组合 AUC 均值**全部 < 0.60**（接近随机线，modeling-decision-tree 基准 <0.60 接近随机）→ 触发紧急回退。

**回退流程**（负结果不是终点，逐级尝试候选模型族，直至交付可用模型或穷尽）：

| 回退层级 | 候选模型族 | 思路 | 防泄漏约束 |
|:--|:--|:--|:--|
| R1 | **树模型族**（Random Forest / XGBoost，物种级过滤后特征） | S1 域内实测 RF 略优于 L2（Zeller 0.846 vs 0.812，A 类验证值，正式值 0.7907），树模型对零值/非线性鲁棒，跨疾病表现可能不同 | 特征选择在训练折内；超参仅训练集 |
| R2 | **样本合并通用模型**（2 训练疾病样本合并训练「患病 vs 健康」通用分类器） | 消除训练疾病间的标签差异，学「通用生病信号」而非疾病特异信号 | 测试疾病样本完全不可见 |
| R3 | **密度比重加权域适应**（importance weighting） | 针对标签语义漂移（C3 灵敏度 0.006），给训练样本加权匹配测试分布 | 转导式边界显式声明（用测试集特征、绝不用测试集标签） |
| R4 | **对抗式域适应**（DANN 思想，最后手段） | 小样本过拟合风险最高，仅在 R1-R3 全败且时间允许时尝试 | 严格验证集防泄漏 |

**可用判定标准**：回退候选 3 组合 AUC 均值 ≥ 0.65（超过 Obesity 域内地板 0.644，即「跨疾病不劣于最弱疾病的域内表现」）或相对策略 A 基线提升 ≥ 0.10 → 判定可用，作为交付模型。

**穷尽出口**：R1-R4 全部不达标 → 报告最优策略 + **完整失败证据链**（策略对比表 + 衰减归因 + 迁移模式 + 阈值漂移），结论句式：「在现有数据与协议下，跨疾病预测模型的最优可达性能为 AUC X（策略 Y），低于可用线 0.65；证据链表明主因是……，建议的部署方式是……」——**此时负结果才是经过回退流程验证后的最终结论**，而非默认起点。

**S3 无「主目标 + 次目标」问题，声明不适用。**

S3 的核心诉求是单一评估目标——「度量跨疾病预测性能」，不存在「最小面积 + 长宽比」这类需要二选一（ε-约束两阶段 / 软惩罚）的主次目标结构。AUC 是唯一主指标，辅指标（ACC/F1/灵敏/特异）是 AUC 的**分解视图**（同一评估的不同切面），不是独立的次目标，不写次目标量化结论。

## 4. 数学框架

> 本节所有符号首次出现均给定义与读法（math-explainer 约束 1）。

### 4.1 leave-one-disease-out（LODO）协议

**定义**：leave-one-disease-out（读作「留一疾病」，记作 LODO）——每次留一种疾病作测试集，其余两种疾病作训练集，共 3 个组合。这是「跨疾病」的诚实评估协议：测试疾病在训练阶段**完全不可见**（标签与特征均不参与训练）。

| 组合 | 训练集（2 疾病） | 测试集（1 疾病） | 测试集正类占比 |
|---|---|---|---|
| C1 | IBD（metahit）+ Obesity（Chatelier） | CRC（Zeller） | 40%（患病 48 / 健康 73） |
| C2 | CRC（Zeller）+ Obesity（Chatelier） | IBD（metahit） | 23%（患病 25 / 健康 85，少数类） |
| C3 | CRC（Zeller）+ IBD（metahit） | Obesity（Chatelier） | 65%（患病 164 / 健康 89，正类占多数） |

**直觉解释（类比）**：好比一个医生只见过「A 病和 B 病患者 vs 正常人」，现在要他判断「C 病患者是不是病人」——他学到的「像病人」的直觉能复用多少，就决定跨疾病预测成败。

### 4.2 AUC（主指标）

**定义**：AUC（读作「曲线下面积」，Area Under the ROC Curve）——ROC 曲线（横轴假阳性率、纵轴真阳性率）下方的面积，等价于「随机抽一个患者比随机抽一个健康人得分更高的概率」。取值范围 $[0,1]$，0.5 表示与抛硬币无异（随机），1.0 表示完美区分。

**为什么选 AUC 作主指标**：AUC **与阈值无关**——不需要决定「多高算患病」就能衡量区分能力，因此**不依赖阈值迁移假设**，是最诚实的跨疾病泛化度量。解读基准（modeling-decision-tree）：0.80-0.90 良好、0.70-0.80 尚可、0.60-0.70 差、<0.60 接近随机。

### 4.3 Youden J 阈值（辅指标阈值迁移）

**定义**：Youden J 统计量（读作「约登 J」）定义为灵敏度与特异度之和减 1：

$$J = \text{灵敏度} + \text{特异度} - 1 = \text{TPR} + \text{TNR} - 1$$

其中 TPR（真阳性率，读作「真阳性率」）= 患者中被正确判为患病的比例；TNR（真阴性率）= 健康人中被正确判为健康的比例。**Youden J 最优阈值** = 使 $J$ 最大的决策阈值 $\tau^*$。

**阈值迁移规则**：$\tau^*$ **只在训练集上估计**，然后原样搬到测试集，报告该阈值下的 ACC/灵敏度/特异度/F1。**禁止在测试集上重定阈值**——那会用到新疾病标签，造成评估泄漏，违背 LODO 的「新疾病不可见」语义。

**直觉解释**：Youden J 好比「既要抓得住病人、又要不冤枉健康人」的平衡点；把训练集上找到的这个平衡点搬到新疾病，看它还灵不灵——不灵（如 C3 灵敏度 0.006）就说明「患病概率的决策边界跨疾病不一致」。

### 4.4 Platt 校准（策略 D）

**定义**：Platt 缩放（读作「普拉特缩放」）把模型原始分数 $f(\mathbf{x})$ 通过一个单调 sigmoid 映射到校准概率：

$$P_{\text{cal}}(y=1 \mid \mathbf{x}) = \frac{1}{1 + \exp(A \cdot f(\mathbf{x}) + B)}$$

其中 $A, B$ 是两个标量参数，**只在训练集上**用 Logistic 回归拟合（把训练集的原始分数 $f(\mathbf{x})$ 当作唯一特征、真实标签当作目标）。$A$ 控制分数尺度的缩放，$B$ 控制概率基线的平移。

**为什么不改 AUC**：Platt 缩放是**单调递增**变换（$A<0$ 时），不改变样本的排序，因此 ROC 曲线与 AUC 完全不变。它修复的是「分数到概率的映射」——当训练集与测试集的患病概率基线不同（标签语义漂移）时，原始分数的阈值迁移会失准，校准后概率的阈值迁移更可靠。

**实现校验（B6 裁定）**：实现时显式校验 $A<0$——若拟合得 $A \geq 0$（排序反转异常），触发警告并检查训练过程（校准参数仅训练集估计）；$A<0$ 约束是「校准不改 AUC」成立的前提。

**直觉解释**：好比温度计刻度不准——Platt 校准是「重新标定刻度」，让「分数 0.7」在两个数据集上都对应「70% 患病概率」，但不会改变「谁比谁更可能患病」的排序。

### 4.5 三分法归因的操作化定义

**定义**：对每个低 AUC 组合，把失败归因到三个**互斥**来源，每个来源配一个可计算的定量证据：

| 来源 | 操作化定义 | 定量证据（A 类验证） |
|---|---|---|
| **批次效应** | 训练/测试来自不同研究/平台导致的分布偏移 | silhouette 系数（数据集标签）= **0.070**（近 0，不主导） |
| **疾病特异信号** | 模型学的是训练疾病特有标志物，对新疾病不适用 | 域内 AUC − 跨疾病 AUC 衰减量，IBD 最大 **−0.358**（域内最强却衰减最大） |
| **标签语义漂移** | 新疾病患病概率基线整体偏移，决策边界失准 | C3 训练阈值迁移灵敏度 **0.006**（A 类验证值，正式实现 0.024，几乎全判健康） |

**silhouette 系数**（读作「轮廓系数」）：衡量聚类分离度的指标，取值 $[-1,1]$，越接近 1 表示簇越清晰分离，越接近 0 表示簇重叠。数据集标签 silhouette 0.070 说明三数据集在低维空间**不清晰分簇**，即批次效应不主导全局结构。

**直觉解释**：三分法好比医生误诊的三个可能原因——「仪器不同」（批次效应）、「这病和那病根本不是一回事」（疾病特异信号）、「判断标准整体偏了」（标签语义漂移）。实验证明主要是后两个，不是仪器问题。

## 5. 求解方法

1. **预处理**（与 S1 同用 L2+CLR，但额外加 StandardScaler，防泄漏）：近全零过滤（1331→264，三病并集）→ CLR 变换（零值乘法替换 δ=0.65×检出限=6.5e-6）→ StandardScaler（均值/方差**仅训练集估计**）。
2. **策略 A（直接迁移）**：对每个 LODO 组合，用训练集拟合 `LogisticRegression(penalty='l2', C=1.0, class_weight='balanced', max_iter=2000)`，对测试集预测，报 AUC + 训练 Youden J 阈值迁移下的 ACC/灵敏/特异/F1。
3. **策略 B（共享标志物）**：过滤后 264 特征中取三病按特征名交集（不含测试标签→无泄漏），在训练疾病上重训策略 A 同款模型，重跑 LODO。
4. **策略 C（分类学聚合）**：物种级特征按 `g__`（属）/ `p__`（门）层级聚合（同属/同门丰度求和），CLR 后重训同款模型，重跑 LODO——如实报告聚合不提升（F4）。
5. **策略 D（部署校正）**：在 A/B/C 中 AUC 最优者上，训练集拟合 Platt 参数 $A,B$，对测试集分数校准，再迁移 Youden 阈值，报校准后辅指标（AUC 不变）。
6. **紧急回退**（若 A/B/C/D 均值均 < 0.60）：按 §1.6 逐级尝试 R1 树模型（RF/XGBoost）→ R2 样本合并通用模型 → R3 importance weighting → R4 对抗式域适应（最后手段），每级同协议评估，达可用线（均值 ≥0.65 或提升 ≥0.10）即交付。
7. **深度迁移分析**：对共享物种（过滤后重算），计算每个物种在训练疾病与测试疾病中的「患病 vs 健康」丰度变化方向，分「方向一致/方向翻转」两类，配符号检验/置换检验（不裸报描述统计）。
8. **C3 阈值漂移量化**：训练集 vs 测试集患病概率基线差 + Youden 阈值迁移后决策边界位置。

## 10. 方案讲解收束（正面回答：建立模型 + 回退兜底）

**直觉解释（日常语言，无公式无希腊字母）**：好比一个只见过「A 病和 B 病患者 vs 正常人」的医生，现在要他判断「C 病患者是不是病人」。S3 的正面回答不是「他判断不了」就完事，而是：**先认真尝试四种培养方案**（直接迁移、只用共有的菌、合并成大类、校准刻度），**对比哪种方案判断得最准，交付那个方案**；如果四种都不行，**换一批方法重新试**（决策树/合并样本/加权/对抗训练），直到拿出一个能用的判断工具，或把「为什么都试过还是不行」的完整证据链摆出来。这才是对「建立一个跨疾病预测模型」的完整回答——先尽力交付模型，失败证据链是穷尽努力后的最后结论，不是默认起点。
