## 1. 三个独立方案

> 三个方案由共享事实独立推导，互不预设对方结论；每个方案先给"它回答什么、怎么做、为什么"，再给优劣势。

### 方案 Alpha —— 接受负结果 + 失败原因三分法归因 + 深度迁移分析

**回答什么**：S3 的核心诉求是"评估跨疾病预测性能"（题面注1），而共享事实 F1 已给出答案——**性能差**。Alpha 不追求把 AUC 拉高，而是把"为什么差"变成可讨论、可交付的结论。

**怎么做**（三步）：
1. **三分法归因**（沿用决策树预置框架）：对每个低 AUC 组合，把失败归因到三个互斥来源——**批次效应**（训练/测试来自不同研究/平台）vs **疾病特异信号**（模型学的是 CRC/IBD 特有菌，对 Obesity 不适用）vs **标签语义漂移**（新疾病患病概率基线整体偏移）。用共享事实 F5（批次不主导）、F3（疾病特异信号强）、F6（C3 阈值漂移）分别给三个来源**定量证据**。
2. **深度迁移分析**（Alpha 的独特增量）：回答"什么在迁移、什么不迁移"——对三数据集共享的 344 个物种（F2），逐个检查其**跨疾病方向一致性**（在训练疾病里"患病↑"的标志物，到测试疾病里是否仍"患病↑"）；把共享标志物分成"方向一致（可迁移信号）"与"方向翻转（疾病特异信号）"两类，量化各自占比。
3. **C3 阈值漂移量化**：把 F6 的"灵敏度 0.006"展开成完整诊断——训练集与测试集的患病概率基线差多少、Youden 阈值迁移后决策边界落在测试集分布的哪个位置、为什么 AUC 尚可（0.56）而可部署指标崩溃。

**为什么**：因为负结果本身是合法交付物（题面注1 定义跨疾病预测用于评估泛化能力，性能差 + 原因分析 = 完整回答），强行提升 AUC 反而会引入泄漏或过度设计，违背"诚实评估"的题面本意。

**优劣势**：优势 = 完全诚实、无泄漏、可解释性最高、直接回答题面；劣势 = 不产出"一个能用的跨疾病模型"（但题面并未要求模型必须好用）。

### 方案 Beta —— 特征交集筛选（共享标志物训练）+ 概率校准

**回答什么**：共享事实 F2 说"共享信号充足"，但 F1 说"全特征迁移失败"——Beta 追问一个诊断性问题：**如果只用三数据集共享的标志物训练，共享信号本身能否迁移？** 同时用概率校准修复 F6 的阈值漂移。

**怎么做**（两步）：
1. **特征交集筛选**：取三数据集共享的 344 物种（或 125 属）作为特征子集，重跑 leave-one-disease-out。这是**诊断实验**而非性能赌博——若共享子集 AUC 仍近随机，则证明"共享信号本身不可迁移"（疾病特异信号藏在共享物种的**方向**里，而非共享物种的**存在**里）；若共享子集 AUC 显著高于全特征，则说明全特征里的疾病特异噪声在拖后腿。
2. **概率校准**（Platt 缩放 / 温度缩放）：校准参数**仅从训练集估计**（严格防泄漏），把模型输出的原始分数映射到校准后的概率，再迁移 Youden 阈值。目标不是改 AUC（AUC 阈值无关，校准不改变排序），而是修复 F6 的可部署指标（ACC/F1/灵敏度）。

**为什么**：因为 F2 与 F1 之间存在一个未解的矛盾——"共享信号充足"却"迁移失败"，Beta 用特征交集筛选把这个矛盾拆开；概率校准则针对 F6 这个**已被量化**的独立失败模式，是唯一有明确靶点的"改进"。

**优劣势**：优势 = 有明确诊断价值、概率校准靶点清晰、无泄漏（交集基于特征名、校准参数仅训练集）；劣势 = 不改变 AUC（校准不提升区分能力）、特征交集筛选可能只是"换个方式确认负结果"。

### 方案 Gamma —— 域适应尝试（重加权/对抗式，严格防泄漏）+ 诚实报告

**回答什么**：共享事实 F5 说"批次效应不主导全局结构"，但 Gamma 追问：**是否存在可被域适应方法利用的、局部的分布偏移？** 即使批次不主导，训练/测试的协变量分布仍可能不同，域适应试图校正这种偏移。

**怎么做**（两步，均严格防泄漏）：
1. **重加权（importance weighting / 协变量偏移校正）**：估计训练样本相对测试分布的权重（如用密度比估计），给训练样本加权后重训。**关键约束**：权重估计若借用测试集特征分布，须明确这是"转导式"设定（transductive，可用测试集特征但**绝不用测试集标签**），并在报告中显式声明这一边界。
2. **对抗式域适应（可选，小样本风险高）**：训练一个域判别器 + 特征提取器对抗，使特征对"来自哪个数据集"不敏感。**小样本风险**：484 样本分三队列，每队列仅 ~110-156 样本，对抗训练易过拟合，须严格正则化 + 报告失败即诚实报告。

**为什么**：因为域适应是"跨队列泛化"文献里的标准工具，即使 F5 显示批次不主导，仍有必要**用受控实验排除**"域适应能否救回一点性能"这一可能性，否则负结果结论会被质疑"没试过域适应"。

**优劣势**：优势 = 覆盖"域适应"这一文献标准手段、结论更完整（"试过且失败"比"没试"更有说服力）；劣势 = 泄漏风险最高（转导式边界易踩线）、小样本对抗训练过拟合风险大、实现成本最高、最可能"费力确认负结果"。

## 2. 攻击矩阵（4 维度交叉批评）

> 4 维度定义：**① 泄漏与评估有效性**（是否诚实、是否踩 leave-one-disease-out 的"新疾病不可见"红线）；**② 生物学可解释性与信号真实性**（结论能否被生物学解读、是否把技术伪影当信号）；**③ 统计稳健性与小样本风险**（方法在 484 样本/三队列下是否可靠）；**④ 交付价值与题面契合度**（能否回答"评估跨疾病预测性能"这一核心诉求）。

| 方案 | ① 泄漏与评估有效性 | ② 生物学可解释性 | ③ 统计稳健性/小样本 | ④ 交付价值/题面契合 |
|---|---|---|---|---|
| **Alpha** | ★★★ 无泄漏（纯分析，不碰测试集标签） | ★★★ 最高（方向一致性分析直接对应"疾病特异 vs 共享信号"） | ★★★ 稳健（分析性结论，不依赖小样本估计） | ★★★ 直接回答题面（负结果 + 归因 = 完整回答） |
| **Beta** | ★★☆ 无泄漏（交集基于特征名、校准仅训练集），但校准假设需声明 | ★★☆ 中（交集=共享信号，但校准是黑盒概率映射） | ★★☆ 中（校准参数小样本估计有方差） | ★★☆ 中（诊断价值高，但不改 AUC，交付"确认负结果"） |
| **Gamma** | ★☆☆ 泄漏风险最高（转导式边界易踩线，须显式声明） | ★☆☆ 低（重加权/对抗是黑盒，难生物学解读） | ★☆☆ 低（小样本对抗训练过拟合风险大） | ★★☆ 中（覆盖文献标准手段，但最可能费力确认负结果） |

**攻击要点（交叉批评）**：

- **攻击 Alpha**：Alpha 是"放弃治疗"——它不产出任何"能用的跨疾病模型"，若评审期待"一个模型 + 一个数字"，Alpha 会被读作"没做出来"。且"方向一致性分析"若只做描述性统计、不做显著性检验，可能把噪声当信号。
- **攻击 Beta**：Beta 的概率校准**不改变 AUC**（AUC 阈值无关），它修复的只是"可部署指标"，而题面主诉求是"预测性能"——若只报校准后的 ACC/F1 提升，有"用辅指标掩盖主指标失败"的嫌疑。特征交集筛选若共享子集 AUC 仍近随机，Beta 就退化成"换个方式确认负结果"，增量有限。
- **攻击 Gamma**：Gamma 的转导式设定（用测试集特征估权重）在 leave-one-disease-out 语义下是**灰色地带**——"新疾病不可见"到底指"标签不可见"还是"特征也不可见"？若踩线，整个评估失效。且 F5 已显示批次不主导，Gamma 的靶点（分布偏移）可能根本不存在，是"为用方法而用方法"。

## 3. 反驳（各方案对攻击的回应）

- **Alpha 反驳"放弃治疗"**：题面注1 的措辞是"评估其跨疾病预测性能"，**评估**是动词、**性能**是宾语——性能差是评估的**结果**，不是评估的**失败**。负结果 + 归因是题面明示的合法交付（problem-statement 隐含约束第 49 行："跨疾病预测大概率性能显著下降……需要合理的分析与讨论而非只报数字"）。"方向一致性分析"会配显著性检验（如符号检验/置换检验），不裸报描述统计。
- **Beta 反驳"辅指标掩盖主指标"**：Beta 从不主张"用校准后的 ACC 替代 AUC"——AUC 仍是主指标，校准只作为**对 F6 这一独立失败模式的诊断与修复**，两者并列报告、不混淆。特征交集筛选即使确认负结果，也**回答了 F2 与 F1 的矛盾**（共享信号充足却迁移失败 → 因为疾病特异信号藏在共享物种的方向里），这是有独立价值的诊断结论。
- **Gamma 反驳"为用方法而用方法"**：Gamma 的价值不在"救回性能"，而在**排除**——"试过域适应且失败"比"没试"更能堵住"你没试域适应"的质疑，让负结果结论更完整、更不可反驳。转导式边界会**显式声明**（用测试集特征、绝不用测试集标签），不踩线。

## 4. 改进与混合

> 三个方案不是互斥的，而是**分层**的：Alpha 是骨架（负结果 + 归因），Beta 是诊断增量（拆解 F2/F1 矛盾 + 修复 F6），Gamma 是排除性补充（堵质疑）。混合后形成"一个骨架 + 两个受控子实验"。

**混合方案（推荐形态）**：

1. **骨架 = Alpha**：接受负结果，三分法归因（批次/疾病特异/标签漂移，各配定量证据 F5/F3/F6），深度迁移分析（共享标志物方向一致性 + C3 阈值漂移量化）。
2. **子实验 1 = Beta 的特征交集筛选**（诊断性，非性能赌博）：用共享 344 物种重跑 leave-one-disease-out，回答"共享信号本身能否迁移"。**无论结果如何都有交付**——迁移则发现"共享信号可迁移、全特征被疾病特异噪声拖累"；不迁移则坐实"疾病特异信号藏在共享物种的方向里"。
3. **子实验 2 = Beta 的概率校准**（针对 F6 的靶点修复）：Platt/温度缩放，参数仅训练集估计，修复 C3 可部署指标，**不改变 AUC 主指标**。
4. **子实验 3 = Gamma 的重加权**（排除性，可选/降级）：仅做 importance weighting（不做对抗式，小样本风险过高），转导式边界显式声明，作为"域适应能否救回"的受控排除实验。

**混合的取舍**：Gamma 的对抗式域适应**砍掉**（小样本过拟合风险 > 排除价值，F5 已显示批次不主导）；Gamma 的重加权**降级为可选子实验**（若时间/成本允许才做，不做也不影响主结论）。

## 5. 合成

### 5.1 共识点（三方案无分歧）

1. **负结果是合法交付物**：跨疾病预测性能差（AUC 0.556）是 S3 的核心结论，不是失败；题面注1 + 隐含约束第 49 行都支持"性能差 + 原因分析 = 完整回答"。
2. **属级聚合作为性能手段被证伪**（F4）：不再追求"聚合提升 AUC"，属级聚合最多保留为**可解释性/降维手段**（如报告属级标志物），不作为性能策略。
3. **批次效应不主导**（F5）：跨疾病失败主因是疾病特异信号 + 标签语义漂移，不是批次效应；因此**不引入 ComBat 等批次校正**（泄漏风险高、靶点不存在）。
4. **AUC 仍是主指标**：任何校准/改进都不改变 AUC 的主指标地位，辅指标（ACC/F1/灵敏/特异）只作参考且标注测试集不平衡。
5. **严格防泄漏**：所有方案都遵守"新疾病标签不可见"，校准参数/权重估计只从训练集（或显式声明的转导式特征）估计。

### 5.2 不可调和分歧

- **无不可调和分歧**。三方案在"负结果 + 归因"这一主线上完全一致，分歧只在"要不要做受控子实验"（Beta/Gamma 的增量）与"子实验做到什么程度"（Gamma 对抗式砍不砍），这些是**程度问题**而非**方向问题**，可通过混合方案（骨架 + 受控子实验）消解。

### 5.3 推荐方案

**推荐 = 混合方案（Alpha 骨架 + Beta 两个子实验 + Gamma 重加权可选）**，即：

> **接受负结果 + 失败原因三分法归因 + 深度迁移分析（骨架），叠加特征交集筛选（诊断）与概率校准（修复 C3 阈值漂移）两个受控子实验，重加权作为可选排除实验。**

**能交付什么**（推荐方案的具体产出清单）：

1. **迁移失败的模式**（三分法归因的定量结论）：
   - 批次效应：**不主导**（silhouette 0.070/0.001，F5）→ 排除。
   - 疾病特异信号：**主导**（IBD 域内最强 0.885 却衰减最大 −0.358，F3）→ 模型学的是疾病特异标志物。
   - 标签语义漂移：**独立且严重**（C3 阈值迁移灵敏度 0.006，F6）→ 概率基线偏移。
2. **什么信号跨疾病共享**：共享标志物方向一致性分析——把 344 个共享物种分成"方向一致（可迁移）"与"方向翻转（疾病特异）"两类，量化占比，给出"哪些菌的丰度变化方向跨疾病一致"的生物学清单（可对接 S2 的生物标志物结论）。
3. **C3 阈值漂移的量化**：训练集 vs 测试集患病概率基线差、Youden 阈值迁移后决策边界位置、AUC 尚可（0.56）而可部署指标崩溃（灵敏度 0.006）的完整诊断。
4. **一个诚实的跨疾病评估结论**：跨疾病预测 AUC 0.556（近随机），远低于域内 0.64-0.88 与 domain-knowledge 预期 0.70-0.80，**"模型到新疾病上不灵"是有效发现**，并给出"为什么不灵"的三分法归因。

## 6. B 类分歧标记

| # | 分歧 | 拟议裁定 | 级别 | 理由 |

## 7. 待裁定项处置建议

### [A级] 决策树主策略"属级聚合"被证伪 → 推荐方案明确替代策略

- **人话一句话**：原来打算"把物种合并成属/门来提升跨疾病预测"，但实验证明合并后预测反而更差，所以这个主策略作废，要换一个。
- **影响判定**：按拟议（转向"接受负结果 + 归因"）处理 → 对结论可信度**正向**（诚实、无泄漏、直接回答题面）；维持现状（继续追求聚合提升）→ **负向**（与 F4 事实矛盾，强行提升会引入过度设计）。
- **上下文**：S3 决策树 §4 推荐主策略"分类学层级聚合（属级）"；A4 验证显示物种 0.556 → 属 0.539 → 门 0.528（略降）。
- **矛盾点**：决策树假设"聚合降维减批次/疾病特异噪声" vs A4 实测"聚合不提升反略降"。
- **拟议裁定**：主策略从"追求提升 AUC"转向"接受负结果 + 三分法归因 + 深度迁移分析"；属级聚合降级为**可解释性/降维手段**（报告属级标志物），不作为性能策略。
- **处置意见**：采纳拟议（推荐方案 §5.3 已明确替代策略）。
- **回滚路径**：若后续发现属级聚合在特定组合（如 C2）有提升，可局部恢复为对照实验，成本低。
- **级别**：`[A级-需立即]`（影响主策略方向，须在 1.3 方案确认前裁定）。

## 8. 方案讲解收束（math-explainer 6 条约束）

> 受众 = 队友能看懂 + 代码对话无歧义实现（1.4/2.1 的规格依据）。

1. **先定义再使用**：AUC（读作"曲线下面积"，衡量"随机抽一个患者比随机抽一个健康人得分更高的概率"，与阈值无关）、leave-one-disease-out（读作"留一疾病"，每次留一种疾病作测试、其余作训练）、标签语义漂移（训练疾病学到的"患病/健康"决策边界搬到新疾病时整体偏移）、三分法归因（把失败归到批次效应/疾病特异信号/标签漂移三个互斥来源）、Platt 校准（把模型原始分数映射到校准概率的单调变换，参数仅训练集估计）——均首次出现给定义。
2. **每步有"因为"**：主指标选 AUC 因为阈值无关最诚实（F6 显示阈值迁移会崩溃）；主策略转向负结果因为 F1/F4 显示提升无望且题面支持负结果；砍掉对抗式域适应因为 F5 显示批次不主导 + 小样本过拟合风险高。
3. **多视角**：几何视角（AUC = ROC 曲线下面积，阈值漂移 = 决策边界在测试集分布上整体平移）；生物学视角（疾病特异信号 = 共享物种的丰度变化方向在疾病间翻转）；统计视角（silhouette 近 0 = 三数据集在低维空间不分开）。
4. **核心洞察收束**：S3 解决"模型到新疾病上还灵不灵"，做法是"留一疾病协议 + 接受负结果 + 三分法归因 + 深度迁移分析"，之所以这样做，是因为跨疾病预测是评估任务而非建模大赛，**负结果也是答案**。
5. **直觉解释（含"负结果也是答案"）**：**类比**——好比一个只见过"A 病和 B 病患者 vs 正常人"的医生，现在要他判断"C 病患者是不是病人"。他学到的"像病人"的直觉（肠道菌群紊乱、炎症信号）能复用多少，就决定跨疾病预测成败。实验结果是：这个医生**基本判断不了 C 病**（AUC 0.556，和抛硬币差不多）。但"他判断不了"本身是**有价值的发现**——它告诉我们：肠道菌群里的"疾病信号"大多是**各病各的**（IBD 的菌和 CRC 的菌不一样），而不是一个通用的"生病信号"。**负结果也是答案**，就像"这个药对 C 病无效"和"这个药对 C 病有效"一样，都是医生需要的结论——前者避免了误用，后者指导了用药。
6. **防跳跃**：需展开的概念点——AUC 的几何含义与 ROC 曲线；Youden J 阈值定义；Platt/温度缩放的数学形式与"为何不改 AUC"；importance weighting 的密度比估计与转导式边界；方向一致性分析的显著性检验（符号检验/置换检验）。
