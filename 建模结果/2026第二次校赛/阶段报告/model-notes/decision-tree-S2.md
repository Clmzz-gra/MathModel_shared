## 1. 题型判定（决策日志）

```
[决策日志][题型判定] 依据=核心诉求是"从 1331 物种特征筛选最具影响力的特征子集（潜在生物标志物）+ 列 Top 标志物 + 丰度/存在趋势 + 跨疾病对比"，即变量筛选服务于疾病判别，属预测/分类建模中的特征工程子任务
 → 命中=预测类（分类），特征选择子任务（表 2-4 机器学习预测 / 表 2-6 特征工程优化）
 → 结论=预测类（分类）特征选择子问题；核心交付是"稳定、可解释、生物合理"的特征子集与标志物解读，而非单点性能最大化
```

**判据说明**：本问不直接构建最终分类器（那是 S1），而是回答"哪些物种特征最有判别力、其丰度如何随疾病状态变化、跨疾病关系如何"。故归入**预测类的特征选择子任务**——方法链以"稳定特征筛选 → 差异丰度检验 → 标志物解读"为主线，与 S1 的分类建模解耦但共享成分数据前置。

## 3. 决策树

```
高维(1331)×稀疏(92%零)×小样本(110~253/集) 定和成分数据
  │
  ├─ 主方法：稳定性选择（Lasso + bootstrap）
  │    · 每折对训练集做 CLR/伪计数 → Lasso 稀疏 Logistic 拟合（每病独立）
  │    · 多轮 bootstrap 重复，统计每个特征的"出现频率"
  │    · 以频率 ≥ τ（如 80%）作为稳定特征入选 → 每病 Top 10~20 生物标志物
  │    └─ 理由：直接对抗"小样本特征选择方差大"这一最大风险（PR-011/PF-019 小样本保护链）
  │
  ├─ 解释层（对稳定特征做，非再选）：Wilcoxon 差异检验（病 vs 健）+ FDR(BH) 校正
  │    · 区分两类信号：存在/缺失（零值占比差异，用精确 Fisher 或 Wilson 区间）
  │                    丰度高/低（非零值上的 Wilcoxon/CLR 丰度差）
  │    · 对照 domain-knowledge 已知标志物（CRC-Fusobacterium nucleatum、IBD-Faecalibacterium prausnitzii）
  │
  ├─ 备选（交叉验证主结果）：
  │    · RF 重要性（不依赖 CLR，容忍零值非线性——树模型直接跑）
  │    · PLS-DA VIP（成分数据原生，VIP>1）
  │    └─ 三者 Top-N 交集/排名一致性作为稳健性佐证（稳定性选择的结果若被 RF/VIP 独立复现 → 更可信）
  │
  └─ 稳定性策略（强制）：所有方法在**分层 CV 折内**做特征选择（测试集信息隔离（约束），见 2025C 参考"特征筛选与建模解耦"）
       多轮重复取出现频率；报告时同时给"全量选择结果（乐观）"与"CV 内稳定频率（诚实）"
```

**推荐主方法 = 稳定性选择（Lasso + bootstrap）**，理由三选：
1. **直击最大风险**：小样本下任何单次特征选择都高方差，bootstrap 聚合频率把"选择不稳定"量化出来并过滤（这正是 2025C 小样本教训的泛化）。
2. **可解释 + 稀疏**：L1 稀疏解天然给出小而精的特征集，符合 2025C"少而精优于多而全"。
3. **与 S1 联动**：所选特征子集可直接作为 S1 下游分类器的输入，形成"特征选择 → 分类建模"一致链路。

**备选**：RF 重要性（树模型容忍零值/非线性，无需 CLR 前置）；PLS-DA VIP（成分数据原生）。三者做 Top-N 一致性交叉验证。

## 4. 最大风险（1-2 个）

1. **小样本下特征选择方差大 → 假标志物**：110~253 样本对 1331 特征，单次选择结果几乎不可复现；一个"运气"特征可能因少数样本而被选中。**应对**：bootstrap 多轮取出现频率 ≥80%；Top 标志物必须与 domain-knowledge 已知标志物交叉核对（若 CRC 选不出 Fusobacterium nucleatum 类公认标志物，须警惕选择偏差）；报告区分"CV 内稳定频率"与"全量选择"。
2. **92% 零值主导 → 差异检验失真 + 信号语义混淆**：多数特征在多数样本为 0，Wilcoxon 的"差异"主要反映**存在与否**而非丰度高/低；且零膨胀使检验分布严重偏离。**应对**：拆成两路信号分别分析——(a) 存在/缺失（零值占比差，Fisher 精确检验）；(b) 非零丰度高/低（CLR 或伪计数后 Wilcoxon）；BH-FDR 校正 1331 次比较；明确标注"检出率差异 vs 丰度差异"两种标志物语义。

**附加风险（登记，非本问主风险）**：Obesity 患病为多数类（164/89），差异检验方向与类不平衡处理需注意；CRC 含 small_adenoma 26 例的患病方案待 [B级] 裁定（见 gate-0.1 待裁定项）。

## 5. A 类共享事实验证清单（交代码代理执行）

> **第一步强制为简单基线**：单特征 Wilcoxon/存在率阈值，先建立"单特征判别力下界"，防过度设计。

1. **【基线】单特征 Wilcoxon 判别力下界**：对每特征做病 vs 健 Wilcoxon（+FDR），按 p 值排序；看零值占比差异 vs 非零丰度差异哪个主导；给出"至少 1 个特征即可区分"的最优单特征 AUC 量级。→ 产出 Top 单特征散点/分布图。
2. **【零值占比对方法影响】分零值率分箱**：将 1331 特征按零值占比（0-100%）分箱，观察各候选方法（Wilcoxon p、L1 入选、RF 重要性、VIP）在每箱的选中率——量化"零值主导 → 方法失效"的边界，指导是否需先过滤近全零特征。
3. **【特征冗余度】相关性/共线初查**：抽样计算特征间 Spearman 相关（对非零样本）；量级估算高度相关簇（|ρ|>0.7）数量与最大簇规模——决定 Lasso 共线组内选择是否严重、RF 重要性是否被分散。
4. **【三数据集重叠度初查】物种存在/特征重叠**：三数据集各自非零特征集合的 Jaccard 重叠 + 已知标志物在三数据集的检出率——为"跨疾病标志物对比"与 S3 迁移预判铺底。
5. **【成分数据前置】CLR 必要性验证**：抽检原始丰度 vs CLR 后同一对特征的 Pearson/Spearman 相关差异，确认定和成分导致的伪相关是否需 CLR 前置（PR-006/MS-011 铁律）。
6. **【稳定性量级】bootstrap 频率分布初查**：对 Top-20 稳定特征，Lasso 多轮出现频率的直方图——检验"高频率稳定簇"是否真的存在，还是频率平缓需调阈值。

> 数据接口：`outputs/data/B-raw.pkl`（列：`dataset_name`/`disease` + 1331 特征；标签按 `solution/problem-statement.md` 标准映射）。验证规格与待产探索图清单详见 `handoff-S2-code-agent-verify.md`。

## 6. 讲解收束

- **解决什么**：从 1331 个高维稀疏物种特征中，筛出每病稳定、可解释、生物合理的 Top 生物标志物，并解读其丰度/存在趋势与跨疾病关系。
- **怎么做**：以 **Lasso + bootstrap 稳定性选择**为主方法抗小样本方差 → **Wilcoxon + FDR** 对稳定特征做差异丰度检验 → 拆"存在/缺失"与"非零丰度高/低"两路信号 → RF/VIP 独立复现交叉验证 → 对照已知标志物与跨疾病重叠分析。
- **为什么**：高维稀疏小样本下，特征选择结果本身方差巨大且零值主导语义，必须用多轮聚合稳定化 + 信号拆分去伪存真，否则"最影响"标志物很可能是过拟合的假象。

> 可能需要展开的概念点（供追问）：稳定选择阈值 τ 的选择依据；BH-FDR 原理；存在率 vs 丰度两路信号的统计方法选型（Fisher vs Wilcoxon）；成分数据 CLR 前置的伪相关机制。
