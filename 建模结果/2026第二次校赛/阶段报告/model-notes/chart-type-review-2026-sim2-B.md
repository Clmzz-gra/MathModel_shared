## 三、亮点（值得保持的做法）

1. **S3-strategy-compare 双参考线**（随机 0.5 + 可用线 0.65）：负结果论文的自明性关键——读者不用翻正文就能判断「低于可用线」。
2. **S3-decay-attribution 哑铃图**：配对差值（域内→跨病）用哑铃图而非分组条形，衰减量一眼可见，配归因文字标注。
3. **chart-batch-effect 解读注释**：图上直接写「无清晰分离 → 批次/分布差异」，图自明。
4. **S2-stable-frequency 双口径标注**（全量 bootstrap 频率 + CV 折内诚实频率），诚实性可视化。
