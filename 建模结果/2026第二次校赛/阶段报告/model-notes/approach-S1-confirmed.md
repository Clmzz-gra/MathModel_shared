## 1. 最终方案

| 层级 | 模型 | 数据形态 | 理由 |
|:--|:--|:--|:--|
| **主模型** | **Logistic(L2) + CLR 前置 + class_weight='balanced'** | **近全零过滤后（1331→264，零值占比>95% 剔除）→ CLR 变换的 264 维相对丰度** | 可解释（系数→微生物方向，为 S2/S3 铺垫）、L2 收缩抗小样本、CLR 实证增益 +0.10~+0.15（F4）、概率输出支持阈值分析；近全零过滤与 S2 口径统一（三病并集 264 特征，V2 实证不损失判别信息） |
| **对照模型** | **Random Forest（原始丰度）** | 原始相对丰度（含 92% 零值，免 CLR，**同样过近全零过滤 264 维**） | 非线性对照 + permutation importance 复用 S2；F3 确认 Zeller/Chatelier 略优 |
| **基线（强制）** | **单特征最佳阈值 + Dummy(多数类)** | 原始丰度（过滤后 264 维） | 性能下界，防过度设计（F1 已建立） |
| **评估协议** | 分层 5 折 CV（seed=42）+ AUC 主指标 + F1/Recall(少数类) + LOOCV 兜底 | — | 小样本诚实估计，全量 vs LOOCV 差距 >0.1 判过拟合 |

### 1.1 关键假设

1. **H1 成分数据假设**：1331 维物种相对丰度是定和成分数据（每行丰度和 ≈ 100），进入线性模型前必须 CLR 变换解除定和约束引入的伪相关（F4 实证 +0.10~+0.15）。
2. **H2 零值处理假设**：92.21% 零值视为「低于检出限」的真实稀疏，用乘法替换 δ=6.5e-06 处理（AL-007），而非删除或伪计数 +1。
3. **H2b 近全零过滤假设（2026-08-21 人类裁定采纳）**：零值占比 >95% 的特征（1067 个）几乎无判别信息，先剔除再建模（1331→264），与 S2 过滤口径统一（三病并集）；V2 实证不损失判别信息，AUC 预计持平或略升（实现时以过滤后重跑为准）。
3. **H3 标签口径假设**：small_adenoma 按**四口径敏感性分析**处理（2026-08-21 人类裁定）——①归健康（题面主口径）②归病变 ③剔除 ④单开一类；全做一遍，最终主口径从结果择优（性能+可解释性），不预设单一口径。
4. **H4 独立同分布假设**：三数据集各自独立建模，不跨数据集混合训练（批次效应强，F8）；跨疾病差异按四重来源归因。
5. **H5 内部验证假设**：无外部验证数据，泛化评估靠分层 CV + LOOCV 诚实估计，全量 AUC 仅作乐观上界。

## 2. 数学框架

> 本节遵循 math-explainer「讲解质量约束」全量 6 条：每个符号首次出现给定义与读法；关键公式代入标注数值与理由；配直觉类比；结尾收束。

### 2.1 符号表（先定义再使用）

| 符号 | 读法 | 定义 |
|:--|:--|:--|
| $n$ | "样本数" | 某数据集的样本总数（Zeller=121 / metahit=110 / Chatelier=253） |
| $p$ | "特征数" | 物种级特征列数 = 1331 |
| $x_{ij}$ | "第 i 个样本第 j 个物种的相对丰度" | 原始丰度矩阵 $\mathbf{X}$ 的元素，$i=1,\dots,n$，$j=1,\dots,p$ |
| $\delta$ | "德尔塔，零值替换值" | 零值乘法替换的伪值 = 6.5e-06（见 §2.2） |
| $g_i$ | "第 i 个样本的几何均值" | $g_i = \left(\prod_{j=1}^{p} x_{ij}\right)^{1/p}$，读作"所有物种丰度连乘后开 p 次方" |
| $\mathrm{clr}(x_{ij})$ | "CLR 变换后的值" | 中心化对数比（Centered Log-Ratio），见 §2.2 |
| $\mathbf{w}$ | "权重向量" | Logistic 回归的系数向量，长度 $p$，每个元素 $w_j$ 是第 j 个物种的效应 |
| $b$ | "偏置项" | Logistic 回归的截距 |
| $z_i$ | "线性得分" | $z_i = \mathbf{w}^\top \mathrm{clr}(\mathbf{x}_i) + b$，读作"权重与 CLR 特征的内积加偏置" |
| $\sigma(z)$ | "sigmoid 函数" | $\sigma(z) = \frac{1}{1+e^{-z}}$，把任意实数压到 (0,1) 区间当概率 |
| $y_i$ | "第 i 个样本的真实标签" | 患病=1 / 健康=0 |
| $\lambda$ | "拉姆达，正则强度" | L2 惩罚系数，越大收缩越强 |
| $C$ | "C，正则强度的倒数" | sklearn 参数，$C = 1/\lambda$，C 越大正则越弱 |
| $w_c$ | "第 c 类的样本权重" | class_weight 中类别 c 的权重，见 §2.4 |
| $K$ | "K，交叉验证折数" | 分层 CV 的折数 = 5 |

### 2.2 CLR 变换（成分数据 → 可比较的相对量）

**第一步：零值乘法替换**（因为 92% 零值无法取对数，需先给一个「低于检出限」的伪值）：

$$x_{ij} \leftarrow \max(x_{ij},\ \delta),\qquad \delta = 0.65 \times 10^{-5} = 6.5\times10^{-6}$$

- 读法：每个丰度值若为 0，替换为 δ；δ = 0.65 乘以检出限（1e-05）。
- 因为：δ 取「检出限的 0.65 倍」是 AL-007 标准乘法替换，既保证可对数化，又远小于任何真实非零丰度（不污染信号）。

**第二步：逐行几何均值中心化**：

$$\mathrm{clr}(x_{ij}) = \ln x_{ij} - \frac{1}{p}\sum_{k=1}^{p}\ln x_{ik} = \ln\frac{x_{ij}}{g_i}$$

- 读法：先对每个丰度取自然对数，再减去该样本所有物种对数丰度的平均值（即减去几何均值的对数）。
- 因为：定和约束（每行和 ≈ 100）使丰度之间「此消彼长」，产生伪相关；减去行内几何均值对数后，每个值变成「该物种相对本样本平均水平的对数比」，解除定和偏相关（PR-006 铁律，F4 实证 +0.10~+0.15）。
- **直觉类比**：把「全班 100 分总分里各科分数」换成「各科相对全班平均分的偏离」，才能公平比较不同学生——CLR 就是把「加起来等于 100 的成分」翻译成「相对多少」。

### 2.3 Logistic 回归 + L2 正则

**线性得分与概率**：

$$z_i = \mathbf{w}^\top \mathrm{clr}(\mathbf{x}_i) + b,\qquad P(y_i=1\mid \mathbf{x}_i) = \sigma(z_i) = \frac{1}{1+e^{-z_i}}$$

- 读法：样本 i 患病的概率 = sigmoid(权重与 CLR 特征的内积 + 偏置)。
- 因为：sigmoid 把线性得分映射到 (0,1)，天然输出概率，支持阈值分析与 AUC 计算。

**损失函数（负对数似然 + L2 惩罚）**：

$$\mathcal{L}(\mathbf{w},b) = -\sum_{i=1}^{n}\Big[y_i\ln\sigma(z_i) + (1-y_i)\ln\big(1-\sigma(z_i)\big)\Big] + \frac{\lambda}{2}\lVert\mathbf{w}\rVert_2^2$$

- 读法：损失 = 所有样本的交叉熵之和 + 正则强度 λ 乘以权重向量二范数平方的一半。
- 因为：第一项是交叉熵（衡量预测概率与真实标签的差距）；第二项 $\frac{\lambda}{2}\lVert\mathbf{w}\rVert_2^2$ 是 L2 惩罚，把权重向 0 收缩，防止 $n \ll p$（110~253 样本 vs 1331 特征）下的过拟合（PR-011 协方差收缩）。
- **直觉类比**：L2 像「给每个系数套一根橡皮筋往 0 拉」，样本越少、特征越多，橡皮筋越紧，防止模型死记硬背噪声。
- **sklearn 对应**：`LogisticRegression(penalty='l2', C=1.0)`，其中 $C = 1/\lambda$（C=1.0 即 λ=1.0，为默认起点，可调参）。

### 2.4 class_weight='balanced'（类别不平衡处理）

$$w_c = \frac{n}{n_{\text{classes}} \times n_c}$$

- 读法：类别 c 的权重 = 总样本数 ÷（类别数 × 类别 c 的样本数）。
- 因为：少数类样本数 $n_c$ 小 → 权重 $w_c$ 大 → 损失中少数类样本被放大，迫使模型更关注少数类（针对 metahit 少数类 Recall=0.400 的 F5 问题）。
- 代入：metahit 患病类 $w_1 = 110/(2\times25) = 2.2$，健康类 $w_0 = 110/(2\times85) = 0.647$——患病样本权重是健康的 3.4 倍。
- **直觉类比**：像考试里「错一道难题扣分更多」，逼模型别只顾多数类拿高分。

## 3. 求解方法（sklearn 实现要点）

| 步骤 | 实现 | 要点 |
|:--|:--|:--|
| 数据加载 | `c-data-cleaned.pkl`（float32） | 1331 特征 + 2 元数据列；标签映射见 handoff |
| CLR 前置 | 自写函数（零值替换 δ=6.5e-06 → 逐行几何均值中心化） | 仅主模型 L2 需要；RF 用原始丰度 |
| 主模型 | `LogisticRegression(penalty='l2', C=1.0, class_weight='balanced', solver='lbfgs', max_iter=1000)` | 概率输出，支持阈值分析 |
| 对照模型 | `RandomForestClassifier(n_estimators=500, max_depth=None, min_samples_leaf=1, random_state=42)` | 原始丰度，permutation importance |
| 基线 | 单特征最佳阈值（逐特征扫阈值取 AUC 最大）+ `DummyClassifier(strategy='most_frequent')` | 性能下界 |
| 评估 | `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)` | AUC 主指标 + ACC + F1/Recall(少数类) |
| 兜底 | LOOCV（`LeaveOneOut`） | 全量 AUC vs LOOCV AUC 差距 >0.1 判过拟合 |

> 超参 C 的调参范围：若需调参，在 {0.01, 0.1, 1.0, 10, 100} 内用内层 CV 选择，避免外层 CV 泄漏；默认 C=1.0 为起点（见 proxy 清单）。

## 8. 方案讲解收束（math-explainer 6 条）

- **解决什么**：为三个宏基因组数据集各建一个「患病 vs 健康」二分类模型并诚实评估，回答「模型预测疾病表现如何、为何三数据集表现不同」。
- **怎么做**：小样本高维成分数据 → Logistic(L2)+CLR 为主、RF 对照、简单基线兜底、AUC 主指标 + F1/Recall(少数类) 诚实评估、按四重来源归因跨疾病差异。
- **为什么**：成分数据需 CLR 解除定和偏相关（F4 实证）；L2 收缩抗小样本过拟合（PR-011）；AUC 不受类别不平衡与方向影响，是跨数据集可比的最诚实指标（F5 实证）。

**防跳跃（可能需展开的概念点）**：CLR 为什么解除定和偏相关（几何均值中心化的数学含义）、L2/Ridge 收缩的 λ 选择、LOOCV 为何是最小诚实估计、成分数据零值的乘法替换公式（AL-007）、permutation importance 与 Gini importance 的区别。如需后续展开可追问。
