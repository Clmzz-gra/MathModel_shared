# S3 补充实验 E5：源分离学习与输出级融合（模型组合方式能否突破天花板）

> 阶段：S3 补充实验（归因分析第 5 环）| 日期：2026-08-22 | 角色：代码对话（S3）
> 数据接口：`outputs/data/S3-preprocessed.pkl`（复用，与 S3 正式实现同口径）；官方基线参照 `outputs/data/S3-results.pkl :: strategy_compare.A_direct`
> 脚本：`outputs/scratch/S3-e5-source-ensemble.py` | 产物：`outputs/data/S3-e5-source-ensemble.pkl`
> 目的：检验归因证据链最后一个未覆盖维度——「源分离学习 + 输出级融合」：两训练疾病分别独立训练模型再融合打分测留出疾病，看「模型组合方式」能否突破 0.56~0.60 区间。

---

## 一、实验目的

S3 正式实现测得策略 A（两训练疾病**合并样本**训一个 Logistic）3 组合 LODO AUC 均值 **0.5603**
（近随机）；紧急回退穷尽后最优可达 R3_weighted **0.6068**，仍低于可用线 **0.65**。此前四轮补充
实验已依次证伪「批次效应」（E0 ComBat）、「模型容量不足」（E1 免训练/低容量基线）、「模型族/
稀疏先验」（E2 贝叶斯）、「零样本协议过严」（E3 few-shot）。

剩最后一个未覆盖维度：**合并训练本身是否稀释了源信号**——两个训练疾病混进同一个 StandardScaler
和一个 Logistic 联合拟合，可能互相拉扯决策边界；若把两疾病**分别**训练成源模型再在输出级融合，
AUC 是否显著跳升？若跳升跨过可用线，失败主因应改写为「训练组织方式」；若仅有增益而不达线，
则「模型组合方式」作为第 5 类替代解释被证伪，负结果证据链闭环。

## 二、方法

1. **数据准备**：复用 `X_filtered`（484×264 过滤后物种级丰度）→ CLR 变换（δ=6.5e-6 乘法替换 +
   逐样本几何均值中心化，全数据做过、无泄漏）。LODO 协议不变：C1 测 CRC / C2 测 IBD /
   C3 测 Obesity，训练/测试样本量分别为 363/121、374/110、231/253。
2. **源分离学习（与策略 A 的唯一差异点）**：每个组合把训练集按 `dataset_name` 切成两个源子集
   S_a/S_b，各训一个源模型——StandardScaler **仅在各自源子集上估计**（「分别学习」的核心），
   Logistic 参数与策略 A 完全一致（L2、C=1.0、class_weight='balanced'、max_iter=2000、
   random_state=42）。其余口径（CLR、特征集、LODO 划分）与策略 A 相同。
3. **输出级融合（打分只用训练侧信息，无测试标签泄漏）**：
   - F1 logit 平均：score=(f_a+f_b)/2，f=decision_function；
   - F2 概率平均：P=(P_a+P_b)/2；
   - F3 域内 CV-AUC 加权：每源在自身源子集上做 5 折分层 CV（shuffle+seed=42，Pipeline 内 scaler
     逐折重估防折内泄漏）得池化 OOF AUC，权重 w_d=AUC_d/(AUC_a+AUC_b)，score=w_a·f_a+w_b·f_b，
     权重只由源样本估计，无泄漏；
   - F4 单源对照：M_a/M_b 各自单独打分（机制诊断用）。
4. **基线核对**：脚本内以完全相同口径重算合并训练基线（两源样本合并、scaler 仅合并训练集估
   计），并与官方 `strategy_compare.A_direct.<C>.auc` 逐组合核对，|Δ| 应 <1e-6。
5. **并行与确定性**：3 组合 × {源 a、源 b、合并基线} = 9 个独立任务 ProcessPoolExecutor 并行
   （轻量任务，秒级）；CV 与 Logistic 随机性均固定 seed=42，结果确定可复现。

## 四、判读

**源分离融合有真实增益但不达可用线，「模型组合方式」维度被证伪；机制性发现：合并训练确实稀释源信号。**

1. **基线精确复现**：脚本内重算合并基线与官方 pkl 逐组合 |Δ|=0.00e+00、match_within_1e-6 全部
   为 true（3.2 节），且与 E3 报告 k=0 数字逐位一致——本实验的增益对比无基线漂移干扰。
2. **源分离融合有真实增益（+0.039）**：F1/F3 均值 0.5996/0.5995 vs 基线 0.5603（+0.0393/+0.0392），
   为全部补充实验中相对基线的最大正增益（E3 few-shot 需并入测试疾病标签才 +0.0295）。分方向：
   C1 融合最高 **0.6273**，是**零样本口径下 C1 方向迄今最高**——高于此前最高的 R4 C1 0.6184 与
   R3 C1 0.5945（均出自 `S3-results.pkl :: fallback`；E3 的 C1 k=50 0.6567 属 few-shot 口径、用了
   测试疾病标签，不可比）；C2 F1 **0.6334** 也明显高于其基线 0.5882。
3. **机制性发现：合并训练稀释源信号**。单源模型在 C1 上双双高于合并基线（0.6010 / 0.6082 vs
   0.5674），C2 的 Obesity 源 **0.6348** 更高出合并基线 0.5882 达 +0.0466（同组合 CRC 源 0.5087 近
   随机）。「分开学」普遍不差于甚至好于「合着学」，说明两疾病样本混入同一个 scaler/Logistic 会互
   相稀释源信号——与 E3 呼应：C2 中把少量 IBD 样本并入训练反而扰动边界（k=50 时 −0.067），本质
   都是跨疾病样本混合的相互干扰；本实验证明把这种混合拆开即可回收部分性能。同时融合几乎不吃亏：
   相对最优单源的差为 C1 +0.0143(F1) / +0.0191(F3)、C2 −0.0014 / −0.0061、C3 +0.0049 / +0.0044——
   即使并入了近随机的 CRC 源（C2），logit 平均也几乎不掉点，多样性互补真实存在。
4. **但未突破可用线**：最优融合均值 0.5996 < R3 最优可达 0.6068 < 可用线 0.65，相对基线提升
   +0.0393 也远低于「≥0.10」的可用判定阈值。C3 三种融合 0.5424~0.5429 仍近随机——C3 的失败是
   标签语义漂移（患病定义不一致），换任何训练组织方式/模型组合都救不了排序能力，与 E3 的 C3
   结论一致；C2 的增益主要来自 Obesity 源（0.6348），CRC→IBD 方向信号仍然缺失。
5. **F3 加权 ≈ F1 平均：域内 CV-AUC 不是跨域迁移能力的可靠代理**。两者均值仅差 0.0001
   （0.5995 vs 0.5996）。机制上域内强度与跨域迁移脱钩：C2 中 CRC 源域内 OOF 0.7968 高于
   Obesity 源 0.6659，跨域却仅 0.5087（近随机）、远低于 Obesity 源 0.6348——F3 因此给近随机源
   更高权重（w_CRC=0.5447），反而比简单平均低 0.0047；IBD 是另一极端，域内最强 0.8692 却衰减最
   大（到 Obesity 仅 0.5380，较域内 −0.3312，六条「源→目标」方向中绝对衰减之最）。结论：
   **简单 logit 平均即可，无需复杂加权；域内 CV 好不等于跨域好**。
6. **证据链第 5 环闭合**：至此五类替代解释（批次效应、模型容量、模型族/先验、协议过严、模型组
   合方式）全部检验完毕。最后一环结论是「部分证伪」——源分离融合给出真实增益并附带机制解释
   （合并稀释源信号），但不改变量级判断（天花板仍在 0.60 附近，未超 R3 的 0.6068）。S3 负结果
   （最优可达 R3 0.6068 < 可用线 0.65）结论不变、更稳健：「疾病特异信号不迁移 + 标签语义漂移」
   的数据固有限制仍是失败主因，而非训练组织方式。

## 五、结论

- **「源分离学习 + 输出级融合」有真实增益但不达可用线**：F1 logit 平均均值 **0.5996** / F3 加权
  **0.5995** vs 合并基线 **0.5603**（+0.0393/+0.0392），C1 融合 **0.6273** 为零样本口径下该方向迄今
  最高；但均值未超过 R3 最优可达 **0.6068**，更低于可用线 **0.65**——「模型组合方式」作为第 5 类
  替代解释被证伪。
- **机制收获**：①合并训练确实稀释源信号（单源普遍高于合并基线），这是对「合并为何只有 0.56」
  的部分解释；②域内 CV-AUC 不能预测跨域迁移（C2 权重错配反例：给近随机源更高权重反降
  0.0047），融合用简单平均即可。
- **C3 仍近随机**（0.5424~0.5429）：标签语义漂移无法靠模型组合修复，与 E3 结论一致。
- **部署含义**：未来若扩展多源部署，「按源分离训练 + 输出级 logit 平均」是不需要额外数据/标注的
  零成本正向改进，可作为工程默认；但不改变 S3「跨疾病模型不建议直接部署」的主结论。
