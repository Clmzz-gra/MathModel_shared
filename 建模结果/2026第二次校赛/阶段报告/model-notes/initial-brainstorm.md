# 初始头脑风暴：B题 基于宏基因组数据的疾病预测模型研究

> 日期：2026-08-21 | 阶段：0.1 问题理解（problem-init）
> 本文件记录初始思路，不构成最终方案；后续由建模对话在阶段 1.0-1.3 深化。

## 一、题型判定

**预测类（分类）**：三个子问题均围绕"从微生物组特征预测疾病状态"展开——S1 二分类建模、
S2 特征选择（服务于预测的变量筛选）、S3 跨疾病泛化（迁移评估）。属 100% 可考察核心题型。
数据为高维稀疏成分数据（相对丰度），小样本（484），是本卷的"数据题 + 机器学习题"。

## 二、核心思路（初稿）

### S1 疾病预测模型
- 三个数据集独立二分类：Colorectal（cancer vs n）、IBD（两种亚型 vs n）、Obesity（obesity vs n）
- 候选模型族：逻辑回归（L1/L2 正则）/ SVM（RBF）/ 随机森林 / XGBoost / LightGBM / PLS-DA
- 评估：分层 5-10 折交叉验证（小样本用 LOOCV 兜底），指标 AUC + ACC + F1 + 灵敏度/特异度
- 亮点方向：跨数据集性能差异分析（样本量、类别平衡度、信号强度、特征重叠）

### S2 特征选择与生物标志物
- 方法候选：稳定性选择（Lasso + bootstrap）、RF 重要性、互信息、PLS-DA VIP、Boruta
- 关键难点：小样本下特征选择方差大 → 需重复采样取稳定特征（多轮特征出现频率）
- 交付：Top 10-20 生物标志物 + 患病/健康丰度对比（Wilcoxon 检验）+ 跨疾病标志物热图/维恩图
- 生物学补充：对照已知文献（如结直肠癌 Fusobacterium 属）验证合理性

### S3 跨疾病预测模型
- 协议：leave-one-disease-out（2 训练 → 1 测试），3 种组合
- 预期：性能显著下降（批次效应）→ 重点分析"什么在迁移、什么不迁移"
- 进阶：利用分类学层级聚合（属级特征减少批次差异）；概率校准解决标签语义差异
- 可做方向：特征交集分析（训练疾病与测试疾病共享的标志物是否决定迁移成功率）

## 三、与 2025 国赛 C 题（NIPT）的复用关系

2025 C 题同为"生物医学数据 + 小样本 + 分类"：其小样本保护链（PR-011 正则化、
PF-019 LOOCV、WF-004 降维可视化）与本 B 题直接复用；不同点：B 题是相对丰度成分数据
（需 CLR 前置判断）、多数据集结构（S1 三数据集 + S3 跨数据集）、特征选择是显式交付物（S2）。

## 四、风险与开放问题

1. 数据稀疏度未知：零值占比高 → CLR 需零值处理（乘法替换/伪计数），或直接树模型
2. 类别不平衡程度未知（数据盘点确认）
3. 特征维度未确认（需 pandas 读表确认列数）
4. 跨疾病预测"负结果"风险 → 预先设计失败原因分析框架
5. 生物标志物解释需要文献检索（领域知识空白，见 domain-knowledge）
