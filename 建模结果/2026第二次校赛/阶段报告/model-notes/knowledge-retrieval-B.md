## 1. S1 疾病预测模型

> 实质：三个疾病数据集各自的二分类（cancer vs n / ibd vs n / obesity vs n）+ 跨疾病性能差异分析。

### 1.1 命中卡片清单

**🔴 直接激活（分类模型族 + 评估陷阱）**

| 卡片 | 一句话用途 |
|---|---|
| **MS-026** | Soft Voting 集成——多基分类器加权投票（2020C 违约预测，AUC 评估避开准确率陷阱） |
| **AL-016** | XGBoost——梯度提升树，支持类别权重 `scale_pos_weight` 处理不平衡 |
| **AL-030** | SVM——最大间隔分类器（2022C 成分数据分类，核技巧处理高维） |
| **AL-031** | 随机森林——Bootstrap 聚合决策树，输出特征重要性（S2 复用） |
| **MS-067** | Fisher LDA + Tikhonov 正则化——极小样本判别分析（2025C，协方差奇异时唯一可行） |
| MS-013 | PLS-DA——高维共线成分数据分类 + VIP 特征选择（n/p 比值小时替代 LDA） |
| MS-014 | 决策树单规则——单特征可分离时的可解释分类（生物标志物解释用） |
| AL-029 | KNN——惰性学习无参分类器（基线对比） |
| **PF-007** | 类别不平衡陷阱——高总体准确率掩盖少数类失败，须同时报混淆矩阵+召回率+AUC |
| **PF-017** | 天花板效应——达标率饱和时 Logistic 失效（McFadden R²≈0 时换方法） |
| PF-019 | 小样本泛化评估困境——LOOCV 诚实评估（见 0.2） |

**🟡 可能相关**

| 卡片 | 一句话用途 |
|---|---|
| MS-019 | AIC/BIC/AICc 模型选择准则（模型族对比时用） |
| PF-005 | 大样本 p 值失效——统计显著 ≠ 实际显著（效应量） |
| MS-006 | 灰色关联——多因素影响评估（S2 更相关，S1 弱命中） |

**⚪ 已排除（附理由）**

| 卡片 | 排除理由 |
|---|---|
| MS-002/MS-009/MS-015（VAR/Prophet/LSTM） | 非时序数据，无时间维度 |
| MS-016/MS-017/MS-018（NSGA-II/PSO/LP） | 非优化题 |
| MS-072/MS-073/MS-074（ODE/SEM/系统动力学） | 非机理题 |
| MS-068/MS-069（混合效应/中介分析） | 非纵向重复测量、非因果路径题 |

### 1.2 方法链建议

```
成分数据前置（CLR + 零值处理 AL-007）
  → 特征选择/降维（S2 产出，或 S1 内嵌正则化）
  → 分类模型族（正则化 Logistic / SVM / RF / XGBoost / PLS-DA / Fisher LDA+Tikhonov）
  → 分层 CV / LOOCV 评估（AUC + ACC + F1 + 灵敏度/特异度，PF-007 全指标）
  → 跨数据集性能差异分析（样本量/类别平衡/信号强度/特征重叠）
```

### 1.3 2025C 参考要点（从 `solution/reference/CUMCM2025-C/` 提炼）

- **LOOCV 评估协议**（approach-sub4-confirmed.md + PF-019）：全量 AUC 标注"乐观上界"、LOOCV AUC 标注"诚实估计"，两者差距 > 0.1 即判过拟合；极小样本下结论须声明"需独立外部数据验证"。
- **小样本特征筛选策略**（approach-sub4-confirmed.md）：Top 特征按 Cohen's d 排序，弱信号特征（|d| < 0.3）排除；特征筛选与建模解耦，避免选择偏差泄漏。
- **诚实标注**：报告所有指标基于 LOOCV，不把全量指标当泛化性能（2025C 批判 6.2 的教训）。

### 1.4 知识空白标记

- **[空白]** 宏基因组 ML 分类的基准性能卡（AUC 基准值 CRC 0.80-0.90 / IBD ~0.85 / Obesity 0.65-0.75 现仅存于 domain-knowledge.md，知识库无卡）。
- **[空白]** 类别不平衡在成分数据上的特定处理（SMOTE 对相对丰度闭合约束的适用性）。

> 实质：高维特征选择（数千列微生物特征）+ Top 生物标志物清单 + 丰度变化趋势 + 跨疾病标志物对比。

### 2.2 方法链建议

```
特征选择（稳定性选择 Lasso+bootstrap / RF 重要性 / PLS-DA VIP / 互信息）
  → 重复采样取稳定特征（多轮出现频率，抗小样本方差）
  → Top 10-20 生物标志物清单
  → 患病/健康丰度对比（Wilcoxon 检验 + 趋势图）
  → 跨疾病标志物对比（维恩图/热图）
  → 生物学合理性对照（domain-knowledge 已知标志物：Fusobacterium nucleatum 等）
```

### 2.3 2025C 参考要点

- **小样本特征筛选策略**（approach-sub4-confirmed.md）：Cohen's d 排序 + 弱信号排除，Top-4 特征即够用——小样本下"少而精"优于"多而全"。
- **特征筛选与建模解耦**：先筛选再建模，特征选择在训练集内完成（防泄漏）。

| WF-004 | 降维可视化——跨疾病数据探索（三数据集可比性） |
| MS-028 | PCA 降维——分类学聚合降维（属/门级特征减少批次噪声） |

| 卡片 | 排除理由 |

### 3.2 方法链建议

```
leave-one-disease-out 协议（2 训练 → 1 测试，3 种组合）
  → 分类学层级聚合（属/门级降维减批次噪声，S3 可利用 k__p__c__o__f__g__s__）
  → 概率校准（标签语义差异）
  → 特征交集分析（训练/测试疾病共享标志物是否决定迁移成功率）
  → 失败/成功模式分析（什么在迁移、什么不迁移）
```

### 3.3 2025C 参考要点

- **跨队列泛化讨论结构**（domain-knowledge.md 文献区）：跨队列 AUC 衰减（0.80-0.90 → 0.70-0.80）的诚实讨论——预期 S3 性能显著下降，重点分析"为什么下降"而非只报数字。
- **负结果分析框架**：预先设计失败原因分析（批次效应/疾病特异性微生物），把"负结果"转化为可讨论的发现。
