# S3 补充实验 E6：深度学习直接分类（MLP）跨疾病 LODO（纯深度分类器能否突破天花板）

> 阶段：S3 补充实验（归因分析第 6 环）| 日期：2026-08-22 | 角色：代码对话（S3）
> 数据接口：`outputs/data/S3-preprocessed.pkl`（复用，与 S3 正式实现同口径）；官方基线参照 `outputs/data/S3-results.pkl :: strategy_compare.A_direct`
> 脚本：`outputs/scratch/S3-e6-mlp.py` | 产物：`outputs/data/S3-e6-mlp.pkl`
> 目的：检验归因证据链最后一个未覆盖维度——「深度学习直接分类」：R4 DANN（0.5947）是「域适应深度网络」，**纯深度分类器**从未直接测过；本实验用 MLP 直接分类跑同一 LODO 协议，回答「深度学习本身是否也无效」。

---

## 一、实验目的

S3 正式实现测得策略 A（两训练疾病合并样本训一个 Logistic）3 组合 LODO AUC 均值 **0.5603**
（近随机）；紧急回退穷尽后最优可达 R3_weighted **0.6068**，仍低于可用线 **0.65**。此前补充实验
已依次证伪五类替代解释：「批次效应」（E0 ComBat）、「模型容量不足」（E1 免训练/低容量基线）、
「模型族/稀疏先验」（E2 贝叶斯）、「零样本协议过严」（E3 few-shot）、「模型组合方式」（E5 源分离
融合，部分证伪）。

证据链中还剩最后一个未覆盖维度：**深度学习直接分类**。R4 DANN 0.5947 出自文献复现，是带对抗
域适应机制的深度网络——它证明的是「域适应深度网络也不行」，而「不给任何域适应机制、纯靠深度
非线性表示直接分类」这一档从未在本管线 LODO 协议下测过。若 MLP 直接分类显著跳升甚至跨过可用
线，失败主因应改写为「此前模型族表达能力不够」；若仍落在 0.56~0.59 档且不优于专门做域适应的
DANN，则第 6 类替代解释被证伪，六环证据链闭环。

## 二、方法

1. **数据准备**：与策略 A / E0–E3 / E5 完全同口径——复用 `X_filtered`（484×264 过滤后物种级
   丰度）→ CLR 变换（δ=6.5e-6 乘法替换 + 逐样本几何均值中心化，全数据做过、无泄漏）→
   StandardScaler 仅训练集 fit。LODO 协议不变：C1 测 CRC / C2 测 IBD / C3 测 Obesity，
   训练/测试样本量分别为 363/121、374/110、231/253。
2. **MLP 直接分类**：sklearn `MLPClassifier`（hidden=(64,32)、relu、adam、α=1e-3、max_iter=500、
   random_state=42、early_stopping=True、validation_fraction=0.15、n_iter_no_change=10）。
   MLP 无 class_weight 参数——类别不平衡用 **sample_weight 传入 fit**（sklearn≥1.7 支持，
   环境 1.9.0 已验证），权重口径与 class_weight='balanced' 同款：w_c = n/(n_classes·n_c)，
   保证与合并训练 Logistic 基线的加权口径可比。
3. **敏感性对照（同协议重跑）**：α=1e-2（更强正则，防过拟合对照）；hidden=(128,64)（更大容量
   对照）。三配置除 hidden/alpha 外所有超参一致。
4. **内部验证集精确截获与核验**：early_stopping 开启时 sklearn 从训练集内部再切 15% 作分层验证
   集。本脚本给 sklearn MLP 模块级 `train_test_split` 包一层间谍函数，**精确截获**该内部划分
   （含 sample_weight 的 6 元组分支），在其上算 train_val_auc；并用「最终模型（early stopping
   回滚最优权重后）在该验证集上的**加权**准确率 == best_validation_score_」交叉核验
   （val_split_verified）。核验必须用加权准确率（sklearn 内部评分传 sample_weight），参照必须用
   best_validation_score_ 而非 max(validation_scores_)，且不能按文档直觉重放该划分——实测
   sklearn 1.9 中权重初始化先于划分消耗同一随机流，外部无法按序复现。
5. **基线核对**：脚本内以完全相同口径重算合并训练 Logistic 基线（L2、C=1.0、
   class_weight='balanced'、max_iter=2000、lbfgs、random_state=42），并与官方
   `strategy_compare.A_direct.<C>.auc` 逐组合核对，|Δ| 应 <1e-6。
6. **并行与确定性**：3 组合 × 3 配置 = 9 个 MLP 任务 + 3 个基线任务 ProcessPoolExecutor 并行
   （max_workers=min(8, cpu_count)，分钟级）；MLP/adam 随机性仅来自权重初始化与 batch 顺序，
   固定 seed=42 即确定，Logistic lbfgs 确定性，结果确定可复现。

## 四、判读

**深度学习直接分类在均值层面无效且不如专门域适应的 DANN，「深度学习」维度被证伪；但 C1 方向给出零样本口径迄今最高值，坐实方向不对称。**

1. **基线精确复现**：脚本内重算合并基线与官方 pkl 逐组合 |Δ|=0.00e+00、match_within_1e-6 全部
   为 true（3.2 节）——本实验的全部对比建立在无漂移的同一起点上。
2. **均值层面证伪**：mlp_main 均值 **0.5814**（α1e-2 0.5819 / 宽网络 0.5850）vs 基线 0.5603
   （+0.021~+0.025）：有小幅正增益但远不达线，且全档低于 **R4 DANN 0.5947**（gap −0.0133）
   < **R3 最优可达 0.6068** < 可用线 **0.65**。「纯深度分类器」不仅没突破，还输给了带域适应机制
   的 DANN——深度非线性表示本身不能解决跨疾病信号稀缺问题；α 十倍变化（1e-3→1e-2）各组合
   仅 ±0.0003~0.0014，排除「正则强度没调对」的解释。
3. **C1 方向例外（重要）**：mlp_main C1 = **0.6852**，为**零样本 LODO 口径下 C1 方向迄今最高**
   ——高于 E5 融合 C1 0.6273（+0.0579）与 R4 DANN C1 0.6184（+0.0668）（均出自
   `S3-results.pkl :: fallback`；E3 few-shot C1 k=50 0.6567 属 few-shot 口径、用了 k=50 测试疾病
   标签参与训练，不可比，特此注明）。两层隐层（64-32）的非线性表示比线性 Logistic 与融合方法都
   更好地利用了 CRC 方向的可迁移信号——坐实「方向不对称」结论：CRC 方向确实存在弱可迁移信号，
   表达能力更强的模型能多挤出一些，而其余方向连这点信号都没有。
4. **C2/C3 塌缩**：C2 mlp_main **0.5332**，不仅近随机还**低于合并基线 0.5882 达 −0.0551**——MLP
   在 C2 上比合并 Logistic 更差：非线性容量在小样本跨疾病设置下过拟合训练疾病分布，反而破坏
   排序泛化；C3 **0.5257** ≈ 基线 0.5253（+0.0003）——Obesity 方向的标签语义漂移依旧无法靠模型
   表达力修复，与 E3/E5 结论一致。
5. **val→test 塌缩模式与 E1 完全一致**：train_val 0.64~0.81 → test 0.49~0.69（逐配置塌缩量
   −0.0177 ~ −0.2364），与 E1 PLS-DA 内层 CV 的塌缩模式完全相同（0.72~0.81 → 0.55~0.61）——
   「训练疾病域内学得强、跨疾病不迁移」不是线性模型的特例，深度网络同样如此。train_val_auc
   语义为 early stopping 模型选择的内部验证集（略乐观），field_semantics 已注明不可与 test_auc
   混比；本实验的塌缩对比全部建立在截获核验通过的划分上（3.3 节，9/9 true）。
6. **宽网络不稳定**：mlp_wide C1 = **0.4914**（低于随机 0.5）、C2 = 0.6856、C3 = 0.5780——同一
   配置跨组合摆幅达 0.19，484 样本训深网方差极大；wide 均值 0.5850 仅比主配置高 +0.0037，容量
   增大不带来稳定增益。其中 wide C2 0.6856 名义上是 C2 各实验的最高单点，但它来自一个在 C1 上
   塌到随机以下的高方差配置——单点极值不能支撑「加大容量就能修复迁移」的主张。
7. **证据链第 6 环闭合**：至此六类替代解释（批次效应 E0、模型容量 E1、模型族/先验 E2、协议过严
   E3、模型组合方式 E5、深度学习直接分类 E6）全部检验完毕。最后一环结论是「均值层面证伪」——
   深度学习直接分类无效且不如 DANN（DANN 为文献复现值、与本实验同为 LODO 协议但实现独立，
   仅作「域适应 vs 纯分类」两档对照，非同日复现核对）。S3 负结果（最优可达 R3 0.6068 < 可用线
   0.65）结论不变、更稳健；同时 C1 方向 MLP 0.6852 这一新最高值进一步支持「CRC 方向存在弱可
   迁移信号」，与归因收束口径（CRC 定向迁移受益）互相印证。

## 五、结论

- **「深度学习直接分类」作为第 6 类替代解释被证伪（均值层面）**：三配置均值 0.5814~0.5850，
  相对基线仅 +0.021~+0.025（远低于 ≥0.10 阈值），低于 R4 DANN 0.5947、R3 最优可达 0.6068 与
  可用线 0.65——纯深度分类器不如专门做域适应的 DANN，深度学习本身不是本数据的出路。
- **方向不对称获得新证据**：C1 方向 mlp_main **0.6852** 为零样本口径 C1 迄今最高（>E5 融合
  0.6273 > R4 DANN 0.6184；E3 0.6567 为 few-shot 口径不可比）——非线性表示能更好利用 CRC
  方向的弱可迁移信号；而 C2 反而比基线差 −0.0551、C3 近随机持平——IBD/Obesity 方向信号缺失
  或语义漂移不受模型表达力影响。
- **机制收获**：①域内强/跨疾病塌缩模式在 MLP 上复现（train_val 0.64~0.81 → test 0.49~0.69），
  与 E1 PLS-DA 一致，说明这是数据固有限制而非模型族伪象；②484 样本训深网方差极大（宽网络
  C1 低至 0.4914），小样本跨疾病场景下深度模型既无收益也不稳定。
- **部署含义**：跨疾病场景若未来引入深度模型，纯分类架构不可取，须带显式域适应机制且预期上限
  也仅在 0.59 档（DANN）；不改变 S3「跨疾病模型不建议直接部署」的主结论。
