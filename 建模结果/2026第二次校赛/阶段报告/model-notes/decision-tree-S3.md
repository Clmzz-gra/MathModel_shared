## 1. 题型判定

**依据**：题面 S3 写的是"建立跨疾病预测模型，评估其跨疾病预测性能"，并注明确"利用一种或两种疾病作为训练集，另外一种新的疾病作为测试集"。核心诉求不是求最优决策、不是给多个方案分优劣、也不是建物理微分方程，而是**依托已观测的宏基因组数据，度量一个预测模型对"从未见过的新疾病"的预测能力**——这正是预测类里"迁移/泛化评估"子型的形态。

**命中**：预测类（迁移/泛化评估子型）。

**结论**：预测类。主导模块是"跨疾病预测性能评估"，本质 = 用一套分类模型族（沿用 S1 已验证的模型）+ 一个跨疾病评估方案（leave-one-disease-out），去诚实度量模型的泛化能力。S3 的独特工作量集中在三处：**评估方案设计**（组合/阈值迁移/测试集信息隔离（约束））、**分类学层级聚合**（利用 `k__p__c__o__f__g__s__` 降维减批次噪声）、**患病定义差异与阈值迁移处理**（训练集只有部分疾病时，二分类决策边界能否迁移）。

> 一句话收束：S3 解决的是"模型到新疾病上还灵不灵"，做法是"留一疾病评估框架 + 分类学聚合 + 诚实指标"，之所以这样做，是因为跨疾病预测是评估任务而非建模大赛，负结果也是有效结论。

## 2. 方案设计

### 2.1 leave-one-disease-out 三组合

每次留一个疾病作测试，其余疾病作训练（题面允许 1 或 2 种疾病训练，主方案默认用 2 种训练以信息最足）：

| 组合 | 训练集 | 测试集 | 测试集正类占比（类别平衡提示） |
|---|---|---|---|
| C1 | IBD（metahit）+ Obesity（Chatelier） | CRC（Zeller） | 40%（患病 48 / 健康 73） |
| C2 | CRC（Zeller）+ Obesity（Chatelier） | IBD（metahit） | 23%（患病 25 / 健康 85，少数类） |
| C3 | CRC（Zeller）+ IBD（metahit） | Obesity（Chatelier） | 65%（患病 164 / 健康 89，正类占多数） |

> 强度分析（可选，A 类验证补充）：留 Obesity 时也可报告仅用 CRC 或仅用 IBD 单疾病训练的效果，作为"训练信息量对迁移性能"的敏感性佐证。

### 2.2 患病定义差异问题（核心难点，gate-0.1 登记的 [B级] 待裁定项，本节裁定）

**定义（先定义再使用）**：训练集二分类标签是"患病（各训练疾病患者）vs 健康（各训练疾病健康对照）"；测试集标签是"新疾病患者 vs 新疾病健康对照"。模型在训练疾病上学到的"患病/健康"决策边界，要判断它能否迁移到新疾病——这就是患病定义差异问题。**直觉解释（类比）**：好比一个医生只见过"A 病和 B 病患者 vs 正常人"，现在要他判断"C 病患者是不是病人"，他学到的"像病人"的直觉（肠道菌群整体紊乱、炎症信号等）能复用多少，就决定跨疾病预测成败。

**阈值迁移的三种选择**：
- **(a) 以 AUC 为主指标（推荐）**：AUC（读作"曲线下面积"，即 ROC 曲线下方的面积，衡量"随机抽一个患者比随机抽一个健康人得分更高的概率"）**与阈值无关**——不需要决定"多高算患病"就能衡量区分能力，因此**不依赖阈值迁移假设，是最诚实的跨疾病泛化度量**。
- **(b) 训练集 Youden J 最优阈值直接迁移（参考）**：把训练集上让"灵敏度+特异度-1"最大的那个阈值搬到测试集，报告其下的 ACC / 灵敏度 / 特异度 / F1。隐含假设是"患病概率的决策边界跨疾病一致"。
- **(c) 在测试集上重新定阈值（禁用）**：这会用到新疾病的标签来挑阈值，造成评估违反测试集信息隔离、评估无效——**违背 leave-one-disease-out 的"新疾病不可见"语义**，明确不采用。

**推荐裁定**：主指标用 AUC（阈值无关，最诚实）；同时报告 (b) 训练阈值迁移下的 ACC/F1/灵敏/特异作为"实际可直接应用的水平"的参考；概率校准（Platt/温度缩放）作为备选改进，且校准参数**只能从训练集估计**。

### 2.3 评估指标

- **主指标**：AUC（三组合各报 + 均值）。解读按 modeling-decision-tree：0.80-0.90 良好、0.70-0.80 尚可、0.60-0.70 差、<0.60 接近随机。
- **辅指标**：训练阈值迁移下的 ACC / 灵敏度 / 特异度 / F1。
- **必须标注测试集类别不平衡**：Obesity 正类 65%（正类占多数）、CRC 40%、IBD 23%（少数类）——ACC 单独解读会被不平衡误导，须与灵敏/特异/F1/AUC 联合报告（PF-007 全指标纪律）。
- **衰减量**：跨疾病 AUC − 域内 AUC（S1 基线），量化"泛化代价"。

> 一句话收束：方案解决"怎么诚实地测新疾病"，做法是"留一疾病 + AUC 为主 + 训练阈值只作参考"，之所以这样，是因为只有阈值无关的指标才能不被"训练疾病与新疾病患病概率基线的差异"污染。

## 3. 对比矩阵（7 维度）

**7 维度定义**：① 数据利用（只用训练集特征，还是借用测试集信息）；② 批次效应鲁棒性；③ 患病定义差异/阈值处理；④ 过拟合与测试集信息隔离风险；⑤ 实现与评估成本；⑥ 可解释性/生物学意义；⑦ 预期跨疾病性能与置信度。

> 注：CLR（读作"中心对数比变换"，把每行和为 100 的成分丰度映射到欧式空间以解除定和约束）是所有模型型策略的**强制前置**（PR-006 铁律），不属某单一策略。

| 候选策略 | ①数据利用 | ②批次鲁棒 | ③标签语义 | ④过拟合/信息隔离 | ⑤成本 | ⑥可解释性 | ⑦预期性能(置信度) |
|---|---|---|---|---|---|---|---|
| **直接迁移**（S1 模型不改） | 只训练集 | 低（物种级噪声/批次敏感） | 不处理（用训练阈值） | 低，测试集信息隔离（复用 S1 正则化模型） | 低（复用） | 中（沿用 S1） | **低（性能下界）**，置信度高（确定性） |
| **特征交集筛选**（训练-测试共享标志物） | 训练特征名+测试特征名（交集基于特征名，不含测试标签→测试集信息隔离） | 中（去疾病特异噪声） | 中（共享信号更可能语义一致） | 中低（交集降维） | 中 | 高（交集=共享生物学信号） | 中，置信度中（依赖共享信号量） |
| **分类学层级聚合**（属/门级） | 只训练集 | 中高（聚合减批次/疾病特异噪声） | 不直接处理 | 低（大幅降维） | 中 | 高（属/门级更稳定、可生物学解读） | **中（推荐主策略）**，置信度中高 |
| **概率校准**（Platt/温度缩放） | 训练集校准参数 | 低（不改特征，不解决批次） | **高（解决阈值迁移）** | 低 | 低 | 中（需解释校准假设） | 中（提升有限但更诚实），置信度中 |
| **数据标准化对齐**（CLR + 批次校正思想/ComBat） | 可能借用测试集分布估批次参数→**破坏测试集信息隔离风险高，须谨慎** | **高（直接校正批次）** | 中 | 中（ComBat 小样本参数估计易过拟合+破坏测试集信息隔离） | 高 | 低（批次校正黑盒） | 中，置信度低（小样本 ComBat 风险大，须验证） |

**读法提示**：矩阵横向看，没有一个策略在全部维度占优——"分类学层级聚合"在②⑤⑥⑦综合最优且满足测试集信息隔离，是推荐主策略；"数据标准化对齐"批次鲁棒性最高但破坏测试集信息隔离/过拟合风险也最高，只能作为需要严格验证的备选，不宜直接上。

## 4. 决策树（推荐主策略 + 备选）

```
S3 跨疾病评估（输入：B-raw.pkl，CLR 前置强制）
├─ 特征空间：
│   ├─ 主：分类学层级聚合（属级）——降维 + 减批次/疾病特异噪声 + 增共享信号密度
│   └─ 基线/对照：物种级直接迁移（= A1 简单基线，防过度设计）
├─ 模型：沿用 S1 主模型（正则化 Logistic L2 首选 / PLS-DA 备选）
│        ——跨疾病小样本用 PR-011 正则化保护（λ 用 Ledoit-Wolf/Tikhonov 收缩）
├─ 标签/阈值：
│   ├─ 主：AUC（阈值无关，诚实主指标）
│   └─ 参考：训练集 Youden J 阈值迁移 → ACC/F1/灵敏/特异（标注测试集不平衡）
├─ 增强（按 A 类验证结果叠加，见 §6）：
│   ├─ 若共享信号充足 → 特征交集筛选（训练-测试共享属）叠加
│   └─ 若信号弱 → 概率校准（Platt/温度缩放，参数仅从训练集估计）
└─ 失败原因分析框架（预置，防"负结果"）：
        批次效应 vs 疾病特异性信号 vs 患病定义差异  三分法
```

- **推荐主策略**：**分类学层级聚合（属级）+ 正则化线性模型（Logistic L2 / PLS-DA）+ AUC 主评估**。因为属级聚合同时降维、减批次/疾病特异噪声、加密共享信号，最贴合"评估跨疾病泛化"这一目标，且可解释性高、测试集信息隔离。
- **备选 1（增强叠加）**：特征交集筛选（取训练-测试共享属），当 A 类验证显示三数据集共享信号充足时叠加。
- **备选 2（标签语义处理）**：概率校准（Platt/温度缩放），当某组合 AUC 弱且疑似受阈值迁移影响时用于改进参考指标。
- **备选 3（对照）**：数据标准化对齐（CLR + ComBat 思想），仅当 A 类批次效应初探显示批次强且简单策略失败时考虑，须严格测试集信息隔离、小样本参数风险可控后再上。

## 5. 最大风险（1-2 个）

### 风险 1：跨疾病"负结果"风险（最重要）
- **内容**：跨疾病性能很可能显著下降（domain-knowledge 预期：CRC 跨队列 0.70-0.80，且这是"同疾病跨队列"，本问是"跨疾病"，可能更低，个别组合 AUC 甚至接近随机 0.5）。
- **为什么是风险**：若只报数字，会被解读为"模型失败"，掩盖了"跨疾病预测本身就是最严苛评估任务、负结果也是有效发现"这一事实。
- **应对（预置失败原因分析框架）**：对每个低 AUC 组合，用三分法定性归因——**批次效应**（训练/测试来自不同研究、测序平台不同）vs **疾病特异性信号**（模型学的多是 CRC/IBD 特有菌，对 Obesity 不适用）vs **患病定义差异**（新疾病患者与健康对照的患病概率基线整体偏移）。把"什么在迁移、什么不迁移"变成可讨论结论，而非一句"模型不好"。

### 风险 2：批次效应混淆疾病信号
- **内容**：三数据集来自不同研究（不同测序平台/DNA 提取/生信流程），训练-测试分布差异既可能被**误读为**"跨疾病泛化失败"，也可能**掩盖**真实泛化能力。
- **应对**：A 类加入批次效应初探（PCA/t-SNE 看三数据集是否清晰分开），跨疾病 AUC 解读时区分"批次差异"与"疾病差异"，必要时才考虑批次校正（并严格测试集信息隔离）。

## 6. A 类共享事实验证清单

A 类实验由代码对话执行（验证规格见 `handoff-S3-code-agent-verify.md`）。**第一步必须是简单基线**（TRAE 强制，防过度设计）：

- **[A1] 简单基线（强制第一步）**：直接迁移的 S1 模型 leave-one-disease-out——正则化 Logistic（L2），CLR 前置，物种级特征；输出 3 组合的 AUC + 训练阈值迁移下的 ACC/F1/灵敏/特异。建立性能下界。
- **[A2] 三数据集特征重叠度**：物种级 / 属级 / 门级共享标志物数量（维恩图/热图）——判断共享信号是否足够支撑迁移。
- **[A3] 各疾病信号强度**：S1 基线 AUC 作为参考（若 S1 未产出，用快速小模型估计各疾病域内 AUC）——量化跨疾病 AUC vs 域内 AUC 的衰减量。
- **[A4] 分类学层级聚合对批次差异的影响初查**：物种 vs 属 vs 门聚合下跨疾病 AUC 对比——验证"聚合降噪"假设是否成立。
- **[A5] 批次效应初探（可选）**：三数据集 PCA/t-SNE 分布（WF-004）——看训练/测试是否清晰分开（批次强的标志）。
