## 0. 一句话收束（先给结论）

**本问解决什么**：从 1331 个高维稀疏物种特征中，筛出每病稳定、可解释、生物合理的 Top 10~20 生物标志物，并解读其丰度/存在趋势与跨疾病关系。
**怎么做**：近全零过滤 → CLR 前置 → Lasso+bootstrap 稳定性选择（τ=0.5~0.6）→ Wilcoxon+FDR 两路信号解释 → RF/VIP 独立复现佐证。
**为什么**：高维稀疏小样本下，特征选择结果本身方差巨大且零值主导语义，必须用「多轮聚合稳定化 + 信号拆分」去伪存真，否则「最影响」标志物很可能是过拟合的假象。

## 1. 最终方案

### 1.1 主方法：稳定性选择（Lasso + bootstrap），每病独立

对每个疾病数据集（CRC / IBD / Obesity）**独立**执行，不跨病混合：

1. **近全零过滤**：剔除零值占比 >95% 的特征（1067 个），保留 264 维进入后续所有方法（F3）。
2. **CLR 前置**：对保留特征做中心对数比变换（乘法替换处理零值 + 几何均值中心化，与 S1 口径一致，F6）。
3. **分层 CV 折内 Lasso**：在分层交叉验证的**训练折内**做 Lasso 稀疏 Logistic 拟合（防泄漏）。
4. **bootstrap 聚合频率**：B=50~100 轮分层 bootstrap 重抽样，每轮拟合 Lasso，统计每特征「被选中（系数非零）」的出现频率 $\hat{\pi}_j$。
5. **稳定特征入选**：频率 $\hat{\pi}_j \geq \tau$（τ=0.5~0.6，暂定 0.5）的特征入选为稳定特征，每病取 Top 10~20。

### 1.2 前置（两处，均为共享事实硬约束）

| 前置 | 规则 | 依据 |
|:--|:--|:--|
| 近全零过滤 | 零值占比 >95% 剔除，1331→264 | F3：1067 特征近全零，几乎不携带判别信息，留着稀释 L1/RF 信号 |
| CLR 变换 | 乘法替换（零值加伪计数 δ 后重归一）+ 几何均值中心化 | F6：CLR 使 23~34% 特征对相关方向翻转，不 CLR 则 Lasso 建立在伪相关上 |

### 1.3 解释层（对稳定特征做，非再选）

对入选的稳定特征做差异丰度检验，**拆两路信号**（F2）：

- **(a) 存在/缺失信号**：零值占比差，用 **Fisher 精确检验**（2×2 列联表：存在/缺失 × 病/健）。
- **(b) 非零丰度信号**：非零样本上的 **Wilcoxon 秩和检验**（CLR 后丰度）。
- 两路均做 **BH-FDR 校正（m=1331，全特征规模——2026-08-21 人类裁定：医疗领域宁可严格、不可虚报）**。检验在过滤后 264 特征上执行，但多重比较校正按**全 1331 特征**计数（最严格口径），报告时仅展示稳定特征（Top 10~20）的校正后显著性。
- **已知标志物对照**：与 `domain-knowledge.md` 已知标志物（Fusobacterium nucleatum、Faecalibacterium prausnitzii 等）交叉核对，作方法有效性锚点（F5）。
- **同属近缘种属级聚合**：对同属近缘种（如 Veillonella 属 4 种，F4）做属级聚合补充解读，避免「选 A 不选 B」缺乏生物依据。

### 1.3b 共现分析（协同效应初探，2026-08-21 人类裁定采纳）

> 背景：Lasso 是线性可加模型，只建模每个微生物的**独立边际效应**，显式建模不了「微生物间协同/共现效应」（如 A、B 菌同时出现才致病）。小样本（110~253）下全特征两两交互（~88 万对）不可行，故以入选稳定标志物为限做**二阶初探**，把「没做交互」从潜在扣分点转为「做了初探并声明边界」。

对每病入选的稳定标志物（10~20 个）执行：

- **两两 Spearman 相关**（非零样本上，CLR 后丰度）：输出标志物相关矩阵/热图，识别共现（正相关）与互斥（负相关）对。
- **共现/互斥检验**：对相关显著的标志物对，用 Fisher 精确检验验证「同现/互斥是否超出独立期望」（存在/缺失口径），输出共现网络（节点=标志物，边=显著共现/互斥）。
- **解读定位**：作为**协同效应的初探证据**放讨论节，并显式声明边界：「小样本下仅对入选标志物做二阶探索，无法全特征交互建模；标志物筛选主口径仍为边际信号（生物标志物研究标准口径）」。

### 1.4 佐证层（独立复现，不参与主选择）

- **RF 重要性**：树模型直接跑原始丰度（免 CLR，F6 豁免），多轮取平均重要性。
- **PLS-DA VIP**：VIP 阈值**上调**（VIP>1.5 或按分位数，F8），独立复现。
- 两者与 Alpha 稳定特征的 **Top-N 排名一致性**作为稳健性佐证（Gamma 的「多方法独立复现」思想降级为佐证层）。

### 1.5 稳定性策略（强制）

- 所有特征选择在**分层 CV 折内**做（防泄漏）。
- 报告同时给「全量选择结果（乐观）」与「CV 内稳定频率（诚实）」两套数字。

## 3. 数学框架（符号首次出现给定义与读法）

### 3.1 符号约定

| 符号 | 读法 | 定义 |
|:--|:--|:--|
| $n$ | "n" | 样本数（CRC=121、IBD=110、Obesity=253） |
| $p$ | "p" | 特征数（过滤后 = 264） |
| $y_i$ | "y 下标 i" | 第 $i$ 个样本的标签，$y_i=1$ 患病、$y_i=0$ 健康 |
| $x_i$ | "x 下标 i" | 第 $i$ 个样本的 CLR 变换后特征向量（$p$ 维） |
| $\beta_0$ | "beta 零" | 截距项 |
| $\beta_j$ | "beta 下标 j" | 第 $j$ 个特征的回归系数 |
| $\lambda$ | "lambda" | L1 正则化强度（越大越稀疏） |
| $\sigma(\cdot)$ | "sigma" | sigmoid 函数，$\sigma(z)=\frac{1}{1+e^{-z}}$，把实数压到 (0,1) |
| $\hat{p}_i$ | "p 帽 下标 i" | 第 $i$ 个样本的预测患病概率 |
| $B$ | "B" | bootstrap 重抽样轮数（建议 50~100） |
| $\hat{\pi}_j$ | "pi 帽 下标 j" | 第 $j$ 个特征在 $B$ 轮中被选中的频率 |
| $\tau$ | "套" | 稳定特征入选频率阈值（0.5~0.6） |
| $\mathbb{1}\{\cdot\}$ | "指示函数" | 条件成立取 1，否则取 0 |
| $g(x)$ | "g 括号 x" | 几何均值，$g(x)=(\prod_{k=1}^{D}x_k)^{1/D}$ |
| $\binom{n}{k}$ | "n 选 k" | 组合数，从 $n$ 个中选 $k$ 个的方案数 |

### 3.2 Lasso 稀疏 Logistic 目标函数

对每个疾病，在训练折上最小化：

$$\min_{\beta_0,\beta}\ \underbrace{-\frac{1}{n}\sum_{i=1}^{n}\Big[y_i\log\hat{p}_i+(1-y_i)\log(1-\hat{p}_i)\Big]}_{\text{负对数似然（拟合误差）}}+\underbrace{\lambda\sum_{j=1}^{p}|\beta_j|}_{\text{L1 惩罚（稀疏化）}}$$

其中 $\hat{p}_i=\sigma(\beta_0+x_i^\top\beta)$。

- **第一项（负对数似然）**：衡量模型预测与真实标签的差距，越小拟合越好。
- **第二项（L1 惩罚）**：$\sum|\beta_j|$ 是系数绝对值之和，$\lambda$ 越大，越多的 $\beta_j$ 被压成**恰好为 0**——这就是「自动选特征」的代数来源（少而精）。
- **直觉解释**：L1 惩罚像「预算约束」——每保留一个非零系数都要「交税」，模型只肯为真正有用的特征「花钱」，其余系数被压成 0。

### 3.3 Bootstrap 出现频率

第 $j$ 个特征在 $B$ 轮 bootstrap 中的出现频率：

$$\hat{\pi}_j=\frac{1}{B}\sum_{b=1}^{B}\mathbb{1}\{\hat{\beta}_j^{(b)}\neq 0\}$$

其中 $\hat{\beta}_j^{(b)}$ 是第 $b$ 轮 bootstrap 重抽样上拟合的 Lasso 系数。

稳定特征集：$\hat{S}_\tau=\{j:\hat{\pi}_j\geq\tau\}$。

- **直觉解释**：像选「靠谱员工」——不看一次面试（单次 Lasso），看多次面试（bootstrap）里每次都表现好的人（高频率）。一次发挥好可能是运气，每次都稳才是实力。

### 3.4 CLR 中心对数比变换

对成分向量 $x=(x_1,\dots,x_D)$（$x_j>0$，$\sum_j x_j=1$）：

$$\text{clr}(x)_j=\ln x_j-\frac{1}{D}\sum_{k=1}^{D}\ln x_k=\ln\frac{x_j}{g(x)}$$

- **零值处理（乘法替换）**：零值先替换为伪计数 $\delta$（与 S1 一致），再重归一化到和为 1，然后取对数。
- **直觉解释**：像比较「家庭开支占比」——不能直接比「吃饭花 500 元 vs 5000 元」（总收入不同），要比「吃饭占收入 30% vs 50%」。CLR 把「绝对丰度」换成「相对比例」再进模型，消除「某物种升高必然挤压其他物种」的伪相关。

### 3.5 Wilcoxon 秩和检验（非零丰度信号）

对稳定特征，在**非零样本**上比较病组与健组的 CLR 丰度分布。将两组样本合并排序取秩，检验统计量 $U$ 基于秩和：

$$U=\min(U_1,U_2),\quad U_1=n_1n_2+\frac{n_1(n_1+1)}{2}-R_1$$

其中 $n_1,n_2$ 为两组样本数，$R_1$ 为病组秩和。$U$ 越小，两组分布差异越大。

- **直觉解释**：把两组样本的丰度混在一起从小到大排队，看「病组的人是不是都挤在队尾（或队头）」——挤得越极端，差异越显著。

### 3.6 Fisher 精确检验（存在/缺失信号）

对稳定特征，构建 2×2 列联表：

| | 患病 | 健康 | 行和 |
|:--|:--|:--|:--|
| 存在（非零） | $a$ | $b$ | $a+b$ |
| 缺失（零） | $c$ | $d$ | $c+d$ |
| 列和 | $a+c$ | $b+d$ | $n$ |

在「存在与否与疾病无关」的原假设下，观测到该表的概率服从超几何分布：

$$P=\frac{\binom{a+b}{a}\binom{c+d}{c}}{\binom{n}{a+c}}$$

Fisher 精确检验的 p 值 = 所有「比当前表更极端」的表概率之和。

- **直觉解释**：像问「这个店有没有卖某商品」——92% 的物种在大多数样本里「根本没出现」，所以「在不在」才是主要信号（F2）。

### 3.7 BH-FDR 校正

对 $m$ 个特征同时检验（**$m=1331$ 全特征规模**，2026-08-21 人类裁定：医疗宁可严格不可虚报——检验仅对过滤后 264 特征执行，但多重比较按全 1331 计数，取最严格口径），将 p 值升序排列 $p_{(1)}\leq p_{(2)}\leq\dots\leq p_{(m)}$，找最大的 $k$ 使：

$$p_{(k)}\leq\frac{k}{m}\alpha$$

拒绝 $H_{(1)},\dots,H_{(k)}$。$\alpha=0.05$。

- **直觉解释**：同时检验 1331 个特征，纯靠运气也会有几十个「碰巧显著」。FDR 控制「误报显著」的比例，防止「检验太多必然有几个假阳性」。

## 4. 求解方法

| 步骤 | 方法 | 实现要点 |
|:--|:--|:--|
| 1. 过滤 | 零值占比 >95% 剔除 | 每病独立计算零值占比，取三病并集或各病独立过滤（见 handoff 规格） |
| 2. CLR | 乘法替换 + 几何均值中心化 | 伪计数 δ 与 S1 一致 |
| 3. Lasso | `LogisticRegression(penalty='l1', C=...)` | C 与 λ 关系 $C=1/\lambda$；V6 用 C=0.1，正式实现给 C 范围 |
| 4. bootstrap | 分层重抽样 B=50~100 轮 | 每轮在重采样训练集上拟合 Lasso，记录非零系数 |
| 5. 频率 | $\hat{\pi}_j$ 统计 | 阈值 τ=0.5~0.6 |
| 6. 解释 | Fisher + Wilcoxon + BH-FDR | 两路信号 |
| 7. 共现分析 | Spearman 相关 + Fisher 共现检验 | 入选标志物两两相关矩阵 + 共现网络（§1.3b） |
| 8. 佐证 | RF 重要性 + PLS-DA VIP | VIP>1.5 或分位数 |

> **计算量提示（C8）**：B=50~100 轮 × 3 病 × Lasso 拟合，可并行（每轮独立）。预计单病单轮 Lasso 在 264 维 × 数百样本上 <1 秒，总时长可控；若超 2 分钟按 TRAE-规范 C4 交主会话后台执行。

## 5. 预期输出

1. **每病 Top 10~20 标志物清单**：稳定特征（频率 ≥ τ）+ 频率值 + 两路信号统计量（Fisher p、Wilcoxon p、FDR 校正后显著性）+ 丰度/存在趋势方向（升高/降低）。
2. **两路信号表**：每标志物标注「存在/缺失信号」还是「丰度信号」主导（F2 语义）。
3. **跨疾病标志物对比**：三病稳定特征集的 Jaccard 重叠 + 共同标志物 + 疾病特异性标志物（如 Fusobacterium nucleatum 的 CRC 特异性）。
4. **佐证一致性**：RF/VIP 与 Alpha 稳定特征的 Top-N 排名一致性（Spearman 相关或交集比例）。
5. **诚实标注**：全量选择（乐观）vs CV 内稳定频率（诚实）两套数字并列。
6. **共现分析**：每病标志物两两 Spearman 相关矩阵/热图 + 显著共现/互斥网络（§1.3b），配边界声明。

## 10. 方案讲解收束（math-explainer 6 条约束）

### 10.1 先定义再使用

见 §3.1 符号约定表，所有符号首次出现均给定义与读法。

### 10.2 每步有「因为」

- **为什么先过滤近全零**：因为 1067/1331 特征在 >95% 样本里都是 0（F3），几乎不携带判别信息，留着稀释 L1/RF 信号——过滤后 1331→264，降 80% 维度几乎不损失信息。
- **为什么必须 CLR**：因为 23~34% 特征对在 CLR 后相关方向翻转（F6），原始丰度上的相关是定和约束制造的伪相关，方向不可信。
- **为什么 τ 从 0.8 下调到 0.5~0.6**：因为频率≥0.8 只有 2 特征/病（F7），选不出 Top 10~20；频率分布连续长尾，0.5~0.6 是稳定簇与噪声分界。
- **为什么拆两路信号**：因为零值占比差与 AUC 相关（0.86~0.89）显著高于非零丰度差（0.63~0.67）（F2），「差异」主要来自「在不在」而非「多不多」。

### 10.3 多视角

- **几何视角**：CLR 把成分数据（约束在单纯形上，每行和为 1）映射到欧式空间，让 Lasso 的线性结构有意义——像把球面上的点投影到平面再画直线。
- **代数视角**：Lasso 的 L1 惩罚 $\sum|\beta_j|$ 天然产生稀疏解（很多系数恰好为 0），等价于「自动把不重要特征系数压成 0」。
- **统计视角**：bootstrap 聚合频率 = 用重抽样估计「选择结果的不确定性」，把「一次选择的方差」显式量化——频率低 = 方差大 = 不可信。

### 10.4 核心洞察收束

见 §0 一句话收束。

### 10.5 直觉解释（无公式类比）

- **稳定性选择**：选「靠谱员工」——看多次面试（bootstrap）里每次都表现好的人，一次发挥好可能是运气，每次都稳才是实力。
- **CLR**：比较「家庭开支占比」——比「吃饭占收入 30% vs 50%」而非「花 500 元 vs 5000 元」。
- **两路信号**：问「这个店有没有卖某商品」（在不在）和「卖的话卖得多不多」（丰度）是两个不同问题。

### 10.6 防跳跃（可能需要展开的概念点）

1. **BH-FDR 与 Bonferroni 的区别**：为什么 1331 次比较用 FDR 而非更严格的 Bonferroni。
2. **CLR 的伪计数处理**：乘法替换 vs 加法替换，不同 δ 对结果的影响。
3. **分层 CV 折内选择 vs 全量选择的泄漏差异**：为什么「先全量选特征再 CV」会高估性能。
4. **Lasso 的 λ（C）选择**：bootstrap 内每折的 λ 如何定（交叉验证 vs 固定 C），λ 对入选频率的影响。
5. **RF 重要性有偏的机制**：为什么杂质重要性偏好高基数/连续特征，permutation importance 是否更优。

## 11. 与 S1 联动

所选稳定特征集（每病 Top 10~20）即 S1 分类器的输入特征，形成「特征选择 → 分类建模」一致链路。S1 的 small_adenoma 敏感性分析结果反向约束 S2 的 CRC 标签口径（见 R4）。
