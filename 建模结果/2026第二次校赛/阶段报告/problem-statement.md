# 问题陈述拆解：B题 基于宏基因组数据的疾病预测模型研究

> 来源：`problems/2026第二次模拟赛赛题/B题 基于宏基因组数据的疾病预测模型研究/B题 基于宏基因组数据的疾病预测模型研究.doc`
> 数据：`data.csv` + `附录：数据解释.docx`（484 个公开宏基因组样本，3 种疾病）

## 核心问题

利用人类肠道宏基因组物种级相对丰度数据，构建机器学习模型预测疾病状态（结直肠癌/炎症性肠病/肥胖症 vs 健康对照），并评估特征选择与跨疾病泛化能力。

## 子问题拆解（3 个）

### S1 疾病预测模型
开发疾病预测模型（选择合适的指标），说明模型在疾病预测方面的表现；分析不同疾病数据集上模型性能的差异并探讨可能的原因。

- 实质：三个疾病数据集各自的二分类问题（cancer vs n、ibd vs n、obesity vs n）
- 交付：模型选择 + 性能指标（AUC/ACC/F1 等）+ 跨疾病性能差异分析

### S2 特征选择与生物标志物
开发有效的特征选择方法，从微生物组特征中筛选出对疾病预测最具影响力的特征子集；列出最重要的几个生物标志物（微生物），分析其在不同疾病状态下的相对丰度/存在情况变化趋势；对比不同疾病类型下微生物标志物的关系并分析原因。

- 实质：高维特征选择（数千列微生物特征）+ 生物标志物解释
- 交付：特征选择方法 + Top 生物标志物清单 + 丰度变化趋势图 + 跨疾病标志物对比分析

### S3 跨疾病预测模型
建立跨疾病预测模型，评估其跨疾病预测性能。注1：利用一种或两种疾病作为训练集，另外一种新的疾病作为测试集。注2：可利用微生物的分类学信息。

- 实质：迁移/泛化评估（leave-one-disease-out），可引入分类学层级特征聚合
- 交付：跨疾病模型 + 性能评估 + 失败/成功模式分析

## 要求产出

1. 建模过程：算法原理、模型构建步骤、参数选择依据（详细说明）
2. 每问：清晰分析结果 + 合理讨论（图表展示、统计分析、生物学意义）
3. 过拟合讨论：确保模型在独立数据集上的可靠性和泛化能力
4. 总结发现 + 未来研究方向/实际应用建议
5. 论文格式：A4、摘要单页、正文 ≤20 页、附录含完整可运行代码

## 显式约束

- 数据：484 样本，3 疾病（Zeller_fecal_colorectal_cancer / metahit / Chatelier_gut_obesity），每行 = dataset_name + disease + 物种级相对丰度特征（稀疏）
- 标签口径：Colorectal 中 cancer=患病其余健康；IBD 中 ibd_ulcerative_colitis 与 ibd_crohn_disease=患病；Obesity 中 obesity=患病
- 跨疾病定义：1-2 种疾病训练 → 另 1 种新疾病测试
- 可用信息：微生物分类学信息（特征名含 k__p__c__o__f__g__s__ 层级）

## 隐含约束

- 高维稀疏数据（数百~数千特征 vs 484 样本）→ 必须特征选择/正则化/降维，防止过拟合
- 三个疾病数据集样本量不平衡（Zeller 大肠癌数据集通常 ~156 样本，metahit ~110，Chatelier ~145）
- 跨疾病预测大概率性能显著下降（批次效应/疾病特异性微生物），需要合理的分析与讨论而非只报数字
- 生物学解释需要领域知识（已知标志物：结直肠癌相关 Fusobacterium nucleatum 等）
- 无外部验证数据，泛化评估靠内部交叉验证 + 跨疾病协议

## 数据线索

- `data.csv`：485 行（1 表头 + 484 样本）×（3 元数据列 + N 特征列），特征为物种级相对丰度（0-100 量级，大量 0）
- 特征名格式：`k__Bacteria|p__Firmicutes|...|s__X` 完整分类学层级
- `附录：数据解释.docx`：数据来源说明 + 疾病标签定义 + 分类学层级解释
