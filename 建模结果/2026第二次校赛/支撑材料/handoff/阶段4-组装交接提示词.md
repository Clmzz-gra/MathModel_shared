### 3.1 内容整合（md → LaTeX）

对每个队友模板，把正文转成 LaTeX 并入对应章节：

1. **正文段落**：md 正文直接转 LaTeX 段落（中文正文，`\paragraph`/普通段落即可）。md 中的行内公式 `$...$` 已是 LaTeX 语法，可直接保留；md 中的 `$$...$$` 块公式转 `\begin{equation}...\end{equation}`（已有 label 的保留，无 label 的按需补 `\label{eq:...}`）。
2. **表格**：md 表格（`|...|` 管道格式）转 LaTeX `tabular`/`longtable`。**列宽遵循 PR-013**：`p{}` 列宽比例总和 = 1.04 − 0.04×N（N=列数），所有列用 `>{\centering\arraybackslash}p{比例\textwidth}`。数字单元格不得改动。
3. **图引用**：md 中的 `![...](figures/xxx.pdf)` 转 `\begin{figure}[H]\centering\includegraphics[width=0.9\textwidth]{xxx.pdf}\caption{...}\label{fig:...}\end{figure}`。图文件从 `outputs/figures/` 复制到 `solution/final-paper/figures/`（13 张正式图：S1-roc-curve / S1-performance-compare / S1-adenoma-sensitivity / S1-feature-importance / S1-threshold-analysis / S2-stable-frequency / S2-tau-sensitivity / S2-cooccurrence-heatmap / S2-cross-disease / S3-strategy-compare / S3-decay-attribution / S3-migration-direction / S3-threshold-drift）。
4. **模型节（重点）**：主文件模型节是**内联结构**（子问题一/二/三），已预填公式/表格/图 + `% 队友写作：<指引>` 注释。整合方式：**以主文件预填骨架为底**（公式、结果表、图保留），把队友 md 的正文段落填入对应 `% 队友写作：` 位置；若队友 md 已含相同公式/表格（如 04 的 AUC 公式、四方案表），**去重保留一份**（优先队友 md 的表述，数字以 data-integration 为准）。`model-S1.tex / model-S2.tex / model-S3.tex` 是 8/21 旧版独立文件（主文件未 `\input` 它们），**忽略或删除，不得双份内容**。
5. **交叉引用**：正文引用图/表/公式用 `\cref{}`（cleveref 已配置中文前缀），禁止裸 `\ref{}`。
6. **符号统一**：使用 `preamble-common.tex` 已加载的宏；数学公式必须用 LaTeX 命令（`\theta` 而非 θ），禁止 Unicode 数学符号。

## 六、常见坑（前人踩过）

1. **工作目录**：`E:\MathModel_pj-2026-sim2-B`，不是 `E:\MathModel_pj`（glob/相对路径会解析错）。

6. **model-S1/S2/S3.tex 旧文件**：8/21 旧版，主文件未引用，忽略/删除，不得与内联模型节双份。
