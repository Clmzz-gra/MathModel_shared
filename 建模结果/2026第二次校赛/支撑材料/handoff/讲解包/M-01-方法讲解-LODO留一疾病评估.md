# M-01 · 方法讲解：LODO 留一疾病评估

## 一、这个方法解决什么问题

**LODO（留一疾病，leave-one-disease-out）** 是一种**评估协议**，回答的问题是：「模型到一个训练阶段从未见过的疾病上，还灵不灵？」

它适用于「跨域 / 跨组泛化」类评估场景——模型在若干来源（这里是疾病）上训练，要判断它能否泛化到新来源。在本赛题中，S3 用它来诚实评估跨疾病预测模型的性能。

**在本赛题哪些问中被用到**：S3 全问。四策略对比、紧急回退链、三视角性能探讨，全部在 LODO 协议下评估。

---

## 二、来龙（为什么选它）

**候选评估方式**：
- **随机划分（train/test 随机切）**：测试样本和训练样本来自同一批疾病，模型可能「见过」测试疾病的分布，跨疾病泛化能力被高估。
- **留一疾病（LODO）**：每次留一种疾病作测试集、其余作训练集，测试疾病在训练阶段**完全不可见**（标签和特征都不参与训练）。

**为什么选 LODO**：本问要回答的是「跨疾病」——如果测试疾病在训练时出现过，那测的就不是「跨疾病泛化」，而是「同分布内记忆」。LODO 保证测试疾病完全不可见，模型学到的是真正可泛化的判别，是「跨疾病」最诚实的评估方式。

**适用条件与边界**：LODO 需要至少 2 种训练疾病（留 1 作测试）。本问有 3 种疾病（CRC / IBD / Obesity），正好构成 3 个 LODO 组合。若疾病种类太少，LODO 组合数不足，评估不稳定。

---

## 三、主体（方法怎么用）

### 3.1 核心思想

把 $D$ 种疾病轮流留一种作测试集，其余 $D-1$ 种作训练集，共 $D$ 个组合。每个组合独立训练、独立评估，最后汇总。

本问 $D=3$，三个组合：
- **C1**：测试 CRC，训练 IBD + Obesity；
- **C2**：测试 IBD，训练 CRC + Obesity；
- **C3**：测试 Obesity，训练 CRC + IBD。

### 3.2 迷你算例：LODO 组合怎么构成（手算一遍）

**最小实例**：假设只有 3 种疾病，每种 2 个样本，共 6 个样本。

| 样本 | 疾病 | 标签（1=患病） |
|---|---|---|
| a | CRC | 1 |
| b | CRC | 0 |
| c | IBD | 1 |
| d | IBD | 0 |
| e | Obesity | 1 |
| f | Obesity | 0 |

**流程**：
1. 组合 C1：测试 = CRC 的 {a, b}，训练 = IBD 的 {c, d} + Obesity 的 {e, f}。在训练集上训练模型，在 {a, b} 上评估。
2. 组合 C2：测试 = IBD 的 {c, d}，训练 = CRC 的 {a, b} + Obesity 的 {e, f}。
3. 组合 C3：测试 = Obesity 的 {e, f}，训练 = CRC 的 {a, b} + IBD 的 {c, d}。

**为什么这个算例重要**：它说明 LODO 的「数字从哪来」——每个组合的测试疾病在训练时**完全没出现过**。C1 的模型从没见过 CRC 样本，C2 的模型从没见过 IBD 样本，C3 的模型从没见过 Obesity 样本。这样测出来的 AUC 才是「跨疾病」的真实水平。

### 3.3 在本赛题中的具体实例化

- 数据：0.3 清洗后物种级相对丰度，过滤后 264 特征、484 样本。
- 三个组合的测试集正类占比：C1 39.7%、C2 22.7%（少数类）、C3 64.8%（正类占多数）——数字来源 `strategy_compare.A_direct.C{1,2,3}.test_pos_frac`。
- 每个组合在训练集上训练模型、在测试集上算 AUC，得到 3 个 AUC，再取均值作为该策略的跨疾病性能。

## 四、去脉（结果解读与写作注意）

### 4.1 结果如何解读

- 每个策略得到 3 个组合的 AUC + 均值。均值 < 0.60 说明跨疾病直接迁移接近随机。
- 本问四策略均值全部 < 0.60（最优策略 A 0.5603），触发紧急回退。

### 4.2 可直接写进论文的结论句示例（2–3 句）

> ① 在留一疾病（LODO）协议下，测试疾病在训练阶段完全不可见，模型学到的是真正可泛化的判别能力。

> ② 四策略在 LODO 协议下的 3 组合 AUC 均值全部低于 0.60（最优策略 A 直接迁移为 0.5603），表明跨疾病直接迁移在当前数据下接近随机。

> ③ LODO 协议保证了跨疾病评估的诚实性——测试疾病标签与特征均不参与训练，避免了同分布内记忆对泛化能力的高估。

### 4.3 哪些是过度承诺、不能写

- ❌ **不能写**「LODO 下模型表现好所以跨疾病可行」——本问四策略均值全部 < 0.60，未达可用线。
- ❌ **不能写**「LODO 是唯一正确的评估方式」——它是「跨疾病」最诚实的评估，但不同评估目标（如域内性能）用不同协议。
- ❌ **不能写**「测试疾病完全不可见 = 模型一定泛化差」——LODO 只保证评估诚实，不预设结果方向。
