# M-01 方法讲解：稳定性选择（Lasso + bootstrap）

> 讲解包（供队友写作前建立技术理解）
> 对应内部报告：`math-S2.tex` §3（主方法）
> 数字口径：全部取自 `outputs/data/S2-results.pkl`，与写作素材同一组数字。

## 一、这个方法解决什么问题

**适用场景**：高维（特征数远大于样本数）、稀疏、小样本下的特征选择——要从成百上千个特征里挑出「真正稳定、可复现」的那几个，而不是被单次拟合的偶然性带偏。

**在本赛题哪些问中被用到**：S2（特征选择与生物标志物）的主方法，对 CRC/IBD/Obesity 三病独立执行，筛出每病稳定标志物。对应 `02-问题二分析与思路.md` 主体节第 3 步。

---

## 二、来龙（为什么选它）

**问题**：小样本（110~253 样本）对高维（264 特征）做特征选择，单次 Lasso 或单次 RF 重要性几乎不可复现——换一批样本，选出的特征就变了。这种「选择方差」是过拟合的根源。

**候选方法对比**：

| 候选 | 局限 |
|:--|:--|
| 单次 Lasso | 一次选择方差巨大，结果不可信 |
| 单次 RF 重要性 | 同样受单次拟合偶然性影响；Gini 重要性偏好高基数特征 |
| 神经网络 | 可解释性差，无法回答「哪些是标志物」 |

**为什么选 Lasso + bootstrap**：Lasso 的 L1 惩罚天然产生稀疏解（很多系数恰好为 0），是「自动选特征」的代数来源；bootstrap 重抽样把「一次选择的方差」显式量化——多次重抽样里被稳定选中的特征才是真信号。两者结合 = 「会自己挑重点的模型」+「多次面试看稳定性」。

**适用条件与边界**：适用于特征间冗余度不高的场景（本问已验证高相关边仅 21~30 条/300 特征，最大簇规模 4）；若特征高度共线，Lasso 会在共线组内任选，需先做去冗余。

## 三、主体（方法怎么用）

### 3.1 核心思想 + 公式

**Lasso 稀疏 Logistic 目标函数**（在训练折上最小化）：

$$\min_{\beta_0,\beta}\ \underbrace{-\frac{1}{n}\sum_{i=1}^{n}\Big[y_i\ln\hat{p}_i+(1-y_i)\ln(1-\hat{p}_i)\Big]}_{\text{负对数似然（拟合误差）}}+\underbrace{\lambda\sum_{j=1}^{p}|\beta_j|}_{\text{L1 惩罚（稀疏化）}}$$

其中 $\hat{p}_i=\sigma(\beta_0+\mathbf{x}_i^\top\beta)$，$\sigma$ 是 sigmoid 函数（把实数压到 0~1 之间）。

- 第一项（负对数似然）：衡量预测与真实标签的差距，越小拟合越好。
- 第二项（L1 惩罚）：$\sum|\beta_j|$ 是系数绝对值之和，$\lambda$ 越大，越多的 $\beta_j$ 被压成**恰好为 0**——这就是「自动选特征」的代数来源。
- **直觉**：L1 惩罚像「预算约束」——每保留一个非零系数都要「交税」，模型只肯为真正有用的特征「花钱」。

**bootstrap 出现频率**：

$$\hat{\pi}_j=\frac{1}{B}\sum_{b=1}^{B}\mathbb{1}\{\hat{\beta}_j^{(b)}\neq 0\}$$

其中 $\hat{\beta}_j^{(b)}$ 是第 $b$ 轮 bootstrap 重抽样上拟合的 Lasso 系数，$\mathbb{1}\{\cdot\}$ 是指示函数（条件成立取 1，否则取 0）。

**稳定特征集**：$\hat{S}_\tau=\{j:\hat{\pi}_j\geq\tau\}$，本问 $\tau=0.5$，$B=100$，$C=0.1$。

### 3.2 迷你算例（手动走一遍「数字从哪来」）

> 设一个极小的数据集：3 个样本、2 个特征（A、B）、1 个标签（患病/健康）。演示「bootstrap 频率 → 稳定特征」这一步。

- 样本：$s_1$（患病）、$s_2$（患病）、$s_3$（健康）。
- 特征 A、B 的 CLR 值：$s_1$: A=0.5, B=0.1；$s_2$: A=0.4, B=0.2；$s_3$: A=0.1, B=0.5。
- 做 B=3 轮 bootstrap（每轮从 3 个样本有放回抽 3 个，拟合 Lasso，记录哪些特征系数非零）：
  - 第 1 轮抽到 $\{s_1,s_1,s_3\}$：Lasso 选中 A（系数非零），B 被压成 0 → A 记 1 次。
  - 第 2 轮抽到 $\{s_1,s_2,s_2\}$：Lasso 选中 A、B → A、B 各记 1 次。
  - 第 3 轮抽到 $\{s_2,s_3,s_3\}$：Lasso 选中 B → B 记 1 次。
- 统计频率：$\hat{\pi}_A=2/3\approx0.67$，$\hat{\pi}_B=2/3\approx0.67$。
- 若 τ=0.5：A、B 均 ≥0.5，都入选稳定特征集。

**这个算例说明什么**：稳定频率不是「一次 Lasso 的结果」，而是「多次重抽样里被选中的比例」。真实数据 B=100 轮，频率 0.99 表示「100 轮里 99 轮都被选中」——这才是「稳定」的含义。

### 3.3 在本赛题中的具体实例化

- 三病独立执行，不跨病混合（批次效应强，混合会引入伪信号）。
- 参数：τ=0.5、B=100（全量）/ B=50（CV 折内）、C=0.1。
- 结果：CRC 4 个稳定标志物（频率 0.99/0.94/0.62/0.52）、IBD 4 个（0.81/0.75/0.55/0.53）、Obesity 20 个（Top 0.89/0.84/0.72…）。
- 诚实标注：全量 bootstrap 频率（乐观）与 CV 折内频率（诚实）两套数字并列（如 CRC 的 Peptostreptococcus_stomatis 全量 0.99 / CV 0.96）。

## 四、去脉（结果解读与写作注意）

**结果如何解读**：稳定频率越高，标志物越「稳」；频率刚过阈值（如 0.52）且检验不显著的是低置信边缘，需与高置信核心区分。

**常见误读**：把「稳定频率」当成「效应大小」——频率只说明「被选中的稳定性」，不说明「影响多大」，效应大小要看方向与显著性。

**可直接写进论文的结论句示例（2-3 句）**：

1. 「采用 Lasso 稀疏 Logistic 结合 bootstrap 稳定性选择（τ=0.5，B=100），在严格正则口径（C=0.1）下，结直肠癌与炎症性肠病各筛出 4 个高置信稳定标志物。」
2. 「稳定标志物的 bootstrap 入选频率远高于阈值（如 CRC 的 Peptostreptococcus_stomatis 频率 0.99），表明选择结果对重抽样扰动稳健，非单次拟合的偶然。」
3. 「全量 bootstrap 频率（乐观）与 CV 折内频率（诚实）两套数字并列，CV 折内频率（如 CRC 的 P.stomatis 0.96）为可泛化的诚实估计。」

**哪些是过度承诺、不能写**：

- 不能写「稳定标志物就是因果标志物」——稳定性选择只保证「可复现」，不证明因果。
- 不能写「Obesity 的 20 个标志物可信」——其 FDR 全 >0.05，是弱信号，须标注低可信度。
- 不能写「RF 与 Lasso 一致」——RF 佐证层退化不可用（见 M-05）。
