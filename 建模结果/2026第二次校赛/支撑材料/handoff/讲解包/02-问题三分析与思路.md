## 一、整体认知

**本问解决什么问题**：题面 S3 要求「建立一个跨疾病预测模型，并探讨模型在跨疾病预测上的性能」。这里的核心词是**跨疾病**——模型在若干种疾病上学到的判别能力，能不能迁移到训练阶段**从未见过**的另一种疾病。通俗说：用「结直肠癌 + 炎症性肠病」的数据训练一个「这人有没有病」的分类器，拿去给「肥胖症」的新样本判病，还灵不灵？

**在论文中的位置**：终稿第 N 章「跨疾病预测模型」。本章回答「模型到新疾病上还灵不灵」，是整篇论文里偏「方法 + 结果」的一章，不涉及新的数据采集。

**输入 / 输出 / 依赖**：
- 输入：0.3 清洗后的物种级相对丰度数据（三疾病并集统一口径，过滤后 **264 个物种特征**、**484 个样本**；CLR 变换零值替换常数 $6.5\times10^{-6}$）。
- 输出：四策略跨疾病 AUC 对比 → 最优可达模型 → 三视角性能探讨（衰减归因 / 深度迁移 / 阈值漂移）。
- 依赖上游：策略 A 沿用 S1 已验证的模型口径（L2 正则 + CLR）；深度迁移分析可与 S2 生物标志物结论交叉核对。

**一句话收束**：本问用「留一疾病」的诚实协议，把「跨疾病到底行不行」量化成一组 AUC 数字，结论是——在当前数据与协议下未达可用线，但给出了完整证据链和明确改进方向。

## 二、来龙（为什么用这个方法）

**备选方案有哪些**：要评估「跨疾病泛化」，最直接的做法是把模型从训练疾病搬到测试疾病。围绕「怎么搬、搬什么」，有四种候选策略：

| 策略 | 思路（一句话） | 为什么被考虑 |
|---|---|---|
| A 直接迁移 | 训练疾病上训好的模型原样搬到测试疾病 | 最朴素、最直接的基线 |
| B 共享标志物 | 只保留三疾病都出现的物种（疾病无关特征）重训 | 若疾病特异信号在拖后腿，去掉它看能否恢复 |
| C 分类学聚合 | 把物种特征按属/门层级聚合（利用分类学信息） | 回应题面注 2「可利用微生物分类学信息」 |
| D 部署校正 | 在最优策略上叠加概率校准，修复可部署指标 | AUC 与阈值无关，但 ACC/F1 会因患病基线不同而失准 |

**为什么最终用「四策略对比 + LODO」**：
- 单一策略无法回答「跨疾病行不行」——必须**在同一协议下对比**，才能看出哪种「搬法」最好。
- 评估协议选 **LODO（留一疾病，leave-one-disease-out）**：每次留一种疾病作测试集、其余两种作训练集，共 3 个组合。它保证测试疾病在训练阶段**完全不可见**（标签和特征都不参与训练），是「跨疾病」最诚实的评估方式——模型学到的是真正可泛化的判别，而不是「见过这个病」的假象。
- 关键取舍：**防泄漏**。测试集上禁止重定阈值、禁止用测试集标签做任何特征选择，否则数字虚高、论文结论站不住。

**为什么还要「紧急回退」**：四策略均值全部低于可用线 0.60 后，不能直接说「不行」就交差——按人类裁定，先尽力交付模型，失败证据链是穷尽努力后的最后结论。于是设计回退链 R1–R4（树模型 → 样本合并 → 密度比重加权域适应 → 对抗式域适应），逐级尝试更复杂的模型族。

## 三、主体（模型怎么建）

### 3.1 决策变量 / 目标 / 约束

- **决策变量（模型选择）**：在 A/B/C/D 四策略中选一个作为交付模型；若全部不达标，在回退链 R1–R4 中选最优可达者。
- **目标函数（主指标）**：**AUC**（曲线下面积，Area Under the ROC Curve）。AUC 衡量「随机抽一个患病样本、一个健康样本，模型给患病样本打更高分的概率」，取值 0–1，0.5 等于瞎猜。它**与阈值无关**，是最诚实的排序能力指标。
- **辅指标**：ACC / 灵敏度 / 特异度 / F1，用训练集 **Youden J 最优阈值**（灵敏度+特异度−1 最大处）迁移到测试集计算。**禁止在测试集重定阈值**（会用到新疾病标签，泄漏）。
- **约束（防泄漏边界）**：特征选择、标准化、校准参数、阈值全部只用训练集估计；测试疾病标签全程不参与。

### 3.2 迷你算例：AUC 这个数字从哪来（手算一遍）

AUC 是全文最核心的数字，先搞懂它怎么算，后面所有「0.56、0.60」才有意义。

**最小实例**：假设测试集只有 4 个样本，真实标签和模型打分如下：

| 样本 | 真实标签（1=患病） | 模型打分 |
|---|---|---|
| 甲 | 1 | 0.8 |
| 乙 | 0 | 0.3 |
| 丙 | 1 | 0.6 |
| 丁 | 0 | 0.2 |

**决策变量→目标→结果的流程**：
1. 按打分从高到低排序：甲(0.8, 患病) > 丙(0.6, 患病) > 乙(0.3, 健康) > 丁(0.2, 健康)。
2. 数「患病 vs 健康」的所有配对，看患病样本打分是否更高：
   - 甲 vs 乙：0.8 > 0.3 ✓
   - 甲 vs 丁：0.8 > 0.2 ✓
   - 丙 vs 乙：0.6 > 0.3 ✓
   - 丙 vs 丁：0.6 > 0.2 ✓
3. 4 对全部正确 → AUC = 4/4 = **1.0**（完美排序）。

**为什么这个算例重要**：它说明 AUC 不是「准确率」，而是**排序质量**——只要患病样本普遍比健康样本打分高，AUC 就高，哪怕阈值定得不好。这正是 S3 里「AUC 接近随机（0.525）而可部署指标崩溃（灵敏度 0.024）」能同时发生的原因：排序能力差（AUC 低）且阈值迁移后决策边界失准（可部署指标崩）。

### 3.3 四策略构建（数字来源：`strategy_compare`）

| 策略 | 构建方式 | C1(CRC) | C2(IBD) | C3(Obesity) | 均值 |
|---|---|---|---|---|---|
| A 直接迁移 | L2+CLR 物种级 264 维 | 0.5674 | 0.5882 | 0.5253 | **0.5603** |
| B 共享标志物 | 共享特征子集 252 个重训 | 0.5417 | 0.6080 | 0.5218 | 0.5572 |
| C 属级聚合 | 属级 106 维 + CLR | 0.3616 | 0.4861 | 0.5440 | 0.4639 |
| C 门级聚合 | 门级 11 维 + CLR | 0.4141 | 0.5261 | 0.5999 | 0.5134 |
| D 部署校正 | 策略 A + Platt 校准 | 0.5674 | 0.5882 | 0.5253 | 0.5603 |

- 数字来源：`S3-results.pkl strategy_compare.{A_direct,B_shared,C_genus,C_phylum,D_calibrated}.{C1,C2,C3}.auc` 与 `.mean_auc`。
- 三个组合：C1 测试 CRC（训练 IBD+Obesity）、C2 测试 IBD（训练 CRC+Obesity）、C3 测试 Obesity（训练 CRC+IBD）。
- 观察：A/B 均值都在 0.56 附近（接近随机 0.5）；C 属级/门级更低；D 与 A 相同（Platt 是单调变换，不改排序，所以不改 AUC）。

### 3.4 紧急回退链（数字来源：`fallback`）

四策略均值全部 < 0.60 → 触发回退（`fallback.triggered=True`）。逐级尝试：

| 回退层级 | 模型族 | 均值 | 达可用线？ |
|---|---|---|---|
| R1 树模型 | RandomForest 500 树 | 0.5092 | 否 |
| R2 样本合并 | Logistic（≡ 策略 A） | 0.5603 | 否 |
| R3 密度比重加权 | importance weighting（域分类器法） | **0.6068** | 否（提升 +0.0465 < 0.10） |
| R4 对抗式域适应 | DANN | 0.5947 | 否 |

- 数字来源：`S3-results.pkl fallback.R{1,2,3,4}_*.mean_auc`。
- 可用线定义：均值 ≥ 0.65 **或** 相对策略 A 提升 ≥ 0.10。R3 最优可达 0.6068，仍低于 0.65，且相对 A 只提升 +0.0465，未达线。
- 结论：`fallback.usable=False`、`delivered_strategy=None`、`best_strategy=R3_weighted`、`best_mean_auc=0.6068`、`usable_line=0.65`。

### 3.5 三视角性能探讨（数字来源：`decay_attribution` / `migration_analysis` / `threshold_drift`）

**衰减归因（三分法）**：把每个低 AUC 组合的失败归因到三个互斥来源——批次效应 / 疾病特异信号 / 标签语义漂移。

| 疾病 | 域内 AUC | 跨疾病 AUC | 衰减量 | 主导归因 |
|---|---|---|---|---|
| CRC | 0.7811 | 0.5674 | −0.2138 | 疾病特异信号 |
| IBD | 0.8588 | 0.5882 | **−0.2706** | 疾病特异信号（最强） |
| Obesity | 0.6638 | 0.5253 | −0.1384 | 标签语义漂移 |

- 数字来源：`S3-results.pkl decay_attribution.{CRC,IBD,Obesity}.{domain_auc,cross_auc,decay,dominant_cause}`。
- 衰减量 = 跨疾病 AUC − 域内 AUC。域内 AUC 为 264 特征 5 折 CV 重算，与跨疾病同口径（**不是** A3 的 1331 特征参考值）。

**深度迁移**：共享物种的丰度变化方向跨疾病是否一致。方向一致 387 个 / 方向翻转 369 个，共 756 个有效共享物种，一致占比 **51.2%**，符号检验 **p=0.5364**（不显著）。数字来源：`migration_analysis.{direction_consistent_count,direction_flipped_count,consistent_fraction,sign_test_pvalue}`。

**C3 阈值漂移**：训练患病基线 0.316 vs 测试 0.648，基线差 Δ=+0.332；Youden 阈值 τ\*=0.9205 落在测试分布 **96.0% 分位**，灵敏度仅 **0.024**。数字来源：`threshold_drift.{train_baseline,test_baseline,delta_baseline,youden_threshold,boundary_position,sensitivity}`。

### 3.6 六轮归因实验证据链（E0–E6，2026-08-22 补充）

> 为排除「是不是模型没选对」的替代解释，正式实现之外又完成六轮归因实验（全部复用 LODO 同口径），逐轮证伪——跨疾病失败收敛为**数据固有限制**。详细报告见 `solution/model-notes/experiment-e{0,1,2,3,5,6}-*.md`；论文正文写法见本文件 §六 第 5 步（压缩为一段+一表）。

| 实验 | 检验的替代解释 | 关键结果 | 结论 |
|---|---|---|---|
| E0 ComBat 批次校正 | 三数据集=三批次，失败是批次伪影？ | 校正后 0.5603 → **0.4960**（更差） | 证伪：不是批次 |
| E1 免训练/低容量基线 | 模型容量不足（欠拟合）？ | NCM 0.5362/0.5594、PLS-DA 0.5574/0.5798，全部 ≤ 基线 | 证伪：天花板与容量无关 |
| E2 贝叶斯模型族 | 稀疏先验/贝叶斯框架可突破？ | 贝叶斯 L2/ARD 0.5746/0.5748 ≈ 基线；S1 域内 ARD 不提升 | 证伪：L2 已近上限 |
| E3 few-shot 敏感性 | LODO 零样本协议过严？ | k=50 均值 0.5898（+0.030，仍 <0.60）；C1 达 0.6567 | 证伪：信号稀缺为真 |
| E5 源分离+融合 | 合并训练稀释源信号？ | 融合均值 0.5996（+0.039），C1 融合 0.6273 | 部分证伪：有增益不达线；合并确实稀释源信号 |
| E6 深度学习直接分类 | 深度表示可突破？ | MLP 均值 0.5814（<DANN 0.5947）；**C1 0.6852 为 C1 方向迄今最高** | 证伪（均值层面）：深度无效；C1 方向例外 |

**判读（写作时用）**：六类替代解释全部排除 → 跨疾病负结果收敛为**数据固有限制（疾病特异信号不迁移 + 标签语义漂移）**；失败**方向不对称**——C1(CRC) 存在弱可迁移信号（few-shot 0.6567、MLP 0.6852），C2(IBD) 不可学（0.5212），C3(Obesity) 语义漂移（灵敏度 0.024→0.402 但 AUC 上限 0.59）。「三种疾病之间完全没有可迁移信息」的说法不成立，准确说法是「**统一跨疾病模型不可交付，泛化强度不足且方向高度异质**」。

## 四、去脉（结果怎么看、写作注意）

### 4.1 关键结果含义与量级

- 四策略均值全部 < 0.60，最优策略 A 直接迁移 0.5603——**跨疾病直接迁移接近随机**，说明「把训练疾病模型原样搬到新疾病」基本不灵。
- 回退链穷尽后最优可达 **R3 加权域适应 0.6068**，仍低于可用线 0.65——**在当前数据与协议下，跨疾病预测未达可用水平**。
- 衰减归因：主导来源是**疾病特异信号**（IBD 衰减最大 −0.271）与**标签语义漂移**（Obesity）——模型学的是「训练疾病特有的标志物」，搬到新疾病就失效。
- 深度迁移：共享物种方向一致性接近随机（51.2%，p=0.536）——**共享物种的存在性不承载可迁移信号**，信号藏在疾病特异方向里。
- C3 阈值漂移：训练/测试患病基线差 +0.332，阈值落 96% 分位，灵敏度 0.024——**标签语义漂移导致决策边界失准**，AUC 与可部署指标分离。
- 证据链（2026-08-22 补充）：六轮归因实验（批次/容量/模型族/协议/组合/深度学习）全部无法突破可用线——**不是模型没选对，是数据里没有可迁移的信号**；且失败方向不对称（CRC 方向存在弱可迁移信号，few-shot 0.6567 / MLP 0.6852）。

### 4.2 可直接写进论文的结论句示例（2–3 句）

> ① 在留一疾病（LODO）协议下，四种跨疾病建模策略的 3 组合 AUC 均值全部低于 0.60（最优策略 A 直接迁移为 0.5603），触发紧急回退；回退链 R1–R4 中密度比重加权域适应（R3）达到最优可达均值 0.6068，仍低于可用线 0.65，故本问以「最优可达 + 完整证据链」交付，未宣称可用模型。

> ② 衰减归因显示跨疾病性能损失的主导来源为疾病特异信号（IBD 衰减最大 −0.271）与标签语义漂移（Obesity）；共享物种方向一致性接近随机（51.2%，符号检验 p=0.536），表明共享物种的存在性不承载可迁移信号。

> ③ C3 阈值漂移量化显示训练/测试患病基线差 Δ=+0.332，Youden 阈值落在测试分布 96.0% 分位，灵敏度仅 0.024；Platt 校准为单调变换不改变决策边界，无法修复 C3 可部署指标。

> ④ 为排除模型侧替代解释，完成六轮归因实验：ComBat 批次校正后 AUC 反而下降（0.5603→0.4960）、免训练/低容量基线持平（≤0.58）、贝叶斯模型族持平（0.575）、few-shot 仅 +0.030（0.5898）、源分离融合 +0.039（0.5996）、深度学习均值持平（0.5814），均无法突破可用线——跨疾病泛化受限收敛为数据固有限制（疾病特异信号不迁移 + 标签语义漂移），且失败方向不对称（CRC 方向存在弱可迁移信号）。

### 4.3 哪些说法是过度承诺、不能写

- ❌ **不能写**「跨疾病模型不可行」的绝对结论。本问结论是「在当前数据与协议下未达可用线」，改进方向（更多疾病/更大样本、目标疾病阈值重定、疾病特异方向信号）仍开放。
- ❌ **不能写**「R3 加权域适应是可用模型 / 交付模型」。0.6068 是最优可达性能，未达可用线 0.65。
- ❌ **不能写**「域内 AUC 与跨疾病 AUC 混用口径」。域内 AUC 是 264 特征 5 折 CV 重算（与跨疾病同口径），不是 A3 的 1331 特征参考值（CRC 0.814 / IBD 0.885 / Obesity 0.644）。
- ❌ **不能写**「AUC 高所以模型可部署」。C3 的 AUC 0.525 接近随机而可部署指标崩溃（灵敏度 0.024），必须标注「AUC 与可部署指标分离」。
- ❌ **不能写**「换深度学习/更大模型就能解决跨疾病」。E6 MLP 均值 0.5814 甚至低于域适应 DANN 0.5947；C1 方向 MLP 0.6852 最强但均值层面无效（484 样本训深网方差极大，宽网络 C1 崩到 0.4914 低于随机）。
- ❌ **不能写**「三种疾病之间完全不存在可迁移信息」。证据链显示方向不对称：CRC 方向可学（few-shot 0.6567 / MLP 0.6852），准确表述是「统一跨疾病模型不可交付，泛化强度不足且方向高度异质」。

### 4.4 口径边界（写作时务必声明）

1. 特征集口径：264 物种级特征（三病并集统一口径，与 S1/S2 一致），非 A3 的 1331 全集。
2. 主指标 AUC 阈值无关；辅指标为训练集 Youden 阈值迁移（禁测试集重定阈值）。
3. R3 密度比方法：域分类器法（Logistic 区分 train/test，w=exp(logit)×n_train/n_test，裁剪上界 10），转导式边界（用测试特征、不用测试标签）。
4. R2 ≡ 策略 A：LODO 已合并 2 训练疾病，R2 样本合并与策略 A 数学恒等，不提供增量。

## 六、论文叙事主线（6 步）与答辩要点

> 论文「模型三」正文叙事 + 答辩讲解的统一主线，把六轮实验（E0–E6）、回退（R1–R4）、四策略对比压缩成一条线性逻辑链。数字只取 pkl 实际值。

**叙事逻辑**：诚实评估 → 正面尝试 → 穷尽手段 → 数据归因 → 排除替代 → 方向结论。
**核心一句话**：*「我们不是没做好，是数据里没有可迁移的信号。」*

**第 1 步 · 问题与协议：用最诚实的尺子量泛化**
模型在训练时**从未见过的疾病**上还灵不灵（跨疾病泛化）。用 LODO 留一疾病——每次留一种疾病作测试、其余两种训练，测试疾病完全不可见（标签、特征均不参与训练），避免「测试疾病信息泄漏」的乐观偏差。3 组合：C1 测 CRC（训练 IBD+Obesity）、C2 测 IBD（训练 CRC+Obesity）、C3 测 Obesity（训练 CRC+IBD）。

**第 2 步 · 正面尝试：四种策略全部低于 0.60**
A 直接迁移 0.5603（基线）→ B 共享标志物 0.5572 → C 分类学聚合 0.4639/0.5134 → D Platt 校准 0.5603（AUC 不变）。全部接近随机线 0.5：直接迁移基本失败；共享物种、分类学信息、概率校准都不救。

**第 3 步 · 紧急回退：穷尽模型侧手段，最优仍不可用**
四策略均值全部 < 0.60 触发回退（可用线：均值 ≥ 0.65 或相对基线提升 ≥ 0.10）。R1 树模型 0.5092 → R2 样本合并 0.5603（≡A）→ **R3 密度比重加权 0.6068（最优可达）** → R4 对抗式域适应 0.5947。从线性到树到域适应全部试过，最优仍 < 0.65——**模型侧手段已穷尽**。

**第 4 步 · 数据归因：失败在数据，不在模型**
域内 AUC 0.78~0.86（很强）→ 跨疾病 0.53~0.59（塌缩）。IBD 衰减最大（−0.2706，学的是 IBD 特有标志物）；共享物种方向一致性 51.2%（p=0.5364 不显著，存在性不承载信号）；C3 阈值漂移（训练患病基线 0.3160 vs 测试 0.6482，Δ+0.3322，Youden 阈值落 96.0% 分位，灵敏度 0.0244）——**三个数据集「患病」的定义并不等价**。主因 = **疾病特异信号 + 标签语义漂移**（数据固有）。

**第 5 步 · 排除替代解释：六轮实验，证据链闭环（论文压缩为一段+一表）**

| 实验 | 排除的解释 | 关键结果 |
|---|---|---|
| E0 ComBat 批次校正 | 批次伪影 | 0.5603 → 0.4960（更差） |
| E1 免训练/低容量基线 | 容量不足 | NCM/PLS-DA 全部 ≤ 0.58 |
| E2 贝叶斯模型族 | 模型族/稀疏先验 | 贝叶斯 L2/ARD 0.575 ≈ 基线 |
| E3 few-shot 敏感性 | 协议过严 | k=50 仅 0.5898（仍 <0.60） |
| E5 源分离+融合 | 合并训练稀释 | 融合 0.5996（+0.039，未达可用线） |
| E6 深度学习直接分类 | 深度表示能力 | MLP 均值 0.5814（<R4 DANN 0.5947）；C1 0.6852 为 C1 方向最高 |

六类替代解释全部排除——负结果不是「没做好」，是数据里没有可迁移的信号。

**第 6 步 · 方向性结论与部署建议：负结果也有价值**
统一跨疾病模型不可交付（最优可达 0.6068 < 0.65）；但失败方向**不对称**——CRC 方向有弱可迁移信号（few-shot 0.6567、源分离融合 0.6273、MLP 0.6852 为 C1 方向最高），IBD 不可学（0.5212），Obesity 语义漂移（灵敏度 0.024→0.402 但 AUC 上限 0.59）。部署：域内模型为主 + 跨疾病仅作参考；CRC 方向定向迁移有微弱价值。改进：更大规模多疾病数据、标签定义对齐（统一患病标准）。

**论文取舍与答辩弹药**
- 正文保留第 1–4、6 步（协议/策略/回退/归因/结论）；第 5 步压缩为一段+一表；六份实验报告进附录/支撑材料。
- 答辩弹药：
  - 被问「是不是模型不行」→ 第 5 步六轮实验（批次/容量/模型族/协议/组合/深度全排除）；
  - 被问「为什么不用深度学习」→ E6 MLP 均值 0.5814（<R4 DANN 0.5947）+ E1 容量谱系（零参数→对抗式仅 +0.06）；但 C1 方向 MLP 0.6852 反而最强（方向不对称的又一佐证）；
  - 被问「负结果有什么价值」→ 第 6 步方向性结论 + 部署建议（域内为主、CRC 定向迁移）；
  - 被问「为什么不用更大模型/更多数据」→ 数据固有限制（信号不迁移），改进方向明确。
