## 一、整体认知

**本问解决什么问题**：从 1331 个高维稀疏的肠道微生物物种特征中，为三种疾病（结直肠癌 CRC、炎症性肠病 IBD、肥胖症 Obesity）**各自独立**筛出「稳定、可解释、生物合理」的 Top 生物标志物，并解读这些标志物在不同疾病下的丰度/存在变化趋势，以及跨疾病的关系。

**在论文中的位置**：本问是「特征选择与生物标志物」章，紧接 S1（疾病预测模型）之后。S1 用分类器预测疾病状态，本问回答「**是哪些微生物在驱动预测**」——筛出的稳定标志物集即 S1 分类器的输入特征，形成「特征选择 → 分类建模」的一致链路。

**输入 / 输出 / 依赖**：
- 输入：三个宏基因组数据集的物种级相对丰度矩阵（CRC 121 样本 / IBD 110 / Obesity 253，过滤后 264 个特征）。
- 输出：每病稳定标志物清单（含频率、显著性、方向、已知对照）、两路信号表、共现网络、跨疾病对比。
- 依赖上游：S1 的 small_adenoma 标签口径（本问 CRC 按题面口径「归健康」执行，若 S1 改口径需重跑，见去脉节）。

**一句话收束**：CRC 与 IBD 各筛出 4 个高置信稳定标志物（CRC 3/4 命中已知标志物、IBD 4/4 Fisher 显著），Obesity 筛出 20 个但全部 FDR 不显著（弱信号）；三病标志物完全疾病特异（Jaccard 全 0）；判别信号几乎全为「存在/缺失」主导。

## 二、来龙（为什么用这个方法）

**问题难点**：高维（1331 特征）稀疏（92% 零值）小样本（110~253 样本）下，特征选择结果本身方差巨大——单次选出的「最影响」标志物很可能是过拟合的假象。同时，相对丰度是「定和成分数据」（每行加起来约 100），一种菌升高必然挤压其他菌，直接建模会产生伪相关。

**备选方案与排除理由**：

| 候选 | 为什么被排除 |
|:--|:--|
| 单次 Lasso / 单次 RF 重要性 | 小样本下单次选择几乎不可复现，选择方差巨大，结果不可信 |
| 神经网络 / 深度模型 | 可解释性差，无法回答「哪些微生物是标志物」；小样本易过拟合 |
| 全特征两两交互建模 | 1331 特征两两交互约 88 万对，小样本下不可行 |
| 直接对原始丰度做线性模型 | 定和约束制造伪相关，系数方向不可信（CLR 后 23~34% 特征对方向翻转） |

**最终选择的方法链**：近全零过滤（1331→264）→ CLR 变换（解除定和伪相关）→ **Lasso + bootstrap 稳定性选择**（τ=0.5，B=100，C=0.1）→ 两路信号检验（Fisher 存在/缺失 + Wilcoxon 非零丰度，BH-FDR m=1331）→ 共现分析（二阶初探）→ VIP 佐证（独立复现）。

**关键取舍**：
1. **为什么用 bootstrap 聚合频率**：把「一次选择的方差」显式量化——频率低 = 方差大 = 不可信。像选「靠谱员工」：不看一次面试，看多次面试里每次都表现好的人。
2. **为什么 τ 从 0.8 下调到 0.5**：频率≥0.8 每病只有 2 个特征，选不出 Top 10~20；频率分布连续长尾，0.5~0.6 是稳定簇与噪声的分界。
3. **为什么拆两路信号**：数据显示「在不在」（存在/缺失）比「多不多」（丰度）更能区分疾病（零值占比差与 AUC 相关 0.86~0.89 > 非零丰度差 0.63~0.67），所以把「差异」拆成两个独立问题分别检验。
4. **为什么 FDR 按 m=1331 全特征校正**：医疗领域宁可严格、不可虚报——检验只对过滤后 264 特征执行，但多重比较按全 1331 计数，取最严格口径。

## 三、主体（模型怎么建）

> 方法细节与完整公式见「详见 M-01 稳定性选择」「M-02 CLR 变换」「M-03 两路信号检验」「M-04 共现分析」「M-05 VIP 佐证」。本节给流程骨架 + 一个可手算的迷你算例。

**流程骨架（每病独立执行）**：

1. **近全零过滤**：剔除零值占比 >95% 的特征（1067 个），保留 264 维。因为 92% 的物种在大多数样本里「根本没出现」，留着只会稀释信号。
2. **CLR 变换**：把「加起来等于 100 的成分」翻译成「每个物种相对本样本平均水平的对数比」，解除定和伪相关。
3. **Lasso + bootstrap 稳定性选择**：B=100 轮分层重抽样，每轮拟合 Lasso 稀疏 Logistic，统计每个特征「被选中（系数非零）」的频率 $\hat{\pi}_j$；频率 ≥ τ=0.5 的特征入选稳定特征集。
4. **两路信号检验**：对入选稳定特征做差异检验——Fisher 精确检验（存在/缺失）+ Wilcoxon 秩和检验（非零丰度），均做 BH-FDR 校正（m=1331）。
5. **共现分析**：对入选标志物两两算 Spearman 相关 + Fisher 共现检验，输出共现/互斥网络（二阶初探）。
6. **VIP 佐证**：PLS-DA 的 VIP>1.5 特征清单作独立复现证据（RF 佐证层退化不可用，见去脉）。

**迷你算例（手动走一遍「数字从哪来」）**：

> 设一个极小的数据集：3 个样本、2 个特征（A、B）、1 个标签（患病/健康）。目标：演示「bootstrap 频率 → 稳定特征」这一步的数字来源。

- 样本：$s_1$（患病）、$s_2$（患病）、$s_3$（健康）。
- 特征 A、B 的 CLR 值（已变换好）：$s_1$: A=0.5, B=0.1；$s_2$: A=0.4, B=0.2；$s_3$: A=0.1, B=0.5。
- 做 B=3 轮 bootstrap（每轮从 3 个样本中有放回抽 3 个，拟合 Lasso，记录哪些特征系数非零）：
  - 第 1 轮抽到 $\{s_1,s_1,s_3\}$：Lasso 选中 A（系数非零），B 被压成 0 → A 记 1 次。
  - 第 2 轮抽到 $\{s_1,s_2,s_2\}$：Lasso 选中 A、B → A、B 各记 1 次。
  - 第 3 轮抽到 $\{s_2,s_3,s_3\}$：Lasso 选中 B → B 记 1 次。
- 统计频率：$\hat{\pi}_A = 2/3 \approx 0.67$，$\hat{\pi}_B = 2/3 \approx 0.67$。
- 若 τ=0.5：A、B 均 ≥0.5，都入选稳定特征集。

**这个算例说明什么**：稳定频率不是「一次 Lasso 的结果」，而是「多次重抽样里被选中的比例」。真实数据里 B=100 轮，频率 0.99 表示「100 轮里 99 轮都被选中」——这才是「稳定」的含义。真实结果中 CRC 的 Peptostreptococcus_stomatis 频率 0.99，就是 100 轮 bootstrap 里 99 轮被 Lasso 选中。

## 四、去脉（结果怎么看、写作注意）

### 4.1 关键结果与量级

**CRC（4 个稳定标志物，3 个 Fisher 显著，3/4 命中已知）**：

| 标志物 | 频率 | Fisher q | 方向 | 已知 |
|:--|:--|:--|:--|:--|
| Peptostreptococcus_stomatis | 0.99 | 1.24e-05 | up（患病富集） | ✅ |
| Fusobacterium_nucleatum | 0.94 | 3.94e-05 | up | ✅ |
| Porphyromonas_somerae | 0.62 | 0.0172 | up | ✅ |
| Clostridium_hathewayi | 0.52 | 0.599 | up | — |

- 前 3 个 Fisher 显著且为已知 CRC 标志物，构成**高置信核心**；Clostridium_hathewayi 频率刚过阈值、Fisher 不显著，为**低置信边缘**。

**IBD（4 个稳定标志物，4/4 Fisher 显著）**：Alistipes_finegoldii（0.81, down）、Bifidobacterium_bifidum（0.75, up, 已知属）、Akkermansia_muciniphila（0.55, down）、Eubacterium_ventriosum（0.53, down）。Akkermansia_muciniphila 是文献公认的 IBD 保护菌（丰度降低），方向 down 生物合理。

**Obesity（20 个稳定标志物，0 个 FDR 显著）**：Top 为 Ruminococcus_flavefaciens（0.89）、Pseudoflavonifractor_capillosus（0.84）、Rothia_mucilaginosa（0.72）…全部 fisher_q>0.05，**弱信号、低可信度**。

**两路信号**：三病稳定标志物几乎全为 presence（存在/缺失）主导（CRC/IBD 全 presence，Obesity 18/20 presence + 2 abundance）；稳定标志物中**无一个** Wilcoxon 显著——判别信号以「在不在」为主，丰度信号缺失。

**共现**：CRC 4 条边全 cooccur（最强对 Peptostreptococcus_stomatis↔Fusobacterium_nucleatum，Spearman 0.762、OR=12.86）；IBD 6 条边（3 cooccur + 3 exclude，Bifidobacterium_bifidum 与其余 3 个标志物全部互斥）。

**跨疾病**：三病两两 Jaccard 全 0，无共同标志物，完全疾病特异。

**佐证**：VIP>1.5 特征数 CRC 28 / IBD 27 / Obesity 23，与 Lasso 稳定标志物 Spearman 秩相关 0.539 / 0.515 / 0.347（中等正相关）；CRC/IBD 的稳定标志物全部出现在 VIP>1.5 清单（4/4），Obesity 仅 2/20——VIP 佐证对 CRC/IBD 成立。

### 4.3 哪些是过度承诺、不能写

- **不能写「CRC 4 个标志物全部命中已知标志物」**：pkl 中 Clostridium_hathewayi 的 known=False，仅 3/4 命中（见写作素材禁写句）。
- **不能写「Obesity 标志物显著」**：20 个稳定标志物 FDR 全 >0.05，是弱信号，必须显式标注低可信度，不夸大。
- **不能写「共现为因果/协同机制」**：共现分析仅对入选标志物做二阶初探，小样本下无法全特征交互建模，只能作初探证据放讨论节，不改变主选择口径。
- **不能写「RF 与 Lasso 一致」**：RF permutation importance 全部退化（~1e-17），RF 佐证层不可用，仅以 VIP 作独立复现佐证。
- **不能写「Wilcoxon 显著」**：稳定标志物中无一个 Wilcoxon 显著（q>1 判不显著，数值不展示）。

### 4.4 口径边界（写作注意）

- 主口径 C=0.1（CRC/IBD 各 4 个高置信标志物）；C=0.5 的 19/17 扩展清单（C 敏感性快查值）作补充（附录/讨论），不改变主口径。
- 诚实标注：全量 bootstrap 频率（乐观）与 CV 折内频率（诚实）两套数字并列（如 CRC 的 P.stomatis 全量 0.99 / CV 0.96）。
- small_adenoma 口径：S2 按题面口径（归健康）执行；若 S1 改口径，S2 CRC 需重跑（A 级待核验）。
