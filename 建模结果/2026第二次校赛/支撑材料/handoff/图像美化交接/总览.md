## 一、美化铁律（违反任一条 = 打回）

1. **数字一个都不能改**（见置顶规则 3）。
2. **MATLAB 只画不算**（见置顶规则 2）。特别提醒：
   - 直方图必须显式传 `'BinEdges'`（见 §二 对应表），否则 MATLAB 默认分箱与数据不符；
   - 堆叠条形遇 NaN 列先 `fillmissing(...,'constant',0)`（腺瘤列仅 CRC 有）。
3. **硬约束不能破**：
   - 条形图/面积图必须从 0 开始（禁止截断 Y 轴放大差异）；
   - 禁止 3D、禁止彩虹渐变色；
   - 配色用 Okabe-Ito 系（蓝 `#1f77b4` / 橙 `#d62728` / 绿 `#2ca02c`，去饱和），灰度打印后可辨；
   - 同一变量全文同色（三数据集 = 蓝/绿/橙，全论文一致）；
   - 中文正常显示（MATLAB 中文需设置字体：`set(groot,'defaultAxesFontName','SimHei')` 或 `Microsoft YaHei`，标题/标签逐个指定也行；确保不出现方框乱码）。
4. **核心元素别删**：参考线（随机 0.5 / 可用线 0.65 / 0.95 阈值线）、误差棒、CV 诚实频率标注、p 值、阈值线、数量标注、解读注释——**删了图就失去说服力**。每张图的证据性元素见 §三 ⚠ 标注。
5. **重绘方式**：`readtable('data/fig-xxx.csv')` → 中文标签 → 画 → 导出 **PDF**（矢量）→ 另存 `-v2` 命名，不覆盖原图。
6. **版本与回传**：改完打包发回给我方，我方替换仓库正式版并登记版本。你不需要管 git/路径。
7. **加新图/改图型**：不要自己造数——把需求（要表达什么结论）发给我方，我方从实验数据重算后给你新 CSV 与参考。

## 五、队友 MATLAB 重绘工作流

1. **读数据**：`T = readtable('data/fig-xxx.csv')`（中文编码没问题，BOM 已带）。
2. **看原图**：打开 `charts/fig-xxx.pdf`，目标是**数值一致 + 中文标签 + 样式可美化**地复刻。
3. **画**：按 §二 建议命令 + 中文标签（对照《中英条目对照.md》）：
   - `set(groot,'defaultAxesFontName','SimHei')` 或 `Microsoft YaHei`（中文不乱码）；
   - 配色 Okabe-Ito（蓝 `#1f77b4` / 橙 `#d62728` / 绿 `#2ca02c`）；
   - 数值/参考线/误差棒/注释全部来自 CSV 或标量文件——**禁止手输**。
4. **检查**（对照 §一 铁律逐条过）：中文全 ✓ 数字未改 ✓ 参考线/误差棒/注释在 ✓ 零基线 ✓ 无 3D/彩虹 ✓ 灰度可辨 ✓
5. **导出**：`exportgraphics(gcf,'fig-xxx-v2.pdf','ContentType','vector')`（PDF 矢量）；**另存 -v2，不覆盖原图**。
6. **回传**：全部 `-v2` PDF 打包发回；不需要发脚本/CSV（我方都有）。
7. **后续**：我方替换仓库正式版并登记版本；你若要继续微调，以我方回传的最新版为准。
