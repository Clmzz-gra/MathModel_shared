# 符号说明

> **模板说明**：对应 `final-paper/notation.tex`。预填三子问题共享符号表（md 表格），队友可增补。符号来源 `solution/model-notes/math-S1.tex / math-S2.tex / math-S3.tex`。正文首次出现处均有内嵌定义（自足性符号表）。

| 符号 | 定义 | 首次出现 |
|:--|:--|:--|
| $n$ | 某数据集的样本总数（Zeller=121 / metahit=110 / Chatelier=253） | 见第 1 节过滤式 |
| $p$ | 过滤后特征维数（原始 $p_0=1331$，近全零过滤后 $p=264$） | 见第 1 节过滤式 |
| $x_{ij}$ | 第 $i$ 个样本第 $j$ 个物种的相对丰度 | 见第 1 节过滤式 |
| $\delta$ | 零值乘法替换伪值 $=6.5\times10^{-6}$（检出限的 0.65 倍） | 见第 1 节 CLR 式 |
| $\mathrm{clr}(x_{ij})$ | 中心化对数比变换（CLR） | 见第 1 节 CLR 式 |
| $g_i$ | 第 $i$ 个样本的几何均值 $g_i=\big(\prod_j x_{ij}\big)^{1/p}$ | 见第 1 节 CLR 式 |
| $y_i$ | 第 $i$ 个样本的真实标签（患病=1 / 健康=0） | 见第 1 节 Logistic 式 |
| $\sigma(\cdot)$ | sigmoid 函数 $\sigma(z)=1/(1+e^{-z})$ | 见第 1 节 Logistic 式 |
| $\mathbf{w},b$ | Logistic 权重向量 / 截距 | 见第 1 节 Logistic 式 |
| $\lambda$ | 正则强度（L2 惩罚系数） | 见第 1 节损失式 |
| $w_c$ | class_weight 中类别 $c$ 的样本权重 | 见第 1 节 Logistic 式 |
| $\mathrm{AUC}$ | ROC 曲线下面积（主指标，阈值无关） | 见第 1 节 AUC 式 |
| $\hat{\pi}_j$ | 第 $j$ 个特征在 $B$ 轮 bootstrap 中的入选频率 | 见第 2 节稳定式 |
| $\tau$ | 稳定特征入选频率阈值（$=0.5$） | 见第 2 节稳定式 |
| $m$ | BH-FDR 多重比较规模（$=1331$ 全特征） | 见第 2 节 FDR 式 |
| $\alpha$ | FDR 显著性水平（$=0.05$） | 见第 2 节 FDR 式 |
| $\mathcal{T}_k,\mathcal{E}_k$ | 第 $k$ 组合的训练集 / 测试集（LODO） | 见第 3 节 LODO 式 |
| $f(\mathbf{x})$ | 模型原始分数（logit） | 见第 3 节 Platt 式 |
| $A,B$ | Platt 校准的尺度 / 平移参数（$A<0$） | 见第 3 节 Platt 式 |
| $\tau^{*}$ | Youden J 最优阈值 | 见第 3 节 Youden 式 |
| $\Delta_d$ | 疾病 $d$ 的跨疾病衰减量（跨疾病 AUC $-$ 域内 AUC） | 见第 3 节衰减式 |

> **注**：md 版以「见第 X 节」替代 `.tex` 的 `\cref{}` 标签；正文首次出现处仍须一句话内嵌定义。
