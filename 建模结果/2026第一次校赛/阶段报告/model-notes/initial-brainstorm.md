# 初始头脑风暴：C题 — 竞赛网评结果的建模与分析

> 阶段 0.1 产出 | 2026-07-28

## 关键洞察

1. **这是一个"元评审"问题** — 不是评价论文，而是评价评审机制本身。类似于教育测量中的"评分者信度研究"，但又叠加了双阶段机制的特殊性。

2. **数据不对称** — 只有网评原始分和最终奖项，缺少集中评审阶段的具体评分。这意味着子问题 1（相关性分析）只能间接度量。

3. **隐变量问题** — 论文的真实质量无法直接观测，只能通过多位评委的评分汇总来逼近。这使评委素质评估成为一个"盲估计"问题。

4. **五个题目 = 五个独立数据集**。评委 ID 的命名规则（专家A##、专家B## 等）暗示不同题目使用不同评委池，但需要验证。

## 方法论思考

### Q1 相关性分析
- 网评标准分均值 vs 最终奖项等级 → Spearman 相关
- 关键：网评排名前 55% 的论文与实际获奖的交叉验证
- 如果网评为 z-score，但集中评审阶段的评委也独立评分，网评的价值在于"初步筛选"而非"精确排序"

### Q2 指标体系
- 借鉴 Stemler (2004) 三维框架：共识（agreement）、一致性（consistency）、测量（measurement）
- 扩展到五维：加入准确性（以最终成绩为锚点）和稳定性
- 注意区分"评委之间的差异"和"评委与真实的差异"——前者是信度，后者是效度

### Q3 模型构建
- 多指标综合评价 → 可用熵权法 + TOPSIS，避免主观赋权
- 也可以用主成分分析（PCA）从多个指标中提取综合素质因子
- 每位评委的评分数据量不同（评委的阅卷量可能差异很大），需考虑样本量对指标可靠性的影响

### Q4 组间差异
- 需先确认评委是否跨题——如果 A 题和 B 题使用完全不同评委池，组间比较时要注意论文难度差异的混杂效应
- 可能需要用"相对素质"（评委在其所在题目组内的排名）而非绝对分数来跨题比较

### Q5 网评优化
- 当前权重 1/4 → 可以探索最优权重（通过交叉验证或模拟）
- 考虑引入"评委可信度"动态权重——素质高的评委权重更高
- 潜在方案：岭回归权重、贝叶斯加权平均

## 潜在风险

1. 如果不同题目论文质量分布差异大，跨题比较评委素质需要标准化
2. 评委阅卷量不足时，统计指标（如 ICC）不可靠
3. 最终奖项是离散三级 + 未入围，信息损失较大
4. 集中评审评委信息缺失——最本质的局限
