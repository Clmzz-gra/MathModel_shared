## 聚类方法

特点：整体评分偏高，属于"较宽松"评委群体。题目分布：A=8, B=9, C=11, D=21, E=15（C/E 题比例更高）。

## 数据质量标志

- 两簇之间主要差异在于评分绝对值（严格 vs 宽松），而非区分度或一致性
- B 题簇0占比高（46/55=84%），说明 B 题评委整体偏严格
- C 题簇1占比高（11/20=55%），说明 C 题评委相对宽松
- **这可能导致跨题比较困难**：同样的论文质量在 B 题评委手中可能得分低于 C 题

## 对建模的启示

- 评委聚类揭示了"评分尺度"是最主要的分群维度
- Q2/Q3 中应将"偏差控制"作为核心评价维度
- 跨题比较（Q4）需考虑题目间评委尺度的系统性差异
