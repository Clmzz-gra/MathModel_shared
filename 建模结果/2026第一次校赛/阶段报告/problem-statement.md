# 问题陈述：C题 — 关于某竞赛网评结果的建模与分析

> 阶段 0.1 产出 | 2026-07-28

---

## 核心问题

基于竞赛双阶段评审数据，评估网评有效性、构建评委素质评价模型，并提出评审流程优化建议。

## 竞赛评审流程

1. **网评阶段**：每篇论文随机分配给 4 位评委，百分制评分。通过标准分公式（z-score）将原始分转换为标准分，按标准分总分排名，**前 55% 进入集中评审**。
2. **集中评审阶段**：每篇论文由 3 位评委独立评审（百分制），评审结束后换算为标准分。
3. **最终成绩**：$\frac{\text{三个集中评审标准分} + \text{网评平均标准分}}{4}$

**标准分公式**：
$$z_i = \frac{x_i - \bar{x}}{\sigma}$$
其中 $\bar{x}$ 为该评委所评阅所有论文的平均分，$\sigma$ 为标准差。

## 子问题拆解

### 子问题 1：网评与终评相关性分析
**描述**：量化网评成绩与最终成绩的相关性，并从多角度评价网评结果的有效性。
**输入**：5 个题目（A~E）的网评原始分 + 最终奖项等级
**输出**：相关性系数 + 网评质量多维度评估报告
**与其他子问题的关系**：为 Q5（网评利弊分析）提供数据基础

### 子问题 2：评委素质指标体系
**描述**：从不同角度出发，构建合理的度量评委基本素质的指标体系。
**输入**：教育测量学/心理测量学的评委素质理论框架 + 附件数据结构
**输出**：多维度指标体系（含各维度的定义和度量方法）
**与其他子问题的关系**：为 Q3（数学模型）和 Q4（题目间差异分析）提供评价维度

### 子问题 3：评委素质数学模型
**描述**：建立评价评委基本素质的数学模型，应用于附件数据并给出结论。
**输入**：Q2 的指标体系 + 附件 A~E 全部数据
**输出**：每位评委的综合素质评分 + 排名 + 分类 + 结论分析
**与其他子问题的关系**：依赖 Q2 的指标体系，为 Q4 提供个体评委得分

### 子问题 4：不同题目评委表现差异分析
**描述**：分析 A/B/C/D/E 五个题目中评委整体表现的显著差异及可能原因。
**输入**：Q3 的个体评委素质评分 + 题目标签
**输出**：差异显著性检验 + 差异原因分析
**与其他子问题的关系**：依赖 Q3 的评分结果

### 子问题 5：网评成绩利用策略
**描述**：分析将网评成绩加入总成绩的利弊，给出更有效利用网评成绩的建模建议。
**输入**：Q1 的相关性结论 + Q3 的评委素质结论 + 其他子问题的综合发现
**输出**：利弊分析表 + 改进建议方案（可能含权重优化等）
**与其他子问题的关系**：综合 Q1-Q4 的全部结论

## 子问题依赖关系

```
Q2 (指标体系) ──┐
                ├──→ Q3 (评委素质模型) ──→ Q4 (题目间差异分析)
                │                              │
Q1 (相关性分析) ─┴──────────────────────────────┴──→ Q5 (网评利用策略)
```

**建议攻克顺序**：Q2 → Q3 → Q1 → Q4 → Q5
- 先做 Q2+Q3 因为指标体系是后续所有子问题的基础
- Q1 与 Q3/Q4 可独立进行，但 Q5 必须最后做（综合所有结论）

## 要求产出

- Q1：相关性系数表 + 网评有效性评价报告
- Q2：评委素质指标体系表
- Q3：评委素质得分表 + 排名 + 分类
- Q4：差异显著性检验结果 + 原因分析
- Q5：利弊对比表 + 改进方案

## 显式约束

- 数据来源：附件 A~E.xlsx（5 个题目的评审数据）
- 网评阶段：4 位评委，百分制，标准分归一化
- 集中评审：3 位评委，百分制，标准分归一化
- 最终成绩：网评平均标准分 + 集中评审 3 个标准分，求平均
- 前 55% 论文进入集中评审

## 隐含约束

- 评委来自不同题目组（A~E 使用不同专家池？需要从数据中确认评委 ID 是否跨题目出现）
- 论文质量是隐变量（无法直接观测，只能通过评委评分推断）
- 评委可能同时参与多个题目的评审（影响 Q4 的独立性假设）
- 集中评审的评委可能与网评评委重叠或不重叠（题目未明确）
