# 图像美化操作规范

## 目录结构

```
汇总/
├── paper/               ← 论文 .tex + .pdf
├── charts/              ← 所有图表 PDF（原地替换）
├── code/                ← 所有 Python 脚本
├── data/                ← 建模中间数据（.pkl）
├── explore-results/     ← 探索结果（weighting/ + cv-method/）
├── 图像-代码对应表.md    ← 图表与脚本的对应关系
└── 操作规范.md           ← 本文件
```

## 核心规则（违反即编译失败）

### 1. 文件名绝对不能改

LaTeX 通过文件名引用图表。改名 = 编译报错，必须严格保持一致。

charts/ 下的 20 个 PDF 文件名如下，**一个字符都不能改**：

```
cluster-tsne.pdf
pca-scree.pdf
q1-hit-rate.pdf
q1-rho-bars.pdf
q1-roc-curves.pdf
q1-scatter-matrix.pdf
q2-indicator-architecture.pdf
q3-cluster-scatter.pdf
q3-elbow-silhouette.pdf
q3-entropy-weights.pdf
q3-radar.pdf
q3-ranking-lollipop.pdf
q3-topsis-hist.pdf
q4-dimensions-box.pdf
q4-dunn-matrix.pdf
q4-topsis-box.pdf
q5-alpha-by-topic.pdf
q5-demotion-suggestion.pdf
q5-weight-sensitivity.pdf
q5-weighted-comparison.pdf
```

### 2. 输出格式必须为 PDF 矢量

- 不接受 PNG/JPG/SVG
- 字体必须嵌入 PDF（Illustrator/Matplotlib 默认嵌入）
- 存储位置：直接覆盖 `charts/` 下同名文件

### 3. 尺寸自由，LaTeX 自动缩放

论文中已指定了宽高比（如 `width=0.5\textwidth`），输出任意尺寸均可。建议宽高比 4:3 避免缩放后留白。

### 4. 修改流程

1. 查 `图像-代码对应表.md`，找到目标图表对应的生成脚本
2. 在 `code/` 中修改对应脚本
3. 运行脚本，确认输出覆盖 `charts/` 下同名 PDF
4. 替换汇总文件夹中的 PDF
5. 编译 `paper/main.tex` 验证

### 5. 编译验证

```bash
cd paper/
xelatex main.tex
```

确保无报错（允许 underfull/overfull hbox 警告）。如果报 `File not found`，检查 charts/ 下文件名是否与上面列表一致。

### 6. 禁止事项

- 禁止修改 `paper/main.tex` 中的任何 `\includegraphics` 路径
- 禁止新增或删除 charts/ 中的文件
- 禁止修改 `\graphicspath{{../charts/}}` 路径配置
