## 代码依赖关系

```
c0_data_clean.py     → combined-clean.pkl
c2_q1q4_model.py     → Q1/Q4 建模输出
c2_q2q3_model.py     → Q2/Q3 建模输出 (judge-profile.pkl, q3-judge-scores.pkl)
c2_q5_model.py       → Q5 建模输出 (alpha_results)
c3_generate_charts.py → 绝大多数图表（依赖上述模型输出）
gen_q5_alpha_charts.py → q5-weight-sensitivity.pdf + q5-alpha-by-topic.pdf（依赖 c2_q5_model.py 的 alpha_results）
```
