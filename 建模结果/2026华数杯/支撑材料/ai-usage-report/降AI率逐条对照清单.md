# 降 AIGC 率逐条对照清单（华数杯 2026-C）

> 用法：拿到一段原文，逐条过。命中任一条即改。
> 正反例全部引自 `降AI率方法收集.md` 中的原文与反馈，不另造。

---

## 1. 主语
- [ ] 每句都有主语。不能出现"可以发现""经分析发现""概览…可以发现"等无主句。

  反例：概览题目所给出的六份附件信息，可以发现其数据体量庞大、变量维度多元、时间跨度长，是典型的工业级时间序列与运营数据集合。

  正例：我们概览了题目给出的六份附件，发现数据体量庞大、变量维度多元、时间跨度长。

## 2. 括号
- [ ] 括号里的内容展开为独立短句，不允许 `（…）` 嵌入句子。

  反例：该架构将变量空间压缩约 1 × 10⁵ 倍（36.6M → 223 个 0-1 变量），以可量化的次优性代价换取可解性。

  正例：变量从 36.6M 压到 223 个，压缩了约 10⁵ 倍。代价是精度略有损失，换来的是问题可解。

## 3. 引号
- [ ] 不给概念打引号标签。直接陈述事实。

  反例：表 5 呈现了一组典型的"一升一降"权衡格局：碳感知调度的总成本比零迁移基线增加了约2.0%，但碳排放大幅降低了 32.7%，说明本方案以小幅成本增量为代价换取了显著的碳排削减收益。

  正例：表 5 列出了成本与碳排的变化。碳感知调度的总成本比零迁移基线增加了约 2.0%，碳排放降低了 32.7%。本方案以小幅成本换取了显著的碳排削减收益。

## 4. 冒号与破折号
- [ ] 冒号、破折号全都删掉。拆成多句，用句号连接。

  反例（冒号嵌套）：假设 1：六区域电力系统独立运行，不考虑跨区域潮流。说明：赛题说明 7 明确"不建模跨区域功率交换电网模型"，且各区域独立配有购电上限、售电上限和储能设备，区域间的耦合仅通过任务迁移产生的 IT 负荷转移实现。这一假设将六区域优化问题解耦为可独立求解的电力平衡子问题，大幅降低模型复杂度。

  反例（破折号插论证）：问题四与问题三的负荷结构不同——E、F 区的最小固定负荷购电碳排已超过问题三的基线值，若直接沿用问题三的碳基准将使主解不可行。

  正例：赛题说明 7 已明确不做跨区域功率交换，各区域配有独立的购售电上限和储能。区域间的耦合仅通过任务迁移实现。在这个假设下，六个区域的电力平衡可以独立求解。问题四和问题三的负荷结构不一样。E、F 区归入问题四后，最小固定购电碳排已经超过问题三给出的基线值。这种情况还沿用原来的基准，解直接不可行。

## 5. 超长句
- [ ] 逗号 ≥3 个的句子必拆（句子结构已经出问题）。另外，一个完整语义说完就用句号，不要用逗号续着往下堆。

  反例：本文针对算电协同多目标调度优化问题，基于50000条AI工作负载轨迹和六区域电力市场数据，以运行成本最小化与碳排放控制为目标，建立了一系列逐步递进的数学模型，完成了从基础算力调度到多区域算-储-电协同优化的完整求解。

  正例：本文针对算电协同下的多目标调度。研究数据是 50000 条工作负载轨迹，加六区域电力市场数据。目标两条：运行成本要低，碳排放要控住。模型从基础算力调度做起，逐步加入碳感知、储能，最终做到多区域算-储-电协同。

## 6. 抽象名词
- [ ] 包装性名词全部换成具体说法。

  成本增量 → 成本

  权衡格局 → 趋势（或直接删引号）

  次优性代价 → 精度损失 / 次优

  资源利用尽可能均衡 → 利用率尽量均衡

  提供了定量决策依据 → 删除，直接给结论

## 7. 名词来源
- [ ] 赛题里有的用赛题原词。赛题里没有的，首次出现时先下定义再用。

  碳基准 → 碳基准排放量（赛题可算出的量）

  碳帽 → 碳排放 ε 约束

  主解 → ε=1.00 档的解。若想简称，首次出现时交代"后文称主解"

  碳感知 → 赛题无此词。首次出现："本文把这种考虑碳排放的调度方式称为碳感知调度"

  基荷 / 基荷预填 → 首次出现：定义什么是基荷、为什么这么做

  新能源基荷匹配 → 首次出现：定义

## 8. 技术论证边界
- [ ] 成熟技术不解释原理。直接写做了什么、结果如何。

  反例：然而，极差作为目标函数在 MILP 框架下可通过线性化技术（引入辅助变量与两组约束）精确处理，无需二次规划——这在零迁移、区域间总 GPU 消耗恒定的设定下尤为重要。

  正例：然而，极差作为目标函数在 MILP 框架下可通过线性化精确处理，无需二次规划。
