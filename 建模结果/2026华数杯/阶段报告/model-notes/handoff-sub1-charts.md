## 1. 数据源与口径（必须逐位对应，防口径漂移）

### 1.1 甘特图（sub1-gantt-last24h.pdf）

| 项 | 规格 |
|----|------|
| 数据源 | `outputs/data/s1-schedule-test.pkl` → `alpha` 字段（任务 id → 开工小时） |
| 任务集 | 538 任务：160 实时（到达即开工）+ 378 自由（Alpha MILP 解，极差 0.6283） |
| 任务条 | 横 = 小时，起点 = 开工小时，长度 = `EstimatedDuration_min/60`（精确小数） |
| 时域 | 主窗 [2376, 2399] 到达；跨 2399 任务延伸至 [2400, 2406) 收尾（须画入） |
| 着色 | 按 TaskType：AITraining=#333333 / BatchInference=#1f77b4 / RealTimeInference=#d62728（chart-generator 去饱和） |
| 关键数字 | 538 任务 / 378 自由 / 极差 0.6283 / 超容量 0 |

**已知问题（v1，需图表智能体处理）**：
- **信息过载**（确认书 §6 风险项）：538 任务单图堆叠，y 轴 538 行不可读 → 建议按**区域分面（6 子图）**或按**任务类型分面（3 子图）**聚合，每子图任务条数 ≤200
- **收尾任务缺失风险**：v1 只画 `h < 2400` 的任务，跨 2399 的任务条延伸可能被截断 → 须确认 [2400,2406) 结清任务完整显示
- **y 轴标注**：任务条须可辨识（当前按到达排序无任务 id），建议在条上标 TaskID 或按区域分组

### 1.2 GPU 利用率曲线（sub1-utilization.pdf）

| 项 | 规格 |
|----|------|
| 数据源 | 由 `s1-schedule-test.pkl` 的 alpha/beta 开工表 + `schedule_input.base` 重算（evaluate 逻辑，见 `sub1-model.py` L330-348） |
| 曲线 | 6 区域 × 2 方案（Alpha 实线 #1f77b4 / Beta 虚线 #d62728），横 = 相对小时（2376=0），纵 = 利用率 |
| 口径 | $u_{r,t} = (\sum a_{j,h,t}x_{j,h} + B_{r,t}) / \text{Cap}_r$（math-sub1.tex \eqref{eq:util}） |
| 关键数字 | Alpha 极差 0.6283 / 方差 0.043992；Beta 极差 0.8398 / 方差 0.037166；超容量 0 |
| 标注 | 每子图标题标 `Cap_r`（A:630...F:966） |

**已知问题（v1）**：
- 纵轴上限：利用率上界应为 1.0，须确认所有曲线 ≤1（超容量=0 保证）
- 横轴范围：应为 [2376, 2406) 全窗口，确认含收尾时段利用率

## 2. 阶段 2.1.5 门禁审查要点（图表智能体初查 + 人类复审）

对每张图逐项检查（chart-generator 出图前检查清单 + 数据正确性）：

- [ ] **数据正确性**：图数值与 `s1-schedule-test.pkl`/缓存一致（极差 0.6283/0.8398，超容量 0）
- [ ] **量纲/坐标**：横轴小时单位、纵轴利用率 [0,1]；甘特图横轴小时、条长=时长(h)
- [ ] **类型匹配**：甘特图用条形（barh）；利用率用折线；ACF 用针状/条形；预测对比用折线+竖虚线分隔
- [ ] **自明性**：脱离正文可读——标题、轴标签、图例齐全
- [ ] **格式**：PDF 矢量、SimHei 中文字体、去饱和配色、线宽 1.5-2pt、无 3D/阴影
- [ ] **信息密度**：甘特图经分面后单图任务 ≤200，可读
- [ ] **收尾时段**：甘特图含 [2400,2406) 结清任务；利用率曲线含收尾段
