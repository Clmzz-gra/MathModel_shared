## 4. 报告必写素材（关键发现）

1. **净购电波动反升（重要，诚实呈现）**：成本最小化目标下储能执行峰谷套利（低价时段充电→购电升高，高价时段放电→购电降低），**优化解净购电 std（686）高于无储能（365）与基准（602），且峰值撞 MaxGridImport 反升** → 问题三"负荷波动"指标在纯成本目标下不降反升，削峰与降本在此受限口径下冲突。**建议报告明确"若以削峰/稳波动为目标需引入多目标扩展"**（衔接 B2 占位）。
2. **成本优于基准的"诚实对照"（M2-b 已裁定）**：直接对比优化（2213.35）> 基准（1802.34）会误导——基准含卖电收入且违反 SOC(2406)≥Initial（不可比）；用 B3 剔除卖电后基准 = 2231.50 > 2213.35，储能优化仍更优。
3. **碳排近乎无压缩空间（2.1）**：受限消纳 + 负荷固定 + 储能容量有限 → 碳排由刚性购电主导，ε_min∈[0.957,0.994]，这是 D4（主解 ε=1.00、碳排作评价指标）的量化依据。
4. **卖电消失的机制**：D/E/F SellPrice≤Price 恒成立（无套利窗口）+ 受限消纳下新能源优先直供/充电（R+Cr 用满 cap）→ S≈0（D/E/F 仅 0–0.8 GWh）；基准卖电 426–479 GWh 不可复现（其轨迹非最优且违规终态）。
5. **储能价值 = 调度优化 + 终态合规**（M2-c 限定叙事）：受限口径下储能贡献为成本 −7.3%、碳 −3.0%，来源于充放调度优化与 SOC(2406)≥Initial 合规，而非消纳提升（利用率锁死 20.8% = 基准能力）。
6. **碳–成本–峰值三难（2.2）**：撞顶 16–18% 小时集中于最高碳强度时段，峰值升高是"碳帽 + 受限消纳 + 负荷刚性"耦合的真实代价。
