# C 题 初始方案头脑风暴（initial brainstorm）

> 阶段 0.1 problem-init 步骤 5 产出 | 2026-08-07 | 仅思路梳理，不求解

## 0. 总体定位

本题为**多阶段递进优化**问题：预测（S1 前半）→ 任务调度（S1 后半/S2）→ 储能（S3）→ 全系统协同（S4）。
四个子问题逐步放开自由度：S1 无迁移、S2 加迁移+开工时段、S3 固定任务调度只调储能、S4 全部放开并做多目标权衡。

## 1. S1 GPU 需求统计分析与短期预测 + 基础调度

**统计分析维度**：
- 按区域 × 任务类型 × 小时聚合 GPU 需求量（5 万任务 → 6 区域 × 3 类型 × 2400h 面板）
- 日周期性（PricePeriod 峰谷平联动）、任务到达强度分布、GPU_Demand 分布（长尾？）

**预测模型候选**：
- 基线：Last-Hour / 季节朴素（同小时前一天）
- 统计：ARIMA/Prophet（季节项）+ 外生变量（PricePeriod）
- 深度：LSTM/GRU、Transformer 系（Autoformer/TimesNet）
- 知识卡提示：PF-003 ARIMA 在非平稳序列失败 → 需先做平稳性/周期性诊断（AL-006 ACF）
- 赛题规定三段划分：0–2351 训练 / 2352–2375 调参 / 0–2375 重训 / 2376–2399 测试

**基础调度模型**：
- 无迁移约束下的任务→区域分配（实时任务本地、训练任务可跨区？S1 是"基础调度"——需确认是否允许跨区）
- GPU-hour 容量约束 + 时延约束 + 完成时限
- 方法：贪心/优先队列启发式（简单基线）→ 整数规划（精确）二选一或对比

## 2. S2 碳感知任务调度

**决策变量**：每任务 (迁移目的地, 开工时段)
**目标/指标**：运行成本、碳排放、网络时延、新能源利用率（四指标）
**建模思路**：
- 时段/区域粒度：2400h × 6 区域 × 50000 任务 → 全时域 MILP 规模极大 → 需分解
- 方案 A：线性化单目标（加权和 / ε-约束）→ MILP，用求解器（高德纳/COIN-OR CBC/SCIP）
- 方案 B：时间分解（逐日/逐 24h 滚动）→ 子问题 MILP
- 方案 C：启发式（GA/NSGA-II 求 Pareto 前沿）——与知识卡 WF-001/PR-001 一致
- 区域特征驱动：D 西部（低电价+低碳+大容量）、E/F（新能源富集）自然成为迁移目标，但时延约束限制实时任务

**新能源利用率口径**（统一）：(直接消纳 + 储能充电 + 外送) / 可用新能源

## 3. S3 储能协同优化

**决策变量**：每区域每小时 ChargePower/DischargePower/GridPurchase/GridSell/新能源分配
**给定**：Baseline_AI_IT_Load + NonAI_IT_Load（固定 IT 负荷）
**约束**：SOC 递推、SOC 上下限、充放功率、SOC(2406)≥Initial、MaxGridImport/Export、功率平衡
**方法**：线性规划（LP/MILP，目标：成本+碳排加权，或双目标 Pareto）
**分析**：储能对峰值净购电（削峰）、负荷波动（方差/峰谷差）、成本、碳排的影响对比基准 SOC 轨迹

## 4. S4 多区域算—储—电协同

**整合**：S2 调度 + S3 储能 + 购售电 → 全系统联合优化
**目标**：成本、碳排、时延、QoS、新能源利用率、峰值净购电（六目标权衡）
**场景比较**：不同碳约束（碳价/碳排放上限）、电价机制（峰谷平/分时）、新能源波动（风光出力情景）
**方法**：ε-约束 / 加权和 / NSGA-II Pareto 前沿 + 场景分析
**QoS 度量**：需定义（如时延满意度、任务按时完成率）
