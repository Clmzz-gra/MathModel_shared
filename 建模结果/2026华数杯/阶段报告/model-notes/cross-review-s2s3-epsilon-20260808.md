## 2. 五维差异分析

### 2.1 ε 档位可行性：两子问题均"ε 非活跃"（S2 未绑定 / S3 不可行）

- **S2**：ε 三档（100/90/80%）实测**全部未绑定**——容量感知分配把任务迁往西部低碳区，自由解碳排 251.78 kt 已低于 0.8×E₀=299.42 kt（−32.7% 减碳由迁移本身驱动，非 ε 收紧驱动）。
- **S3**：原 90/95% 档全部区域不可行，碳排几近刚性（受限消纳锚定 + 负荷固定 + 储能容量有限），ε=1.00 单档。
- **全局叙事（修订建议）**：ε-约束在两子问题中**均非主要权衡引擎**（S2 未绑定、S3 不可行）。真正的权衡与杠杆：
  - S2：**迁移降碳**（−32.7%）以成本代价 +2.0% 换取；碳强度东高西低 → 迁移成本-碳同向（无冲突）
  - S3：**储能调度降本**（−7.3%），碳排刚性（<5%）
  - 论文统一表述："减碳杠杆在调度迁移侧（−32.7%），成本优化杠杆在储能侧（−7.3%）；ε-约束作为合规性检查而非权衡引擎"。两子问题分别报告 ε 曲线（S2：未绑定平线至 E_min）与 ε_min 表（S3），不交叉比较 ε 数值。

### 2.2 碳排基线分母语义不同（不可交叉比较）

- S2 的 $E_0$ = S1 调度基线；S3 的 $CarbonBase$ = 数据基准轨迹。两者物理含义不同。
- **建议**：论文对每个子问题的 ε 明确定义"相对各自基线"，禁止跨子问题直接比"ε=90%"；数据集成单文件分别列示 S2（AI 任务碳排）与 S3（总设施碳排）。

### 2.3 碳排核算范围重叠（全局汇总须防重复计数）

- S3 碳排（2044.79 kt）核算**全部设施负荷**购电碳排，**已包含** S2 调度对应的 AI 任务分量。
- **全局碳排汇总口径（建议）**：问题级总碳排 = S3 的碳排（主口径，覆盖全部设施负荷）；S2 的碳排作为**内部构成分析**（AI 任务分量），不得与 S3 相加。

### 2.4 区域结构差异（分区域 vs 全局碳帽）

- S3 逐区独立碳帽（保持区域解耦）；S2 全局碳帽 + 区域分解。两口径在各自子问题内自洽，无需统一；但论文"碳排放约束"一节须分别注明结构，避免评审误读。

### 2.5 新能源利用率接口衔接（潜在冲突，需阶段 3 定夺）

- S2 明确"新能源利用率正式计算移交 S3/S4"（S2 只报间接贡献）。
- **S3 实测（受限口径）**：利用率被逐时锚定基准（20.83%，含/不含外送趋同），**与区域负荷分布无关**。
- **接口结论（建议）**：S2 的迁移调度改变了区域承接量/负荷分布，但在 S3 受限口径下**不影响 S3 利用率指标**（利用率锚定基准消纳能力，非负荷分布函数）。阶段 3 需在论文明确："新能源利用率 = f(消纳能力)，与任务迁移无耦合"——否则 S2"利用率移交 S3"的叙事落空。
