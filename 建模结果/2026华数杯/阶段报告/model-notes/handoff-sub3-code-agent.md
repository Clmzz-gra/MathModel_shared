## 3. 关键发现（供裁定）

1. **ε 档位有效（无需收紧）**：5/6 区域碳排精确撞 1.00 上限（约束绑定），聚合 C* = 2044.79 ≈ 基准 2045.36 → **90/95/100 档位将产生真实 Pareto 梯度**。
2. **无购电→卖电套利（实证）**：D/E/F 全部 2400 h `SellPrice ≤ Price`；受限消纳下 S≈0，新能源全部直供/充电（R+Cr 用满 cap）→ **裁定 3 的"卖电≤新能源充电+富余"约束确认无需追加**。
3. **峰值净购电撞 MaxGridImport**（550/520/510/510/370/340 = 各区域购电上限）：受限消纳削弱新能源削峰 + 优化解高峰充电，**"削峰"叙事需按受限口径重新解读**（优化峰值 > 无储能 479 > 基准 497）。
4. **优化成本 2213.35 > 基准 1802.34**：基准负成本来自卖电收入（其轨迹违反 SOC(2406)≥Initial、非可行/非最优）；受限口径下无富余新能源可卖 → **四指标对比须注明"基准不可比"**。
5. **储能贡献量级（受限口径）**：优化 vs 无储能c：成本 −7.3%、碳排 −3.0%、峰值 +14.8%。
